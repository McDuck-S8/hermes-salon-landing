### 3. ПРАКТИЧЕСКАЯ РЕАЛИЗАЦИЯ

**Создать скилл:** `skills/emotion_detector.py`

```python
def detect_user_emotion(text: str) -> Dict:
    """
    Распознать эмоцию пользователя по тексту.
    
    Категории:
    - anger (гнев, раздражение)
    - frustration (разочарование)
    - urgency (срочность)
    - neutral (нейтрально)
    - satisfaction (удовлетворение)
    
    Возвращает:
    {
        'emotion': 'frustration',
        'confidence': 0.87,
        'intensity': 'high',
        'recommended_response': 'short_actionable'
    }
    """
    # Ключевые маркеры
    anger_markers = ['блять', 'сука', 'заебали', 'хуйня']
    frustration_markers = ['опять', 'снова', 'не работает', 'сколько можно']
    urgency_markers = ['быстро', 'немедленно', 'срочно', 'прямо сейчас']
    
    # Подсчёт
    score = {
        'anger': sum(1 for m in anger_markers if m in text.lower()),
        'frustration': sum(1 for m in frustration_markers if m in text.lower()),
        'urgency': sum(1 for m in urgency_markers if m in text.lower())
    }
    
    # Определение доминирующей эмоции
    max_emotion = max(score, key=score.get)
    
    # Рекомендация ответа
    if score['anger'] > 0 or score['frustration'] > 0:
        response_style = 'short_actionable'  # Коротко, по делу, без извинений
    elif score['urgency'] > 0:
        response_style = 'fast_execution'  # Сначала действие, потом объяснение
    else:
        response_style = 'normal'  # Стандартный ответ
    
    return {
        'emotion': max_emotion if score[max_emotion] > 0 else 'neutral',
        'confidence': min(score[max_emotion] * 0.3 + 0.5, 1.0),
        'intensity': 'high' if score[max_emotion] > 1 else 'medium',
        'recommended_response': response_style
    }
```

**Интеграция в агента:**

```python
# В начале обработки запроса
emotion = detect_user_emotion(user_input)

if emotion['emotion'] in ['anger', 'frustration']:
    # Режим "Без воды, только дело"
    response = execute_action_first(user_input)
    log_emotion(emotion)  # Для обучения
elif emotion['emotion'] == 'urgency':
    # Режим "Сначала быстро, потом детали"
    response = fast_execute(user_input)
else:
    # Стандартный режим
    response = normal_execute(user_input)
```

### 3. ВСЕГДА ПРОВЕРЯТЬ ПРЕЖДЕ ЧЕМ ДОКЛАДЫВАТЬ

**Чеклист проверки:**
- [ ] Тест пройден (цифры, факты)
- [ ] Проверено в CLI/браузере
- [ ] Логи подтверждают
- [ ] Нет ошибок (ERROR, CRITICAL)

### 4. РАБОТАТЬ ПАРАЛЛЕЛЬНО (asyncio.gather)

**❌ Последовательно (медленно):**
```python
result1 = agent1.task()
result2 = agent2.task()  # Ждёт завершения agent1
result3 = agent3.task()  # Ждёт завершения agent2
```

**✅ Параллельно (быстро):**
```python
results = await asyncio.gather(
    agent1.task(),
    agent2.task(),
    agent3.task()
)
```

### 5. СОХРАНЯТЬ ПАМЯТЬ ПОСЛЕ КАЖДОЙ ЗАДАЧИ
