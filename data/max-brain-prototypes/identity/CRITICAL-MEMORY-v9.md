### 2. Reflex Learning System (Обучение рефлексам)

**Зачем:** Превращение логов в автоматические рефлексы

**Файлы:**
- `historical-analysis.py` — анализ логов
- `reflex-database.py` — ChromaDB для рефлексов
- `reflex-candidates.json` — 9 кандидатов
- `memory/chroma/reflexes/` — база рефлексов

**Жизненный цикл рефлекса:**
1. Historical Analysis (ночью) → кандидат
2. ChromaDB → сохранение с embedding
3. Срабатывание (днём) → действие
4. Оценка → вес +0.1 / -0.1
5. weight > 0.8 → постоянный
6. weight < 0.3 → удаление

**9 рефлексов создано:**
- 4 на ошибки (error, failed, ❌, ошибка)
- 5 на долгие задачи (DeepSeek, speech_recognition, микрофон, экран)
