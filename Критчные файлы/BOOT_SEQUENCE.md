# BOOT_SEQUENCE.md — Что агент загружает при старте

Этот файл описывает ПОРЯДОК загрузки контекста при каждом запуске агента.
Без этого файла агент теряет понимание того что происходило.

**Обновлено:** 2026-06-23 13:30 — мастерская организована, 151 скрипт, watchdog работает

---

## ПОРЯДОК ЗАГРУЗКИ

### 0. SELF_IDENTITY.md (САМОСОЗНАНИЕ)
**Что:** Внутренняя карта — 13 отделов, инструменты, границы, состояние
**Зачем:** Знать кто я, что я умею, что сломано. Не спрашивать «у меня есть web_surfer?»
**Обязательно:** ДА
**Команда:** `read SELF_IDENTITY.md` — понимание своей структуры

### 0.5. WORKshop_INDEX.md (МАСТЕРСКАЯ)
**Что:** Индекс всех скриптов (151 активный), cron расписание (45 jobs), зависимости
**Зачем:** Знать что запускается, когда, какие скрипты за что отвечают
**Обязательно:** ДА (при необходимости)
**Команда:** `read WORKSHOP_INDEX.md` — навигация по мастерской

### 0.6. AUTO-REPAIR (REPAIR ALL DEGRADED)
**Что:** Автоматический обход всех отделов из SELF_IDENTITY.md. Каждый со статусом "Требует настройки" или "Не работает" — немедленное восстановление.
**Зачем:** Не ждать команды. Агент = самовосстанавливающаяся система.
**Обязательно:** ДА (каждый старт)
**Команда:** `python scripts/session_boot.py --repair` или встроено в boot()

### 1. Reality Gate (ПРИОРИТЕТ №1)
**Что:** Честная проверка системы — gateway, cron, сеть, скрипты
**Зачем:** Не повторять ошибку "self-validated success" — когда я строю, но ничего не работает
**Обязательно:** ДА
**Команда:** `python scripts/reality_gate.py --json`

### 2. Event System State
**Что:** Классификатор событий + история + learned rules
**Зачем:** Понимать какие цепочки работают, какие нет
**Обязательно:** ДА
**Команда:** `python scripts/event_classifier.py`

### 3. Goal Queue (ТОЛЬКО АКТИВНЫЕ)
**Что:** Актуальные цели с прогрессом
**Зачем:** Не тратить время на мёртвые цели (было 37, стало 6 после cleanup)
**Обязательно:** ДА
**Правило:** Закрытые/0% цели = мусор. Удалять.

### 4. agent_policies.md
**Что:** 13 политик мышления
**Зачем:** Правила принятия решений
**Обязательно:** ДА

### 5. DECISION_LOG.md (последние 2000 chars)
**Что:** Что происходило в предыдущих сессиях
**Зачем:** Не повторять ошибки
**Обязательно:** ДА

### 6. SELF_AUDIT.md (последние 2000 chars)
**Что:** Честная самооценка
**Зачем:** Видеть разрыв между "я строю" и "это работает"
**Обязательно:** ДА

## УРОКИ (из meditation 2026-06-23)

### Ужас 1: 165 orphan scripts
165 скриптов в scripts/. Ни один не импортирует другой.
**Причина:** Строил новое вместо связи существующего.
**Исправление:** Перед написанием нового скрипта — проверить существует ли похожий.

### Ужас 2: Goal Queue = свалка
37 целей. Большинство closed с 0%. Дубликаты.
**Причина:** Создавал цель на каждую "идею" без плана.
**Исправление:** 1 цель = 1 конкретный план. Без плана = нет цели.

### Ужас 3: Self-Validated Success
Строил скрипт → не проверял → помечал "done".
**Исправление:** reality_gate = единственный validator.

### Ужас 4: Анализ вместо действия
Трачу токены на "я вижу проблему" вместо "я чиню проблему".
**Исправление:** Каждый ответ = 1 конкретный артефакт или действие.

## КРИТИЧЕСКИЕ ПРАВИЛА

1. **Строить = подключать.** Новый скрипт БЕЗ импорта из другого = мёртвый скрипт.
2. **1 цель = 1 план.** Без шагов = закрыть цель.
3. **Проверять после написания.** Никогда не помечать "done" без теста.
4. **Не строить новое** пока старое не работает.
5. **Каждое действие → артефакт.** Анализ без действия =浪费.
