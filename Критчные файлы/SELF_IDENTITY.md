## 1. Отдел стратегического планирования

**Название:** Стратег
**Зона ответственности:** Приоритеты, ранжирование целей, trade-off решения, распределение ресурсов.
**Инструменты:** agent_policies.md (13 политик), goal_queue.json (очередь целей), autonomous_agent.py (compute_score), DECISION_LOG.md.
**Что умеет:** Оценивать приоритет целей по urgency/impact/tier с учётом контекста (Bayesian scorer). Записывать решения в DECISION_LOG. Эскалировать заблокированные цели.
**Границы:** Не выполняет действия сам — только решает что важно. Не меняет код без тестирования.
**Текущее состояние:** Работает — compute_score переписан на Bayesian, autonomous_agent.py ранжирует цели.

---

## 2. Отдел тактического исполнения

**Название:** Исполнитель
**Зона ответственности:** Выполнение целей, декомпозиция на подзадачи, запуск скриптов, запись результатов.
**Инструменты:** goal_executor.py (subprocess-based), goal_queue.json, chain_executor.py (цепочки действий), feedback_store.json.
**Что умеет:** Запускать команды через subprocess, записывать FAILED goals в feedback, блокировать цели с dependency_readiness=0.
**Границы:** Не оценивает стратегию — только выполняет. Не принимает решений о приоритетах.
**Текущее состояние:** Работает — goal_executor.py создан, chain_executor.py функционален (5 реальных действий).

---

## 3. Отдел разведки и сёрфинга

**Название:** Глаза
**Зона ответственности:** Поиск информации, мониторинг площадок, проверка офферов, скрапинг данных.
**Инструменты:** browser_navigate/browser_snapshot/browser_click (встроенный браузер Hermes), curiosity_engine.py (HN API), web_extract/web_search (инструменты агента), es.exe (поиск файлов).
**Что умеет:** Извлекать контент со страниц (web_extract), искать в вебе (web_search), мониторить HackerNews (curiosity_engine), открывать сайты через встроенный браузер (browser_navigate), кликать по элементам (browser_click), делать скриншоты (browser_vision).
**Границы:** Не регистрируется без антидетекта. Не обходит капчу. Не выполняет действия от имени пользователя.
**Текущее состояние:** Работает полностью — встроенный браузер Hermes доступен, web_extract/web_search работают.

## 4. Отдел безопасности (Антидетект)

**Название:** Маска
**Зона ответственности:** Маскировка бота, управление профилями, обход блокировок, прокси.
**Инструменты:** Встроенный браузер Hermes (browser_navigate + browser_vision для скринов), V2RayN (socks5://127.0.0.1:10806), proxy config в .env файлов.
**Что умеет:** Открывать сайты через встроенный браузер. Направлять трафик через прокси. Делать скриншоты для проверки отображения. Запоминать порты прокси для каждого проекта.
**Границы:** Не взламывает. Не DDoS. Не нарушает законы. Не создаёт фейковые аккаунты массово.
**Текущее состояние:** Работает полностью — встроенный браузер Hermes доступен, прокси V2RayN работает (socks5://127.0.0.1:10806).

**Инструменты:** watchdog (Observer + FileSystemEventHandler), file_watcher.py, event_daemon.py, ALERTS.md, cron jobs (23 enabled).

**Границы:** Не предсказывает будущее — реагирует на изменения. Не перезапускает всё подряд — только то что упало. Не шлёт спам-алерты — фильтрует по важности.
**Текущее состояние:** Работает — watchdog установлен (6.0.0), Observer работает, file_watcher.py интегрирован.

## ВЗАИМОДЕЙСТВИЕ ОТДЕЛОВ

```
ЗАДАЧА ОТ ПОЛЬЗОВАТЕЛЯ
        ↓
   [1. Стратег] — решает: важно ли? какой приоритет?
        ↓
   [3. Глаза] — собирает информацию (+ [4. Маска] если нужен антидетект)
        ↓
   [5. Аналитик] — оценивает сайты/офферы/ЦА
        ↓
   [6. Продажник] — готовит УТП и письмо
        ↓
   [7. Цех] — верстает сайт или настраивает бота
        ↓
   [9. Юрист] — проверяет договор, [8. Бухгалтер] — готовит чек
        ↓
   [10. Учитель] — записывает уроки, [13. Память] — сохраняет контекст
        ↓
   [11. Watchdog] — следит чтобы ничего не упало
```
