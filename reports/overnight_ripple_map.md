### 🚀 iGaming SEO Playbook

**Что это:** Сетка iGaming-сайтов с SEO-трафиком. Без бюджета. Без KYC.

**Почему завтра:**
- YouTube-видео показывает конкретный кейс: DR 0→30 за 60 дней, 3K impressions/day
- Нужны только: домен ($10), хостинг (GitHub Pages = бесплатно), контент (AI-генерация)
- SEO-трафик = бесплатный, долгосрочный, масштабируемый

**Конкретные шаги:**
1. Зарегистрировать домен (например, igaming-tips.com)
2. Создать 10-15 статей через AI (крикет, ставки, обзоры казино)
3. Запустить PBN из 5-10 сайтов на GitHub Pages
4. Накрутить поведенческие факторы (Yandex-compatible)
5. Монетизировать через CPA-офферы (1xBet, 1win)

**Математика:**
- Домен: $10/год
- Хостинг: $0 (GitHub Pages)
- Контент: 0 (AI-генерация)
- PBN: 5-10 доменов × $10 = $50-100/год
- Ожидаемый доход: 50-200 лидов/мес × $5-15/CPA = $250-3000/мес
- Точка безубыточности: 1-2 месяца

**Конфликты:** Нет. Работает в Крыму, без KYC, без бюджета, stdlib-first.
