## 1. ПОЧЕМУ ПРОГРЕВ — ЭТО НЕ "ПОДОЖДАТЬ НЕДЕЛЮ"

TikTok в 2026 детектирует фермы по трём уровням:
- **Device fingerprint** — 50+ параметров (GPU, WebGL, canvas, fonts, battery, screen)
- **Behavioral analysis** — скролл, тапы, паузы, время просмотра, паттерны
- **Cross-session IP correlation** — если аккаунты заходили с одного IP, они связаны

**Главное открытие:** антидетект браузеры (Multilogin, AdsPower) **не работают** для TikTok в масштабе. TikTok — mobile-first платформа, она проверяет сигналы за пределами браузера: сенсорные кривые, датчики движения, контекст установки из App Store, OS-level идентификаторы. Браузер не может сгенерировать эти сигналы. Конберса: "At portfolio scale — 30-50 accounts — the cumulative gap between spoofed browser signals and genuine device signals becomes statistically detectable."

**Решение:** реальные Android устройства или cloud-телефоны (GeeLark).

## 2. ИНФРАСТРУКТУРА (3-LEVEL PROTECTION STACK)

### Layer 1 — Mobile Proxy (обязательно)
- Только 4G/5G мобильные прокси (94% success rate)
- Residential — 72%, Datacenter — <30% (TikTok их детектит)
- VPN запрещён — TikTok банит VPN-IP мгновенно
- Один прокси = один аккаунт (или группа до 3 аккаунтов)
- Провайдеры: Proxy-Solutions, PROXIES.SX

### Layer 2 — Device/Phone (критично)
- **Для 1-5 аккаунтов:** реальный Android телефон + мобильные данные
- **Для 5-50 аккаунтов:** cloud-телефоны GeeLark (реальные Android в облаке)
- Антидетект браузеры (Multilogin, AdsPower) — только для Linkedin/X/форумов
- Каждый аккаунт = уникальный fingerprint

### Layer 3 — Behavioral Patterns (самое важное)
- Разные паттерны активности для каждого аккаунта
- Не постить в одно и то же время
- Не лайкать одни и те же видео
- Не использовать одинаковые нейтральные видео для прогрева

## 3. 14-ДНЕВНЫЙ ПЛАН ПРОГРЕВА

| День | Действия | Лимиты | Примечание |
|------|----------|--------|------------|
| **1** | Регистрация + скролл FYP 20-30 мин | 0 лайков, 0 подписок, 0 комментов | Просто смотрим ленту |
| **2** | Скролл + редкие лайки | 15-20 лайков, 0 подписок | Лайкать 2-3 в минуту, не чаще |
| **3-4** | Лайки + первые подписки + 1-2 коммента | 30 лайков, 5-10 подписок, 1-2 коммент | Комменты нейтральные ("cool", "nice") |
| **5-6** | **Первое видео** (нейтральное) + активность | 40 лайков, 10-15 подписок, 3-5 коммент | Видео: не про USDT! Просто развлекательное |
| **7** | **Тестовое видео** (близкое к офферу) | 1 видео | Первый намёк на тему |
| **8-10** | 2-3 видео/день, рост активности | 50 лайков, 15-20 подписок | 70% нейтрального / 30% целевого |
| **11-14** | **Bio link** (не раньше 1000 подписчиков) | Полная нагрузка | Если фолловеров < 1000 — link на 12-14 день |

**Критические ошибки:**
- ❌ Bio-ссылка в Day 1 → немедленный shadowban
- ❌ Одинаковый паттерн прогрева на всех аккаунтах → кластеризация
- ❌ Одно и то же видео на всех аккаунтах → нужно уникализировать
- ❌ Резкий переход от нейтрального к офферу → нужен плавный градиент

## 4. ДЛЯ НАШЕГО КЕЙСА (1 TikTok аккаунт, USDT, Крым)

**Ограничения:**
- Крым — некоторые прокси не работают
- 1 аккаунт (не ферма — пока)
- Бюджет $0 (хотя мобильный прокси $4-6/GB — стоит вложить)

**План действий (упрощённый):**

### Фаза 0: Подготовка (сегодня)
1. Купить **мобильный 4G прокси** РФ (Proxy-Solutions или аналог) — $5-10
2. Установить **GeeLark** (cloud phone) ИЛИ использовать реальный Android
3. Создать **новый TikTok аккаунт** — через приложение, не через браузер

### Фаза 1: Прогрев (дни 1-4)
- Скролл 20-30 мин/день
- Лайки (15-30/день)
- Подписки на аккаунты по теме крипта/финансы (5-10/день)
- Ноль видео

### Фаза 2: Первые видео (дни 5-7)
- Видео 1: нейтральное (#crypto #usdt — но без ссылок)
- Видео 2: образовательное ("Что такое USDT простыми словами")
- Только название канала + аватар, без ссылок

### Фаза 3: Рабочие видео (дни 8-14+)
- Градиент от нейтрального к целевому
- Видео 3-5: смешанный контент (50/50)
- Видео 6+: Tutorial + CTA
- Bio link — только после 1000 подписчиков

### Альтернатива (быстрый старт):
Купить **прогретый аккаунт** с историей (5-7 дней прогрева вместо 14).
Стоимость: $3-10 на чёрном рынке. Риск: аккаунт может быть кластеризован.
