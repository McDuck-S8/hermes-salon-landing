## Beget
- Решение: 🛠 Разместить HTML-сайт косметолога. PHP/MySQL/FTP.
- Вопросы:
  - storage: Где хранить пароли/доступы к Beget?
  - backup: Как бэкапить сайт с Beget? FTP → локально?
  - usage: Можно ли сделать лендинг с формой записи?
  - domain: Купить домен через них или отдельно?
  - scaling: Переход на платный при росте трафика?
- Партнёрка: ✅ ЕСТЬ (beget.com/en/partnership, выплаты: безнал + YooMoney)
- Урок: Российский хостинг работает из Крыма. FTP дают. Без карты.
- Связи: 💄косметолог, 📂directory, 💰партнёрка
- Гео: ✅ Крым | Карта: ❌ не нужна | Статус: ⚡готов к тесту

## Cloudflare Pages
- Решение: 🛠 Быстрый статический хостинг. Для directory_proto.html.
- Вопросы:
  - storage: CLI-деплой через npm
  - backup: git clone = бэкап
  - usage: Можно Workers для API
  - domain: Свой — бесплатно
  - scaling: Безлимит bandwidth
- Партнёрка: ✅ $50-200/referral, PowerUP program
- Урок: Быстрее GH Pages. Не требует git. Безлимит трафика.
- Связи: 📂directory, ⚡Workers, 💰партнёрка
- Гео: ⚠ через прокси | Карта: ❌ | Статус: ⚡готов к тесту
