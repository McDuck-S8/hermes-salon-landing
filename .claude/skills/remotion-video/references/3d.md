# 3D with Three.js Reference

Reference: https://www.remotion.dev/docs/3d

## Install
```bash
npx remotion add @remotion/three
```

## Basic Setup
```tsx
import { ThreeCanvas } from "@remotion/three";
// NOT <Canvas> from R3F!

const Scene3D = () => (
  <ThreeCanvas width={1920} height={1080} shadows>
    <ambientLight intensity={0.5} />
    <directionalLight position={[5, 10, 7]} intensity={1} castShadow />
    
    {/* Your 3D objects */}
    <mesh position={[0, 0, 0]} castShadow receiveShadow>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color="#0066ff" roughness={0.3} metalness={0.1} />
    </mesh>
    
    <mesh position={[0, -1.5, 0]} receiveShadow>
      <planeGeometry args={[10, 10]} />
      <meshStandardMaterial color="#111111" />
    </mesh>
  </ThreeCanvas>
);
```

## Animation (MUST use useCurrentFrame)
```tsx
import { useCurrentFrame, useVideoConfig } from "remotion";

const AnimatedCube = () => {
  const frame = useCurrentFrame();
  const { fps, durationInFrames } = useVideoConfig();
  
  const progress = frame / durationInFrames;
  const rotation = progress * Math.PI * 2;
  
  // ❌ FORBIDDEN: useFrame() from R3F
  // ✅ REQUIRED: useCurrentFrame() from Remotion
  
  return (
    <mesh rotation={[rotation * 0.3, rotation, rotation * 0.5]}>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color="#0066ff" />
    </mesh>
  );
};
```

## Lighting
| Light | Use Case |
|-------|----------|
| `ambientLight` | Base fill |
| `directionalLight` | Sun-like, cast shadows |
| `pointLight` | Local light source |
| `spotLight` | Focused beam |

## Materials
```tsx
<meshStandardMaterial
  color="#0066ff"
  roughness={0.3}
  metalness={0.1}

  opacity={1}
/>
```

## Animation Helpers
```tsx
import { interpolate, spring, useCurrentFrame } from "remotion";

const frame = useCurrentFrame();
const { fps } = useVideoConfig();

const rotate = interpolate(frame, [0, 1800], [0, Math.PI * 4]); // 4 full rotations
const float = spring(frame, { fps, config: "gentle" }); // Smooth float
const scale = interpolate(frame, [0, 30], [1, 1.5], { clamp: true });
```

## Post-Processing
```tsx
import { EffectComposer, BloomEffect } from "@remotion/three";

<ThreeCanvas>
  <EffectComposer>
    <BloomEffect intensity={1.5} threshold={0.8} />
  </EffectComposer>
</ThreeCanvas>
```

## ❌ FORBIDDEN Patterns
| ❌ Don't | ✅ Do |
|----------|-------|
| `<Canvas>` from R3F | `<ThreeCanvas>` from @remotion/three |
| `useFrame()` from R3F | `useCurrentFrame()` from remotion |
| `useThree()` from R3F | `useVideoConfig()` from remotion |
| `gsap.to()` | `interpolate()` / `spring()` |
| `requestAnimationFrame` | Frame-based logic only |

## Key Rule
**Every frame renders identically given same inputs.** No randomness, no side effects, pure frame→output mapping.
