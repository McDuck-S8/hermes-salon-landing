# AI Interview Prep — Прототип продукта

**AI-подготовка джуниоров к собеседованиям**: парсинг резюме (PDF/DOCX), парсинг вакансий с HH.ru, мэтчинг навыков через GPT-4o, генерация вопросов и 7-дневного плана подготовки.

---

## 🚀 Быстрый старт

### 1. Backend
```bash
cd backend
cp .env.example .env
# Заполни OPENAI_API_KEY в .env (опционально — работает fallback без LLM)
pip install -r requirements.txt
python main.py
```
Сервер поднимется на `http://localhost:8000`
Документация API: `http://localhost:8000/docs`

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
Откроется на `http://localhost:3000` (проксирует `/api` на бэкенд)

## 🔄 Пользовательский флоу (4 шага)

1. **Резюме** — загрузка PDF/DOCX/TXT → парсинг навыков, опыта, образований
2. **Вакансия** — вставка ссылки HH.ru (`hh.ru/vacancy/123456`) → автопарсинг через API HH
3. **Мэтчинг** — GPT-4o сравнивает резюме и вакансию → мэтч-скор 0-100%
4. **Результат** — вкладки:
   - 📊 Мэтч-скор + рекомендации по правкам резюме
   - ✅ Сильные стороны (матчинг скиллов)
   - ⚠️ Пробелы (нет в резюме, есть в вакансии)
   - ❓ 5-7 вопросов к собеседованию с подсказками
   - 📅 7-дневный план подготовки (теория + практика + мок-собес)

## 🛠 API Endpoints

| Method | Endpoint | Описание |
|--------|----------|----------|
| POST | `/api/resume/upload` | Загрузка файла резюме |
| POST | `/api/resume/text` | Парсинг текста резюме |
| GET | `/api/resume/{id}` | Получить распарсенное резюме |
| POST | `/api/vacancy/fetch` | Парсинг вакансии по URL HH.ru |
| POST | `/api/vacancy/text` | Создание вакансии вручную |
| GET | `/api/vacancy/{id}` | Получить вакансию |
| POST | `/api/match` | Мэтчинг резюме + вакансия |
| GET | `/api/match/{id}` | Получить результат мэтчинга |
| GET | `/health` | Health check |

## 🔧 Технологии

**Backend:** FastAPI, Python 3.11+, PyPDF2, python-docx, httpx, OpenAI SDK  
**Matching:** GPT-4o (structured output JSON) + эвристический fallback  
**Frontend:** React 18, Vite, CSS Variables (design tokens), Lucide icons  
**Storage:** In-memory (MVP) → PostgreSQL + Redis (прод)  
**Deploy:** Docker Compose / Railway / Fly.io / VPS
