# 🤖 Бот для салона красоты

Telegram-бот для записи клиентов в салон красоты / маникюр / парикмахерскую.

## Функции

### Клиент
- Выбрать услугу, мастера, дату и время
- Подтвердить / отменить запись
- Посмотреть свои записи
- Оставить отзыв

### Мастер (/master)
- Войти по коду от администратора
- Смотреть записи на день
- Смотреть статистику

### Администратор (/admin)
- Управление мастерами (добавить/деактивировать)
- Управление услугами (добавить/вкл/выкл)
- Просмотр всех записей
- Статистика (доход, клиенты)
- Генерация кодов доступа для мастеров

## Установка

```bash
pip install -r requirements.txt
```

1. Получите токен у @BotFather
2. Вставьте в config.py BOT_TOKEN
3. Узнайте свой Telegram ID через @userinfobot
4. Вставьте в config.py SUPERADMIN_ID
5. Запустите:

```bash
python main.py
```

## Стек
- Python 3.10+
- aiogram 3.x
- SQLite (aiosqlite)
