# Salon Bot — Demo Template
# Заполняется под конкретного клиента перед продажей

## Что входит в бота

### Для клиентов (клиентский интерфейс):
- /start — главное меню с инлайн-кнопками
- Запись на услугу (выбор мастера → услуги → дата/время)
- Напоминание о визите (за 1 час)
- Просмотр истории визитов
- Mini App (веб-запись прямо в Telegram)

### Для мастера:
- /master — панель мастера
- Расписание на сегодня/завтра
- Подтверждение/отмена записи
- Статистика (сколько клиентов, выручка)

### Для администратора:
- /admin — панель управления
- Управление услугами, мастерами, расписанием
- Статистика (визиты, выручка, популярные услуги)
- Рассылка клиентам

### Автоматизация:
- Авто-напоминания о записях
- Рассылка "Давно не были?" (30 дней без визита)
- Обратная связь после визита
- Cron: watchdog перезапуска

## Установка (для клиента)

### 1. Требования
- VPS Ubuntu 22.04+ (2GB RAM, 1 CPU)
- Python 3.11+
- Telegram Bot Token (от @BotFather)

### 2. Деплой (5 минут)
```bash
# Клонировать проект
git clone <repo_url> salon-bot && cd salon-bot

# Установить зависимости
pip install -r requirements.txt

# Настроить конфиг
cp .env.example .env
# Заполнить: BOT_TOKEN, SUPERADMIN_ID

# Запустить
python main.py
```

### 3. Первоначальная настройка
1. Отправить /admin → добавить услуги
2. Добавить мастеров
3. Настроить расписание
4. Протестировать запись через /start
