# Tribute Setup Guide — AI OFM Telegram Channel

## Быстрая настройка (5 минут)

### 1. Добавить бота в канал

1. Открой Telegram → найди **@Tribute** → нажми Start
2. Нажми "Добавить канал" → выбери свой канал
3. Дай права: отправлять, редактировать, удалять сообщения, добавлять подписчиков

### 2. Настроить подписку

В @Tribute боте:
1. "Управление каналом" → "Подписки" → "Создать подписку"
2. Название: "Premium доступ"
3. Цена: **€5** (или эквивалент в RUB: ~500₽)
4. Период: **Месяц**
5. Способ оплаты: выбери **Wallet Pay** (для USDT)

### 3. Wallet Pay — ключевой шаг

Wallet Pay даёт:
- Подписчики платят в USDT/TON/BTC по курсу
- Деньги конвертируются в USDT сразу
- Выплаты дважды в месяц: 10-го и 25-го числа
- Минимум: 100 USDT для выплаты

В настройках подписки добавь Wallet Pay как способ оплаты.

### 4. KYC (верификация)

@Tribute потребует:
1. Фото паспорта (РФ)
2. Адрес проживания (документ не старше 3 месяцев)

**Для Крыма:** если в паспорте крымская прописка, используй любой другой документ с адресом (например, справку из банка с российским адресом).

### 5. Платёжные данные для вывода

Выбери:
- **Wallet Pay (USDT)** — для крипто-вывода (наш путь)
- Или **Банковская карта** (EUR/RUB) — для прямого вывода на МИР/карту

Рекомендую Wallet Pay → USDT → внешний кошелёк → P2P → RUB.

### 6. Проверка

После настройки:
1. Попроси друга подписаться
2. Убедись, что оплата прошла через Wallet Pay
3. Проверь баланс в @tribute боте

## Вывод USDT на внешний кошелёк

Когда USDT придёт в @wallet:

1. Открой @wallet бот
2. "Send" → "External Wallet"
3. Введи адрес Trust Wallet / MetaMask (сеть TON для 1 USDT комиссии)
4. Подтверди

Даже если @wallet выдаёт "Unsupported region" (Крым в списке):
- Всё равно можно вывести USDT через "Send" → функция доступна при блокировке
- Источник: help.wallet.tg — "If your access is suspended, you can still withdraw via 'Send'"

## P2P: USDT → RUB

Из внешнего кошелька:
1. Отправь USDT на Bybit или Binance
2. P2P торговля: продай USDT за RUB на карту Т-Банка (или любой российской)
3. Готово
