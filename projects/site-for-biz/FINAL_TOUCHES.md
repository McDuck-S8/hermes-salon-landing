# ТРИ ФИНАЛЬНЫХ ШТРИХА — САМОВОСПРОИЗВОДЯЩАЯСЯ СИСТЕМА

**Дата:** 2026-06-20

---

## 1. РЕФЕРАЛЬНАЯ ПЕТЛЯ

После завершения проекта:
1. Сделать кейс (было/стало/результат) — с разрешения клиента
2. Попросить рекомендацию: "Если понравилось — посоветуйте меня"
3. Через 2 недели: письмо-благодарность "Как сайт? Кстати, если есть знакомые..."
4. Одна продажа → кейс → доверие → следующая продажа. Петля замыкается.

---

## 2. ПАССИВНЫЙ ПОТОК (портфолио-сайт)

Создать сайт-портфолио:
- Заголовок: "Сайты для малого бизнеса за 3 дня. Симферополь и Крым"
- 3 кейса (когда появятся первые клиенты)
- Кнопка "Заказать сайт" → Telegram
- SEO: "создание сайтов Симферополь", "сайт для салона красоты Крым"

Создать после первых 2-3 продаж.

---

## 3. БАЗА ЗНАНИЙ ПО ГОРОДАМ (CITY_PLAYBOOK.md)

Симферополь = пилот. После первых продаж — масштабирование:
1. Собрать бизнесы (Яндекс.Карты, 2GIS)
2. Изучить локальный рынок (ниши, цены)
3. Адаптировать УТП под город
4. Запустить конвейер

Тогда: не "делаю сайты в Симферополе", а "захожу в любой город за неделю".
