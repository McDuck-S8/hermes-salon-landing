## Каналы поиска клиентов

1. **Яндекс.Карты** — ищем «барбершоп Симферополь», «стоматология Симферополь»
   → берём те, у кого нет сайта
   → находим Telegram/WhatsApp из карточки

2. **2ГИС** — аналогично

3. **Instagram** — ищем бизнес-аккаунты WITHOUT website link
   → пишем в DM

4. **Avito** — объявления бизнеса → kontakt → outreach
