📊 Массивы
Two Sum Easy 
def twoSum(nums, target):
    prev = {}
    for i, n in enumerate(nums):
        diff = target - n
        if diff in prev:
            return [prev[diff], i]
        prev[n] = i
Хэш-таблица: для каждого числа ищем разницу target - n. O(n) время, O(n) память.
Maximum Subarray Medium 
def maxSubArray(nums):
    max_sum = nums[0]
    cur = 0
    for n in nums:
        if cur < 0: cur = 0
        cur += n
        max_sum = max(max_sum, cur)
    return max_sum
Алгоритм Кадана: обнуляем сумму если отрицательная. O(n), O(1).
Contains Duplicate Easy 
def containsDuplicate(nums):
    return len(nums) != len(set(nums))
Сравниваем длину массива с длиной множества. O(n), O(n).
📝 Строки
Valid Parentheses Easy 
def isValid(s):
    stack = []
    pairs = {')': '(', '}': '{', ']': '['}
    for c in s:
        if c in pairs:
            if not stack or stack.pop() != pairs[c]:
                return False
        else:
            stack.append(c)
    return not stack
Стек для отслеживания открывающих скобок. O(n), O(n).
Longest Substring Medium 
def lengthOfLongestSubstring(s):
    seen = {}
    left = max_len = 0
    for right, c in enumerate(s):
        if c in seen and seen[c] >= left:
            left = seen[c] + 1
        seen[c] = right
        max_len = max(max_len, right - left + 1)
    return max_len
Скользящее окно с хэш-картой позиций символов. O(n), O(n).
Valid Anagram Easy 
def isAnagram(s, t):
    if len(s) != len(t): return False
    from collections import Counter
    return Counter(s) == Counter(t)
Сравниваем частотные словари символов. O(n), O(n).
🌳 Деревья
Max Depth of Binary Tree Easy 
def maxDepth(root):
    if not root: return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
Рекурсивный DFS: глубина = 1 + макс(левая, правая). O(n), O(h).
Invert Binary Tree Easy 
def invertTree(root):
    if root:
        root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root
Меняем местами левого и правого потомка рекурсивно. O(n), O(h).
Symmetric Tree Easy 
def isSymmetric(root):
    def mirror(a, b):
        if not a and not b: return True
        if not a or not b: return False
        return (a.val == b.val
                and mirror(a.left, b.right)
                and mirror(a.right, b.left))
    return mirror(root, root)
Проверяем зеркальность левого и правого поддеревьев. O(n), O(h).
