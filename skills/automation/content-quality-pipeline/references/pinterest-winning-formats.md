## The Winner: Collage Pins

**Data from Jared Bauman (Better Marketing):**
- **4 out of 5 outbound clicks** came from Collage Pins
- **42% higher CTR** than Text Overlay (TOBI)
- **28% higher CTR** than Pure Image pins
- Dominated all 3 metrics: Impressions, Saves, Outbound Clicks

## Pin Format Comparison

| Format | Structure | Best For | CTR Rank |
|--------|-----------|----------|----------|
| **Collage** | 2-5 images in grid, swipeable story | Products, tutorials, transformations, listicles | #1 ⭐ |
| **Text Overlay (TOBI)** | 60% image / 40% text overlay | Benefit-driven headlines, quick value | #2 |
| **Carousel** | 2-5 slides, swipeable | Step-by-step, before/during/after | #3 |
| **Idea Pin (Video)** | 9:16, 15-60 sec, native | Tutorials, transformations, personality | #4 |
| **Pure Image** | No text, lifestyle/hero shot | Brand awareness, aesthetic niches | #5 |

## Collage Pin Anatomy (Winning Formula)

```
┌─────────────────────────────────────┐
│  Hero Image (40%)                   │  ← Main result/lifestyle shot
├─────────────────────────────────────┤
│  Supporting Images (60%)            │  ← 2-4 smaller: process, details, alt angles
│  ┌─────────┬─────────┐               │
│  │ Img 1   │ Img 2   │               │
│  ├─────────┼─────────┤               │
│  │ Img 3   │ Img 4   │               │
│  └─────────┴─────────┘               │
├─────────────────────────────────────┤
│  Headline + CTA Button (bottom)     │  ← "Get the Guide" / "Shop the Look"
└─────────────────────────────────────┘
```

**Key specs:**
- Dimensions: 1000x1500px (2:3) — gold standard
- Text overlay: Max 30% of image area (algo preference)
- Headline: 15-20% of pin height
- CTA button: 8-10% of pin height, 28px border radius
- Font: Max 2 families (e.g., Montserrat Bold + Open Sans)

## Niche-Specific Winning Patterns

### Home Decor / DIY
- **Format**: Before/After split OR 4-image process grid
- **Colors**: Warm neutrals (terracotta, sage, cream) — Pinterest Predicts 2025 "Earth Tones Renaissance"
- **CTA**: "Save for Reno" / "Get Tutorial"

### Food / Recipes
- **Format**: Process collage (ingredients → steps → final hero)
- **Colors**: Bright natural lighting, food-accurate
- **CTA**: "Get Recipe" / "Save for Dinner"

### Fashion / Beauty
- **Format**: Outfit grid (3-4 pieces) OR flat lay + detail shots
- **Colors**: Seasonal palettes, muted coral + digital lavender (Gen Z)
- **CTA**: "Shop the Look" / "See Details"

### AI Tools / Tech (OUR NICHE)
- **Format**: Tool comparison grid (3-4 tools side by side)
- **Colors**: Midnight navy + champagne gold (luxury) OR teal/white (clean tech)
- **CTA**: "Compare Tools" / "Try Free"

### Finance / Arbitrage
- **Format**: Results collage (dashboard screenshot + payout proof + setup)
- **Colors**: Deep olive + terracotta + warm beige (trust + wealth)
- **CTA**: "See Setup" / "Get Config"

## Typography Hierarchy (From Case Studies)

| Element | Size | Weight | Font Pairing |
|---------|------|--------|--------------|
| Headline | 48-60px | Bold/ExtraBold | Montserrat / Oswald / Playfair Display |
| Subheadline | 24-28px | Medium/Regular | Open Sans / Lato / Roboto |
| Body (if any) | 18-20px | Regular | Same as subheadline |
| CTA Button | 18-20px | Bold | Same as headline |
| Hashtags | 14-16px | Regular | Muted color |

**Rules:**
- Max 2 font families per pin
- Line height: 1.2-1.4
- High contrast: WCAG AA (4.5:1) minimum
- Never script fonts for keywords/headlines (mobile unreadable)

## Production Workflow (Batch Creation)

```
1. KEYWORD RESEARCH (PinInspector / Pinterest Trends)
   → 50+ terms per niche, group by intent

2. TEMPLATE CREATION (Canva / Figma)
   → 5 master templates per niche
   → Brand kit: colors, fonts, logo placement, CTA zones
   → Safe zones: 100px from edges

3. IMAGE SOURCING
   → Hero: Bing DALL-E 3 (text-heavy) / Leonardo (people)
   → Supporting: Playground AI (batch) / Stock (Pexels)

4. BATCH PRODUCTION
   → 20 pins/session, 3x/week minimum
   → Swap images/text in templates
   → A/B test: TOBI vs Collage vs Carousel

5. SCHEDULING (Tailwind / native)
   → 5-10 pins/day (start slow, scale)
   → Peak: 8-10 PM, weekends

6. ANALYTICS & ITERATE
   → Track: Impressions → Saves → Clicks → Conversions
   → Double down on top 20% performers
   → Refresh: New pins for old winning URLs
```
