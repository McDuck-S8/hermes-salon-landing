# Web Studio Operations (Swarm-Inspired)

## Philosophy

Один developer керує всім pipeline. Як swarm: централізований orchestrator, спеціалізовані
"агенти" (ролі), паралельна робота без конфліктів.

## Open Swarm Mechanics (запозичено)

| Механіка OpenSwarm | Як застосовано в веб-студії |
|---|---|
| **Orchestrator** — єдина точка входу | Ти — orchestrator. Розподіляєш задачі між "агентами" |
| **Parallel agents** — одночасна робота | Пошук клієнтів + створення сайту + деплой можуть йти паралельно |
| **Git worktree isolation** — ізольовані гілки | Кожен клієнт = окрема гілка/папка |
| **Skills library** — централізовані навички | Скили Hermes: outreach, deployment, etc. |
| **Human-in-the-loop** — затвердження дій | Клієнт затверджує макет, текст, ціну до деплою |
| **Cost tracking** — відстеження витрат | Витрати на хостинг, домени, інструменти |

## Pipeline: 5 етапів

```
[1] Пошук → [2] Аутріч → [3] Сайт → [4] Деплой → [5] Підтримка
```

### Критерії відбору

1. Є хоча б сторінка в Instagram / Facebook

3. Немає сайту або сайт занедбаний (не оновлювався >1 року)
4. Працюють у радіусі 3 км від тебе (локальність)

## Етап 3: Створення сайту

### З існуючого (шаблони)

```
Папка: D:\Portable_Soft\hermes\cache\website-templates\
```

| Тип | Що є | Як використати |
|-----|-------|----------------|
| Fargo portfolio | Салон краси | Замінити фото + текст |
| Microsite base | Лендінг | Generic landing |
| HTML/CSS starter | Базовий | Будь-який сайт |

### Новий сайт (vibe-mode)

Принципи (з `vibe-mode` skill):
1. **Anti-slop** — унікальний візуальний язык на нішу
2. **Колірна палітра** — terra-cotta + olive + cream для салонів
3. **People first** — майстри > послуги
4. **CTA без тиску** — "записатися", не "купити"

### Процес створення

1. Дізнатися кольори/логотип клієнта
2. Вибрати шаблон (або створити новий)
3. Наповнити контентом (фото клієнта, його опис)
4. Показати клієнту — до 2 раундів правок
5. Затвердити → деплой

## Етап 4: Деплой та домени

### Free hosting

| Платформа | Підходить для | Обмеження |
|-----------|---------------|-----------|
| **GitHub Pages** | Статичні сайти | 1GB, 100GB/міс трафіку |
| **Cloudflare Pages** | Статичні сайти | 500 builds/міс |
| **Netlify** | Статичні сайти | 100GB/міс, 300 min build |
| **Vercel** | Статичні + SSR | 100GB/міс |
| **Render** | Статичні + бекенд | 500+ годин/міс |

### Paid hosting

| Платформа | Ціна | Коли потрібно |
|-----------|------|---------------|
| **Hostinger** | ~$3/міс | Початковий рівень |
| **Hetzner VPS** | ~$5/міс | Декілька сайтів |
| **DigitalOcean** | ~$6/міс | Бекенд + база даних |
| **AWS S3 + CloudFront** | ~$1-5/міс | Високий трафік |

### Домени

| Реєстратор | .com.ua | .ua | Інше |
|------------|---------|-----|------|
| **NIC.UA** | ~200 грн/рік | ~400 грн/рік | — |
| **Imena.UA** | ~180 грн/рік | ~350 грн/рік | .com ~$10 |
| **GigaHost** | ~190 грн/рік | — | .com ~$9 |
| **Porkbun** | — | — | .com ~$10, .net ~$12 |

### Вибір схеми деплою

```
Клієнт без бюджету:
  GitHub Pages + свій домен (або наш субдомен)
  → 0 грн/міс

Клієнт з малим бюджетом:
  Cloudflare Pages + .com.ua домен
  → ~200 грн/рік

Клієнт середній:
  Hostinger / Hetzner + .com.ua або .com домен
  → ~$5-10/міс

Свій сервер для всіх клієнтів:
  DigitalOcean / Hetzner VPS → $5-10/міс
  Nginx reverse proxy → кожен клієнт окремий порт або сервер
```

## Етап 5: Підтримка після угоди

### Що входить (базово)

| Послуга | Частота | Що робити |
|---------|---------|-----------|
| **Хостинг** | Щомісяця | Перевірка uptime, оновлення |
| **Домен** | Щороку | Продовження, підтвердження |
| **Резервне копіювання** | Щотижня | Копія файлів + бази |
| **Оновлення контенту** | За запитом | Додати фото, змінити текст |
| **Техпідтримка** | За запитом | Баги, поломки |

### Моделі підтримки

```
Базовий:  500 грн/міс — хостинг + бекапи + uptime моніторинг
Стандарт: 1000 грн/міс — базовий + 2 правки тексту/фото
Преміум:  2000 грн/міс — стандарт + SEO + нові сторінки
```

### Retention

- Чек-ін раз на 2 місяці: "як сайт працює? скільки заявок?"
- Пропонувати розширення: Instagram інтеграція, блог, відгуки
- Знижка на реферала: "приведи друга — місяць хостингу безкоштовно"
