# Crimea Market Analysis — Web Studio Segments

## Date: 2026-07-27

## Three Underserved Segments

### 1. Guest Houses / Mini-Hotels (ЮБК)
**Scale:** Hundreds of properties from Simeiz to Sudak
**Digital presence:** 80% without websites; rely on Avito + Instagram + word-of-mouth
**Need:** Landing page with room catalog, photo gallery, availability calendar, WhatsApp booking
**Revenue potential:** 5000-15000 RUB/season for site + maintenance
**Competition with proper sites:** <20%

### 2. Wineries / Craft Producers
**Scale:** Growing craft boom — wine, cheese, essential oils, handmade soap, ceramics
**Digital presence:** Instagram only, no e-commerce, no brand story
**Need:** Brand site + catalog + tasting booking + online store
**Revenue potential:** 3000-10000 RUB/month
**Competition with proper sites:** <15%

### 3. Adventure Tourism / Excursions
**Scale:** ATVs, horseback riding, diving, boat tours, jeep tours, paragliding
**Digital presence:** Instagram + WhatsApp only; no route catalog, no online booking
**Need:** Tour catalog + pricing + calendar + safety info + online booking
**Revenue potential:** 2000-5000 RUB/season (lower but simpler)
**Competition with proper sites:** <10%

## Recommendation
Start with Guest Houses — highest volume, lowest competition, Fargo template adaptable.
