# Анализ Крыма: 3 неохваченных сегмента

Дата: 2026-07-27
Контекст: Поиск сегментов рынка для веб-студии в Крыму

## Сегмент 1: 🏡 Гостевые дома / мини-отели ЮБК

**Кто:** частные mini-hotels, guest houses, "комнаты посуточно" от Симеиза до Судака
**Сколько:** сотни объектов, 80% без своих сайтов
**Чем живут:** Avito + Instagram + сарафан
**Проблема:**
- Нет возможности забронировать напрямую (только звонок)
- Нет фотогалереи с номерами
- Нет онлайн-календаря занятости
- Зависят от агрегаторов (Booking, Avito) — комиссия до 20%

**Что нужно:** Лендинг с номерами + цены, фотогалерея, календарь "СВОБОДНО/ЗАНЯТО", WhatsApp/Telegram бронь, отзывы
**💰 Готовы платить:** 5000-15000 рублей/сезон
**🔥 Конкурентов с нормальными сайтами:** <20%

## Сегмент 2: 🍷 Винодельни / крафтовое производство

**Кто:** частные винодельни, сыроварни, производители эфирных масел, мыла ручной работы, керамисты
**Где:** Бахчисарайский р-н, Севастополь, Алушта, Солнечная Долина
**Проблема:**
- Нет интернет-магазина
- Нет истории бренда
- Нет каталога продукции
- Винодельни: нет онлайн-брони дегустаций

**Что нужно:** Сайт-витрина с историей, каталог продукции + цены, интеграция с Instagram, доставка, бронь дегустаций
**💰 Готовы платить:** 3000-10000 руб/мес за интернет-магазин
**🔥 Конкурентов с нормальными сайтами:** <15%

## Сегмент 3: 🏍️ Активный отдых / экскурсии

**Кто:** квадроциклы, конные прогулки, дайвинг-центры, морские прогулки, джип-туры, параплан
**Где:** Ай-Петри, Балаклава, Коктебель, Новый Свет, мыс Тарханкут
**Проблема:**
- Instagram + WhatsApp = единственный канал
- Нет каталога маршрутов
- Нет онлайн-брони
- Нет цен (все "уточняйте")

**Что нужно:** Сайт-каталог маршрутов с ценами, календарь бронирования, фото/видео, отзывы, погода
**💰 Готовы платить:** 2000-5000 руб/сезон за базовый сайт
**🔥 Конкурентов с нормальными сайтами:** <10%
