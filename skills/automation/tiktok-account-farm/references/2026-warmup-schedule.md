# TikTok Account Warmup — 2026 Day-by-Day Scheme

Source: 360Uniquizer (March 2026), PROXIES.SX, Undetectable.io
Compiled: 2026-07-21

---

## Infrastructure Before Warmup

**Proxies:** Mobile (4G/5G) or residential ONLY. VPN doesn't work — TikTok detects VPN IP ranges instantly and bans the account. One proxy = one account.

**Device:** Real Android, GeeLark cloud phone, or iOS. Anti-detect browsers FAIL on TikTok (see SKILL.md warning).

**Timeline:** New reg = 10-14 days warmup. Purchased with history = 5-7 days.

## 14-Day Warmup Scheme

| Day | Actions | Limits | Notes |
|-----|---------|--------|-------|
| **1** | Register, 20-30 min FYP scroll | 0 likes/follows/comments | Just watch. Build behavioral baseline. |
| **2** | Scroll + occasional likes | 15-20 likes, 0 follows | Like 2-3/min, not faster. |
| **3-4** | Likes + follows + 1-2 comments | 30 likes, 5-10 follows, 1-2 comments | Comments: neutral ("cool", "nice"). |
| **5-6** | **First video** (neutral topic) + engagement | 40 likes, 10-15 follows, 3-5 comments | Video NOT about offer. Entertainment/educational. |
| **7** | **Test video** (close to offer creative) | 1 video | First hint at the niche. |
| **8-10** | 2-3 videos/day, ramp up engagement | 50 likes, 15-20 follows | Mix: 70% neutral / 30% targeted. |
| **11-14** | **Bio link** — only after 1000 followers | Full load | If followers < 1000, link on day 12-14 still OK. |

## Critical Mistakes (Burn the Network)

| Mistake | Why | Fix |
|---------|-----|-----|
| VPN instead of proxy | TikTok bans VPN IPs instantly | Use mobile 4G/5G proxy |
| Identical warmup across network | Anti-fraud builds cluster graph | Each account needs unique pattern |
| Same neutral video on all accounts | TikTok links accounts by content | Use 360° Uniquizer to generate variants |
| Abrupt switch neutral→offer | Algorithm flags the shift | Gradient: 70%→50%→30% neutral over 7 days |
| Bio link on day 1 | Shadowban until 1000+ followers | Wait for day 11-14 |
| Launching all accounts at once | Correlated creation pattern detected | Batch 5-10 accounts with 2-3 day gaps |

## Warmup Mistakes That Kill Reach (from 360Uniquizer)

1. **No behavioral history** — new account with zero history gets zero reach from day one
2. **Skipping warmup** — uploading without warmup simply doesn't work
3. **Non-unique content** — at scale, everyone uses same warmup videos; platform links accounts based on this
4. **All accounts on same schedule** — anti-fraud detects coordinated behavior
5. **Too fast, too early** — don't ramp likes/comments from 0 to 50 in one day

## 3-Layer Protection Stack

```
Layer 1: Mobile Proxy (4G/5G)
  - Real carrier IP, trusted by TikTok
  - 94%+ success rate vs <30% for datacenter
  - One proxy = one account (or 1:3 account:port ratio)

Layer 2: Real Device / Cloud Phone
  - GeeLark, real Android, or iOS
  - NOT anti-detect browser (they fail on device-level checks)
  - Produces genuine sensor data, touch curves, OS identifiers

Layer 3: Behavioral Uniqueness
  - Different scroll speeds, different engagement times
  - Varied content consumption patterns per account
  - No two accounts post at the same time
```

## Detection Signals (When TikTok Is Watching)

- **Repeated CAPTCHA** — soft block; reduce activity for 24h
- **Zero views on post (2+ hours)** — shadowban; switch IP, reduce frequency
- **Account check/CVV required** — suspicious login from flagged IP
- **Message: "You're doing this too much"** — rate limit hit; 24h pause
- **Message: "This account was banned"** — hard ban; device fingerprint is compromised
