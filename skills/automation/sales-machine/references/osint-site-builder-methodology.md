# OSINT Site Builder Methodology (learned 2026-07-22)

Користувач описав 3-фазний процес створення сайту з Telegram-каналу бізнесу.

## Фаза 1: OSINT — збір інформації

Аналізуємо канал бізнесу та збираємо:

### Базові дані
- Назва бізнесу, сфера, адреса (місто, вулиця)
- Телефон, email, посилання на соцмережі
- Графік роботи (якщо вказано)

### Послуги та ціни
- Назва кожної послуги
- Ціна (якщо вказана)
- Опис з постів
- Акції та спецпропозиції

### Візуал
- Фото інтер'єру, робіт (до/після), майстрів
- Логотип (якщо є)

### Відгуки та довіра
- Коментарі клієнтів
- Репости відгуків

### Позиціонування
- Як бізнес себе подає
- УТП (якщо сформульовано)
- Чим відрізняється від конкурентів

## Фаза 2: Генерація сайту

На основі зібраних даних створюємо landing page, використовуючи підходящий шаблон:

- **Салон краси** → `salon-lumiere-builder` або `demo_builder.py` (niche='salon')
- **Медичний/косметолог** → чистий медичний дизайн (білий + бірюзовий, без прикрас)
- **Інше** → `demo_builder.py` або кастомний HTML

### Обов'язкові елементи сайту:
- Hero з назвою та фото
- Послуги та ціни
- Фото (реальні з каналу, не стоки)
- Контакти (Telegram, телефон, карта)
- Форма запису (посилання на Telegram або телефон)
- Відгуки (якщо знайдені)
- WCAG 2.1 AA

### Правило стилю:
- Не мішати стилі різних ніш
- Для медицини — білий + бірюзовий, мінімум емодзі
- Не використовувати "золото" для медичних проєктів

## Фаза 3: Звіт

Створити `reports/osint_report_[назва].md` з розділами: що знайшли, чого не знайшли, посилання, покращення.

## Потік роботи
1. Отримуємо Telegram-канал
2. Фаза 1 → показуємо користувачу
3. Чекаємо рішення
4. Якщо генерувати → Фаза 2 + Quality Gate → deploy
5. Фаза 3: звіт

## Важливо
- Канал = ОКРЕМИЙ проєкт. Не змішувати.
- Не додумувати дані. Якщо немає → ❌ в звіті.
