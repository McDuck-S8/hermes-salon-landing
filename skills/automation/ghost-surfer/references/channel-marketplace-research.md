## Verification Checklist Before Buying

- [ ] **Stats screenshots** (Combot/Telemetr) — last 30 days
- [ ] **ER (Engagement Rate)** — views/subs ≥ 15% for niche, ≥ 5% for general
- [ ] **No bots** — check viewer overlap, comment quality
- [ ] **Post frequency** — regular posting history
- [ ] **No shadowban** — forward a post, check if views drop
- [ ] **Transfer method** — admin rights transfer, not "invite link only"
- [ ] **History** — channel age, previous owners, ban history
- [ ] **Niche match** — audience matches your offer (India cricket betting ≠ Russia crypto)

## Red Flags
- Seller refuses Combot/Telemetr link
- Sudden subscriber spikes (bought bots)
- All posts from last week only (farmed)
- "Invite link only" transfer (you can't remove old owner)
- Price too low for niche (e.g., 10k betting subs for $30)

## Safe Deal Process (Telega.in / EpicStars)

1. Seller lists channel with verified stats
2. Buyer pays to platform escrow (USDT TRC20/ERC20)
3. Platform verifies admin transfer (bot checks)
4. Buyer confirms access → funds released
5. Platform takes 10-15% commission
