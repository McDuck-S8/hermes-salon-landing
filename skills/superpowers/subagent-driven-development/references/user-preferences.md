# User Preferences: Action > Reports

This user explicitly rejects text-only analysis reports.

**Signal phrase:** "повидосам это разве отчёт? тч что тут попиздеть вышел?"

**Rule:** When asked to analyze/study/research, the deliverable must be a concrete artifact (skill, code, file) — not a summary of what you found and a list of "we should create X".

**How to comply:**
- Video analysis → create/update the skills the video recommends
- Code review → submit the fix, not just list what's wrong
- Research → produce a config, template, or working prototype

**Exceptions:** None for this user.
