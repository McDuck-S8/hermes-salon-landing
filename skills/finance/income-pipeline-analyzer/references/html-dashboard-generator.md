# HTML Dashboard Generator Reference

Generated by `scripts/generate_dashboard.py` → `reports/income_pipeline_dashboard.html`

## Purpose

Standalone HTML dashboard with Chart.js visualizations that works offline in any browser via `file://` protocol. No GitHub, no Mermaid renderer, no internet required (Chart.js bundled locally).

## Usage

```bash
# Generate dashboard
python scripts/generate_dashboard.py
# Output: reports/income_pipeline_dashboard.html

# Open in browser
start reports/income_pipeline_dashboard.html    # Windows
open reports/income_pipeline_dashboard.html     # macOS
xdg-open reports/income_pipeline_dashboard.html # Linux
```

## Chart.js Integration

**Local Chart.js (no CDN):**
- Downloaded to `scripts/chart.umd.min.js` (205 KB)
- Referenced in HTML as `<script src="../scripts/chart.umd.min.js"></script>`
- Works on `file://` protocol — no CORS issues

## Dashboard Components

### 1. Pie Chart — Scheme Statuses
- **Data:** UNVERIFIED, TESTING, VERIFIED, Code-unblockable
- **Colors:** Red/Yellow/Green/Blue (matching Mermaid)
- **Tooltip:** Shows count + percentage

### 2. Horizontal Bar Chart — Blocker Distribution
- **Data:** Blocker type vs count of UNVERIFIED schemes
- **Colors:** Blue = code-fixable (LANDING_PAGE, VIDEO_SCRIPT, BOT), Gray = user-action (AD_BUDGET, MANUAL_ACCOUNT, API_KEY)
- **Index axis:** Y (horizontal bars)
- **Tooltip:** "Схем: N"

### 3. Table — Top-10 Code-Unblockable Schemes
| Columns |
|---------|
| # |
| Схема (name) |
| Статус (color badge) |
| Блокеры (comma-separated) |
| Что разблокирует код (script names) |
| Действие |

### 4. Refresh Mechanism
- **Button:** "🔄 Обновить данные" → `location.reload()`
- **Keyboard:** `R` key → reload
- **Workflow:** Run generator → F5 (or click button)

## Data Flow

```
ARBITRAGE_BONDS.md
       ↓
scripts/generate_dashboard.py (parse + embed JSON)
       ↓
reports/income_pipeline_dashboard.html (self-contained)
       ↓
Browser (file://) → Chart.js renders → Interactive charts
```

## Customization

Edit `scripts/generate_dashboard.py`:
- `blocker_labels` — rename blocker types
- `status_colors` — change color scheme
- `top10` logic — change which schemes appear in table
- Chart options (responsive, maintainAspectRatio, tooltips)

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Charts don't render | Check `scripts/chart.umd.min.js` exists (205 KB) |
| Blank canvas | Browser console: Chart loaded? DOMContentLoaded fired? |
| File won't open | Use `file:///D:/Portable_Soft/hermes/reports/income_pipeline_dashboard.html` |
| Data stale | Re-run generator, then refresh browser |
