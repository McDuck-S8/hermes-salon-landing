# Flow Visualization Reference

Generated by `scripts/generate_flowchart.py` → `reports/income_pipeline_flow.html`

## Purpose

Standalone HTML visualization of the complete 50-scheme income pipeline as a left-to-right flow diagram. Uses Mermaid.js via CDN — renders directly in browser, no build step.

## Usage

```bash
# Generate flow visualization
python scripts/generate_flowchart.py
# Output: reports/income_pipeline_flow.html

# Open in browser
start reports/income_pipeline_flow.html    # Windows
open reports/income_pipeline_flow.html     # macOS
xdg-open reports/income_pipeline_flow.html # Linux
```

## Data Flow

```
ARBITRAGE_BONDS.md
       ↓
scripts/generate_flowchart.py (parse + group + embed mermaid)
       ↓
reports/income_pipeline_flow.html (self-contained HTML + CDN mermaid)
       ↓
Browser (file://) → mermaid.js renders → Interactive SVG
```

## Customization

Edit `scripts/generate_flowchart.py`:
- `MERMAID_CODE` string — modify groups, nodes, edges, styles
- Group definitions — add/remove source/proxy/offer/withdrawal categories
- Color scheme — `classDef` definitions at top
- Main pipeline nodes — `SRC`, `PRX`, `OFF`, `WDR` styling

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Diagram doesn't render | Check internet (CDN), browser console for mermaid errors |
| Too wide/overflows | Click 🔍 "Подогнать под экран" or pan/zoom |
| Nodes overlap | Increase `nodeSpacing` / `rankSpacing` in mermaid init |
| Want offline | Download mermaid.min.js locally, reference in HTML |
