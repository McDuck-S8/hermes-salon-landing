# Crypto → Fiat Offramp

Подключается **только когда понадобились живые деньги**. В обычном режиме весь цикл идёт в USDT.

## Когда нужен этот навык

- Нужно оплатить что-то, что не принимает крипту
- Нужно вывести прибыль в RUB
- Налоги/отчётность

## Методы вывода USDT → RUB

### 1. P2P-биржи (KuCoin, Bybit, HTX, OKX)
**Схема:** Продажа USDT → продавец кидает RUB на карту/счёт

- **KuCoin P2P** — вывод на T-Банк (по реквизитам счёта, а не на карту — меньше рисков)
- **Bybit P2P** — высокая ликвидность, вывод на Сбер/Т-Банк
- **HTX P2P** — можно продавать без верификации

**Риски:** 115-ФЗ (блокировка карты если контрагент серый). Снижение: вывод на счёт, а не карту; лимит до 100K/операция; разные банки.

### 2. BestChange (обменники)
**Схема:** USDT → обменник → RUB на карту
- Комиссия 3-5%
- Не флажится банками (обменники легальные)
- Многие обменники не проверяют регион карты
- **Минус:** курс хуже P2P

### 3. Крипто-карты
- **Bybit Card** — USDT → карта → траты, конвертация при оплате
- **Bitget Card**
- **НО:** большинство не работает на Крым (IP/адрес проверка). Вариант: заказать на адрес в РФ, получать через друзей.

### 4. Белорусский/зарубежный мост
- **Whitebird BY** — KYC, до $12K, перевод на любую карту
- **Advcash** — верификация РФ, карта Advcash → вывод на любую

## Рекомендация для Крыма

```
USDT → KuCoin P2P → T-Банк (счёт, не карта) → расходы
```

Или **BestChange** без рисков — дороже, но надёжнее.

## Когда НЕ нужен

Если все расходы (PWA.Market, прокси, аккаунты, VPS) оплачиваются USDT напрямую — этот навык не используется. Возвращаться только при реальной потребности в фиате.
