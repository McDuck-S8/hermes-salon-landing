## Critical Pivot: CPA Registration CANNOT Be Automated

**Discovered 2026-06-28:** CPA networks (Admitad, EduGram, EPN, etc.) require:
- Email verification (real inbox)
- Phone verification (SMS)
- Manual approval by network manager (1-3 business days)
- Traffic source description + audience stats

**Therefore:** Cannot set up CPA monetization in single session. Pipeline is:
1. User registers manually (email + phone)
2. User gets approved (1-3 days)
3. THEN agent can use CPA links in posts
