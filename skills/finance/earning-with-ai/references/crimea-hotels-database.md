# Crimea Hotels Database — Real Hotel Contacts

## How to Build Hotel Database

### Data Sources
1. **2GIS** — most reliable for Russian businesses
2. **Yandex Maps** — good for Crimea
3. **Google Maps** — international chains
4. **Booking.com** — verified hotels
5. **Avito** — guest houses, mini-hotels

### Search Strategy
```
Query patterns:
- "отели Ялта телефон"
- "гостиницы Симферополя контакты"
- "гостевые дома Алушты бронирование"
- site:2gis.com Ялта отель
```

### Target Segments (Best Clients)
1. **Mini-hotels** (10-30 rooms) — highest conversion
2. **Guest houses** — price-sensitive, easy to sell
3. **Sanatoriums** — medium difficulty
4. **Large hotels** (100+ rooms) — hard, long sales cycle

### Price Segments
- Economy (1500-2500₽/night): 5 hotels
- Mid-range (2500-5000₽/night): 7 hotels
- Premium (5000-10000₽/night): 5 hotels
- Luxury (10000₽+): 3 hotels
