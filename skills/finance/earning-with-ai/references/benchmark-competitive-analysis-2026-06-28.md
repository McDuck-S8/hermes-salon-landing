# Benchmark & Competitive Analysis Pattern

## When to Use
Before offering ANY service or product, run this analysis. Prevents "rushing to sell without research" mistake.

## Pattern (5 Steps)

### 1. Collect 50 References (not 5, not 10)
- 10 niches × 5 sites each = 50
- Sources: behance.net, dribbble.com, awwards.com, cssdesignawards.com
- Google: "best [niche] website design 2025"

### 2. Analyze Each Reference (7 Dimensions)
| Dimension | What to Check |
|-----------|---------------|
| Structure | Pages, navigation, funnel |
| Design | Colors, typography, spacing, balance |
| USP | What it sells, how it positions |
| Mobile | Responsiveness, speed |
| Conversion | CTA, forms, buttons, trust |
| Technology | CMS, framework, load speed |
| Rating | 1-10 score |

### 3. Create Benchmark Table (25+ Competitors)
For each competitor document:
- Features offered
- Pricing (entry, mid, enterprise)
- Strengths / Weaknesses
- What they do well / lack

### 4. Identify Gaps
- Where are competitors weak?
- What do customers complain about?
- What's missing in the market?
- Where can we be 10x better?

### 5. Create Competitive Offering
- Position: where we fit vs competitors (price vs features)
- USP: what makes us different
- Pricing: based on market data (not arbitrary)
- Services: what we can ACTUALLY deliver

## Anti-Patterns
- Landing page without research = wish, not business
- Selling what doesn't exist = embarrassing
- One-dimensional research = blind spots

## Correct Pattern
RESEARCH → BENCHMARK → IMPROVE → VALIDATE → OFFER → REVENUE

## Validation Checklist
- [ ] 50+ references collected
- [ ] 25+ competitors documented
- [ ] Pricing based on market data
- [ ] Competitive advantage identified
- [ ] Quality proof exists (working demos)
- [ ] USP clearly articulated
