# Frontend Design Methodology (из Anthropic skills)

Источник: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md

## Ground it in the subject

Назови: (1) конкретный предмет, (2) его аудиторию, (3) единственную задачу страницы. 
Визуальный язык берётся из мира предмета — его материалов, инструментов, артефактов, среды.

## Процесс: два прохода

1. **Первый проход** — токен-система (4–6 hex-цветов, 2+ гарнитуры, концепт лейаута, signature-элемент)
2. **Рецензия** — проверь что это решение не шаблонное (прогони через тест: "выдал бы я то же самое для любой похожей задачи?")
3. **Сборка** — строго по плану, каждый цвет/шрифт из токенов

## Принципы

- **Hero — это тезис.** Открывай самым характерным элементом предмета. Большая цифра + маленькая подпись + градиент — шаблон, используй только если это реально лучший вариант.
- **Typography carries personality.** Пара display и body осознанно, не те же гарнитуры что в прошлом проекте.
- **Structure is information.** Нумерация (01/02/03) уместна ТОЛЬКО если контент реально последователен — процесс, таймлайн.
- **Motion — осознанно.** Один orchestrated moment лучше россыпи эффектов. Иногда меньше = больше.
- **Complexity = vision.** Максимализм требует elaborate исполнения. Минимализм — точности в spacing, type, detail.
- **Copy — материал дизайна.** Не заполняй рыбой. Слова в дизайне для понимания, не для декора.

## AI-шаблоны (обходить)

Три доминирующих AI-шаблона:
1. Тёплый кремовый фон (#F4F1EA) + контрастный серифный display + терракотовый акцент
2. Почти-чёрный фон + яркий кислотно-зелёный или вермилион акцент (**мой шаблон!**)
3. Broadsheet-вёрстка: hairline rules, нулевой border-radius, газетные колонки

Все три легитимны для некоторых брифингов, но они должны быть ВЫБОРОМ, не дефолтом.

## Один смелый ход

Потрать boldness в одном месте. Signature-элемент — единственная запоминающаяся вещь. Всё остальное — тихо и дисциплинированно. "Перед выходом сними один аксессуар."

## A/B тест вариантов

По дефолту — минимум 3 варианта:
1. Conservative — ближе всего к существующим паттернам
2. Strong-fit — лучшая интерпретация брифа
3. Divergent — неожиданное решение для поиска границ вкуса

Варианты должны отличаться по layout, иерархии, типу, плотности, цвету — НЕ только цветом.
