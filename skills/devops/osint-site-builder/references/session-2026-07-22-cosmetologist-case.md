## Техніка добування фото з Telegram каналу (застосовано)

1. Відкрити пост: `t.me/alliccenncosmm/POST_ID?embed=1`
2. Знайти `a[style*="background-image"]` — це контейнери фото
3. Витягнути `url(...)` з background-image — це full-size JPG
4. Завантажити через Python `urllib.request` з User-Agent
5. Результат: 5 фото з каналу (46559-144507 байт)

Не всі JPG URL працюють — деякі 404. Пробувати інші пости.
