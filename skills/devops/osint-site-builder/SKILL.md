# OSINT Site Builder

## Призначення
З Telegram-каналу бізнеса — в готовий сайт. Без питань до клієнта, без зайвих ітерацій.

## Загальне правило
**Старпом не кодить.** Фазу 2 (генерацію сайту) делегувати саб-агенту через `delegate_task`.
Фазу 1 (OSINT) робити самому — це аналітика. Quality Gate перед показом.

---

## Фаза 1: OSINT — збір інформації

Джерело: Telegram-канал. Парсити:
1. Опис каналу (назва, сфера, контакти, локація)
2. Закріплені повідомлення
3. Стрічка постів (останні 15-20)
4. Медіа (фото, відео) — якщо доступні

### Що зібрати в таблицю:

**База:**
- Назва бізнесу
- Сфера (салон, кафе, автосервіс, косметолог...)
- Адреса, телефон, email, соцмережі
- Графік роботи

**Послуги та ціни (з постів):**
- Назва послуги
- Ціна (якщо є)
- Опис з тексту

**Медіа:**
- Фото майстрів/команди
- Фото робіт (до/після)
- Фото інтер'єру

**Маркетинг:**
- Акції та спецпропозиції
- Тактики (дефіцит, знижки, терміновість)

**Пробіли:**
- Чого не вистачає (ціни, адреса, графік, фото)
- Що треба уточнити у клієнта

### Формат звіту

Зберегти в `reports/osint_report_[назва].md` з таблицями.

## Фаза 2: Генерація сайту

На основі зібраних даних створити landing page.

### Вибір шаблону за сферою:

| Сфера | Шаблон |
|---|---|
| Салон краси | `salon-lumiere-builder` або `demo_builder.py` (salon) |
| Косметолог/медицина | Медичний преміум (білий + бірюзовий/зелений) |
| Кафе/ресторан | `demo_builder.py` (restaurant) |
| Готель | `demo_builder.py` (hotel) |
| Автосервіс | `demo_builder.py` (auto_service) |
| Інше | `demo_builder.py` (універсальний) |

### Обов'язкові секції:
1. Hero з назвою + фото/відео
2. Послуги та ціни (з OSINT)
3. Фото робіт (якщо є — реальні, не stock)
4. Про майстра/команду
5. Контакти + карта (якщо є адреса)
6. Форма/кнопка запису (Telegram, телефон)

### WCAG — обов'язково:
- Skip link
- focus-visible
- aria-hidden на емодзі
- for/id на формі
- role-атрибути (banner, navigation, main, contentinfo)
- Alt тексти до всіх зображень (описові, мовою сайту)
- WCAG бейдж у футері

### Hero — 2 колонки (learned 2026-07-22)
- Ліва колонка: текст (назва, опис, кнопки, бейджі)
- Права колонка: фото майстра/команди
- `.hero-left{padding:0 48px}` (не тільки padding-right)
- `.hero-right img` — НЕ absolute, в потоці (щоб не вилазило за краї)

### Фото в каруселі — 3 в ряд (learned 2026-07-22)
- `.carousel-slide{min-width:33.333%}` — 3 фото
- `aspect-ratio:4/5`, `max-height:450px`
- Безкінечне листування: cloneNode + transitionend
- `display:flex;align-items:center` на slide для центрування

### Відгуки — карусель, 2 в ряд (learned 2026-07-22)
- `#reviewTrack .carousel-slide{min-width:50%}`
- aspect-ratio:auto (текст, не фото)

### Контакти — без дублів (learned 2026-07-22)
- НЕ додавати "Мій канал" посилання
- НЕ додавати синій `.contact-telegram` блок
- Тільки: текст + велика кнопка + локація

### Фото:
- Майстра — копіювати в `assets/` поруч з index.html
- Before/after — якщо є в каналі, скачати через браузер або попросити клієнта
- Якщо немає — заглушка з описом "(добавьте фото)"

## Жорстке правило: не видаляти контент без питання (learned 2026-07-22)

Якщо на сайті (в Telegram-каналі) вже є якийсь контент — соціальна кнопка, посилання, телефон, іконка — **не видаляти його**, навіть якщо виглядає зламаним. "Якщо воно там було — значить була причина". Запитати у клієнта перед видаленням.

Замість видалення: виправити href/посилання, але елемент залишити.
