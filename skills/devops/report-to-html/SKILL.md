# Report → HTML Converter

Конвертирует `.md` файлы в HTML-страницы с тёмной темой GitHub-стиля.

## Использование

```bash
python scripts/md2html.py <input.md> [output.html] [--charts]
```

- `--charts` — подключает Chart.js и парсит `` ```chart `` блоки
- Если `output.html` не указан — создаётся рядом с `.md`

## Графики (Chart.js)

В `.md` внутри `` ```chart `` блока пиши:

```
```chart
type: bar          # bar, pie, doughnut, line, radar
label: Название
- Метка1: 30
- Метка2: 50
- Метка3: 20
```
```

Типы: `bar`, `pie`, `doughnut`, `line`, `radar`.

## Круги Эйлера (Venn)

```
```venn
Actionable: 96
Blocked: 25
Both: 10
```
```

- Первые строки **без маркеров** = основные множества (до 3)
- Строки, начинающиеся с `Both`, `All`, `And`, `Overlap`, `∩` = пересечение
- Рендерятся как инлайн SVG, без внешних зависимостей

## Синтаксис разметки

| Элемент | Как пишется |
|---------|-------------|
| Заголовки | `# h1`, `## h2`, `### h3` |
| Жирный | `**текст**` |
| Курсив | `*текст*` |
| Код | `` `code` `` |
| Ссылки | `[текст](url)` |
| Таблицы | `\| a \| b \|` |
| Код-блок | ```` ```python ```` |
| Цитаты | `> текст` |
| Списки | `- item` / `1. item` |

## Скрипт

`scripts/md2html.py` — чистый Python, без внешних зависимостей (кроме Chart.js CDN при `--charts`).
