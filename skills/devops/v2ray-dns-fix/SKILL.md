# V2Ray DNS Fix

## Когда загружать
Когда пользователь жалуется что прокси/V2RayN не работает из-за DNS.

## Что делать

1. Сказать пользователю заменить DNS в V2RayN на нейтральные:

```json
{
  "hosts": {},
  "servers": [
    "94.140.14.14",
    "94.140.15.15",
    "9.9.9.9",
    "149.112.112.112"
  ]
}
```

2. Пояснити: AdGuard DNS (Кипр, без логування) + Quad9 (Швейцарія, блокує шкідливі сайти). Ні РФ, ні Google.

## Альтернативні варіанти

### Максимальна анонімність:
```json
{
  "hosts": {},
  "servers": [
    "84.200.69.80",
    "84.200.70.40",
    "185.43.135.1",
    "193.17.47.1"
  ]
}
```

### Через DoH (для обходу блокувань):
```json
{
  "hosts": {},
  "servers": [
    "https://dns.quad9.net/dns-query",
    "https://dns.adguard.com/dns-query"
  ]
}
```

- Google DNS (8.8.8.8) — логує, США
- Яндекс DNS (77.88.8.8) — під контролем РФ
