# 13 Lessons from Fargo + Cosmetologist Project (2026-07-22)

## 1. Check file path before editing
User had `index.trend.html` open, I edited `index.html`. Fixes didn't apply.
**Rule:** Before any edit, read the URL/file:// path the user shows. Edit THAT file.

## 2. Never remove content without asking
Deleted Viber link because href="#". User: "if it was there, there was a reason".
**Rule:** Don't delete content even if broken. Fix the href, keep the element. Ask first.

## 3. WCAG from start, not later
Skip-link, focus-visible, aria-hidden, for/id, role=banner/main/contentinfo should be in the BASE template, not added as an afterthought.
**Rule:** WCAG in first commit, not retroactively.

## 4. Verify photos visually before inserting
Took Pexels IDs on faith. "Haircut" photo wasn't a haircut, "Makeup" was a bird.
**Rule:** Before inserting an image URL, open it in the browser to confirm it shows the right content.

## 5. Don't duplicate sections
Had "Services" (with prices) AND separate "Prices" section. Duplicate.
**Rule:** Either services-with-prices OR a price section. Not both.

## 6. Carousel: 3 visible + seamless loop
Built 1-photo-fullscreen carousel that jumped to start. User: "25 years ago".
**Rule:** `min-width:33.333%` for 3 visible, cloneNode + transitionend for infinite seamless loop.

## 7. Header CTA button must be prominent
Button was plain teal, no shadow, no emoji. Blended into background.
**Rule:** `✉️ + box-shadow + font-weight:600` on header CTA buttons. Must pop.

## 8. Contacts: minimum duplicates
Had "Telegram" + "Мой канал" + "Написать в Telegram" — 3 ways to same thing.
**Rule:** One contact handle + one big button. No triple redundancy.

## 9. Quality Gate before presenting
Never ran qa_check.py before saying "done". User found bugs every time.
**Rule:** Always run quality-gate BEFORE the final "done" message.

## 10. Delegate, don't code directly
I'm first mate, not coder. Kept editing files directly.
**Rule:** task → subagent (delegate_task) → quality-gate → present.

## 11. .nojekyll on gh-pages deploy
Without .nojekyll, GitHub Pages 404s on new directories or serves stale content.
**Rule:** `touch .nojekyll && git add .nojekyll` on every gh-pages deploy.

## 12. Use notebooklm-py for research
Installed but never invoked. User explicitly told me to use it.
**Rule:** Research task = notebooklm-py first, or delegate_task with web_search.

## 13. Menu order = section order
Menu had "Услуги, Отзывы, Обо мне, Результаты..." but sections were in different order.
**Rule:** Nav links sequence must match page section sequence 1:1.

## Protocol (new, post-session)
Before ANY task:
1. Load `using-superpowers`
2. Load `brainstorming` (if task > 5 min)
3. Load `writing-plans` (if implementation needed)
4. Delegate coding to subagent via `delegate_task`
5. Run `quality-gate` before presenting
6. Save lessons to memory/skills
