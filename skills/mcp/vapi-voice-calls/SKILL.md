# VapiAI MCP Server — Голосовые AI-звонки

## Что это

VapiAI — это платформа для создания AI-ассистентов, которые могут совершать и принимать голосовые звонки. MCP-сервер позволяет интегрировать VapiAI в Hermes Agent для автоматизации телефонных взаимодействий.

## Возможности

- **Автоматические звонки клиентам** — AI-ассистент звонит клиенту и выполняет задачу (напоминание, запись, опрос)
- **Приём входящих звонков** — AI отвечает на звонки клиентов и обрабатывает запросы
- **Настраиваемые сценарии** — скрипты для салонов красоты, лидогенерации,售后服务
- **Логирование и аналитика** — запись звонков, транскрипция, метрики

## Использование

### Салон красоты — напоминание о записи

AI звонит клиенту за день до визита, напоминает о записи и уточняет детали:

```
Задача: Позвонить клиенту Анне (тел: +79001234567) и напомнить о записи на стрижку завтра в 15:00. Если она не может — перенести на другой день.
```

### Лидогенерация — холодный звонок

AI совершает холодный звонок потенциальному клиенту, представляет продукт и квалифицирует лид:

```
Задача: Позвонить Ивану (тел: +79009876543), представиться от имени компании «ТехноПлюс», узнать, интересует ли его наше предложение по ERP-системам. Записать ответ в CRM.
```

### Опрос клиентов

AI звонит клиентам после оказания услуги и проводит короткий опрос:

```
Задача: Позвонить 10 клиентам из списка и провести опрос удовлетворённости. Записать ответы в таблицу.
```

## Установка

### 1. Регистрация на VapiAI

1. Зайдите на [vapi.ai](https://vapi.ai)
2. Создайте аккаунт и получите API-ключ (Dashboard → API Keys)
3. Создайте ассистента (Assistant → Create Assistant)
4. Настройте сценарий (Script) и голос (Voice)

### 2. Установка MCP-сервера

```bash
npm install -g @anthropic/vapi-mcp-server
```

Или через uv/pip (если доступен Python-вариант):

```bash
pip install vapi-mcp-server
```

### 3. Конфигурация в Hermes

Добавьте в `config.yaml`:

```yaml
mcp_servers:
  vapi:
    command: npx
    args: ["-y", "@anthropic/vapi-mcp-server"]
    env:
      VAPI_API_KEY: "your-vapi-api-key"
```

### 4. Создание ассистента

В консоли VapiAI создайте ассистента с нужным скриптом:

- **Salon Assistant**: скрипт для напоминаний о записях, работы с календарём
- **Lead Caller**: скрипт для холодных звонков, квалификации лидов
- **Survey Agent**: скрипт для проведения опросов

## Интеграция с Hermes

### Звонок через MCP-инструмент

```python
# Пример вызова через MCP
result = mcp_vapi.make_call(
    phone_number="+79001234567",
    assistant_id="asst_xxx",
    message="Добрый день! Это салон «Красотка». Напоминаем вам о записи на стрижку завтра в 15:00."
)
```

### Пакетные звонки

```python
# Массовые звонки клиентам
for client in clients:
    mcp_vapi.make_call(
        phone_number=client.phone,
        assistant_id="asst_reminder",
        message=f"Добрый день, {client.name}! Напоминаем о вашей записи на {client.service} {client.date}."
    )
```

## Питфоллы

1. **API-ключ** — храните в переменных окружения, не в коде
2. **Ассистенты** — каждый сценарий = отдельный ассистент с уникальным Script
3. **Телефония** — для исходящих звонков нужен подключённый номер (Twilio или встроенный Vapi)
4. **Записи** — по умолчанию записываются все звонки; можно отключить в настройках
5. **Латентность** — первый ответ AI может занять 1-2 секунды; настройте приветствие
