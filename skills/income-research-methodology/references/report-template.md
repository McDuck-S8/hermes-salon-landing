# Шаблон отчёта исследования

Использовать для каждого исследования. Скопировать и заполнить.

```markdown
# Исследование [тема] — [дата]

## Источники

| Источник | Идей | Статус |
|----------|------|--------|
| DeepSeek (локальный) | N | ✅/❌ |
| Web Search (через прокси) | N кейсов | ✅/❌ |
| Форумы (AffiliateFix, Reddit, др.) | N подтверждений | ✅/❌ |

## Таблица перелинковки

| Способ | DeepSeek | Web Search | Форумы | Пересечений | Достоверность |
|--------|----------|------------|--------|-------------|---------------|
| [название] | ✅/❌ | ✅/❌ (N кейсов) | ✅/❌ | X/3 | Высокая/Средняя/Низкая |

3/3 = высокая, 2/3 = средняя, 1/3 = низкая

## Топ-3 проверенных способа

### Способ 1: [название]
- **Что это:** [одно предложение]
- **Источники:** [ссылки]
- **Цифры:** [конкретные цифры]
- **Применимость к нам:**
  - Из Крыма: ✅/❌/❓
  - No KYC: ✅/❌
  - USDT/P2P: ✅/❌
  - Бюджет $0: ✅/❌
- **Что есть:** [инструменты, скиллы]
- **Чего не хватает:** [список]
- **Automation Score:** 0-10
- **TTFD:** [часы/дни]
- **Scalability:** [потолок]

### Способ 2: ...

### Способ 3: ...

## Trend Analysis
- Растёт/падает/стабилен
- Новые игроки:
- Умершие за год:

## Risk Grid
- Юридические: [нет/есть]
- Технические: [бан/ограничения]
- Рыночные: [платформа зависимость]

## Рекомендация
Какой способ запускаем первым и почему.
```
