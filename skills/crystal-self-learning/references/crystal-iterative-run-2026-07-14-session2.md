## Ключевые наблюдения

1. **output ≠ input подтверждён**: Каждый из 6 циклов (2 запуска × 3 цикла) дал уникальный вывод в блоке «Воля»
2. **Источник fabric частично исчерпан**: Первый цикл после очистки `studied` извлёк 2 новые сущности, след. циклы — 0
3. **self_model.json обновляется**: `last_cycle`, `cycle_count`, `umeyu.roles.all_entities` (3595→3597), `znu` (6→7 записей)
4. **Проблема**: Исчерпанные источники не помечаются персистентно → повторные попытки на следующих запусках

## Рекомендация

Добавить в `self_model.json` поле `exhausted_sources: []` для персистентного отслеживания источников, которые дали 0 новых сущностей N раз подряд. В `will()` проверять этот список и пропускать такие источники.
