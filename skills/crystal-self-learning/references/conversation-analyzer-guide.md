# ConversationAnalyzer — Анализ полной переписки

## Назначение

Модуль `scripts/crystal/conversation_analyzer.py` анализирует ВСЮ историю сообщений из state.db для извлечения инсайтов, идей, проблем и паттернов.

## Данные

- **Всего сообщений**: 55,261 (из них 4,037 user, 25,887 assistant, 25,333 tool)
- **Сессий**: 917
- **Период**: 24 мая - 17 июня 2026 (24 дня)
- **Источник**: `~/.hermes/state.db` (SQLite)

## Использование

```bash
# Анализ за 7 дней
python scripts/crystal.py --analyze-conversation --days=7

# Анализ за 30 дней (по умолчанию)
python scripts/crystal.py --analyze-conversation

# Программный доступ
from crystal.conversation_analyzer import ConversationAnalyzer
analyzer = ConversationAnalyzer()
result = analyzer.analyze_full(days=30)
```

## Что извлекает

### 1. Инсайты (insights)
Ключевые слова: "идея", "план", "стратегия", "проблема", "решение", "улучшение"
- Извлекает предложения с ключевыми словами
- Дедупликация по первым 100 символам
- Лимит: 50 инсайтов

### 2. Идеи (ideas)
Паттерны regex:
- "можно сделать/создать/добавить"
- "стоит попробовать/сделать"
- "хочу чтобы/сделать/получить"
- "надо бы/было бы хорошо"
- "а что если"
- Лимит: 50 идей

### 3. Проблемы (problems)
Ключевые слова: "проблема", "ошибка", "баг", "глюк", "не работает", "сломал"
- Извлекает предложения с проблемами
- Лимит: 50 проблем

### 4. Процессы (workflows)
Ключевые слова: "процесс", "workflow", "pipeline", "этап", "шаг"
- Извлекает абзацы с описанием процессов
- Лимит: 30 процессов

### 5. Паттерны (patterns)
- Активность по дням (сообщения/день)
- Частота ключевых слов (топ-20)

## Топ-5 тем из переписки

1. **Метрики и отчётность** — пользователь хочет видеть "сколько задач выполнено успешно, сколько с ошибками"
2. **Telegram-боты** — активная разработка и использование
3. **Self-evolution** — запуск self-evolution для скиллов
4. **Knowledge Cube** — создание и использование базы знаний
5. **Исправление багов** — постоянная работа над стабильностью

## Кэширование

Результат анализа кэшируется в `cache/crystal/conversation_analysis.json`.
Повторный вызов загружает кэш без повторного анализа.

## Ограничения

- Анализирует только текстовые сообщения (не изображения, не код)
- Ищет по ключевым словам и regex-паттернам (не семантический анализ)
- Дедупликация по первым 100 символам (может терять похожие, но разные инсайты)
