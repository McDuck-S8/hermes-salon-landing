15. Long-term Goals — strategic objectives tracking
16. External Intelligence — monitoring new tools, APIs, trends
17. Automated Testing — test before applying changes
18. Rollback — revert if change broke something

20. Communication Adapter — adapts style to user
21. Resource Monitor — budget and limits
22. Self-Evolution — Crystal improves itself

## Core Loop

```
Sessions + External World → Signals → Patterns → Needs → Memory → Energy → Dependencies → Goals → Priority → Risk → Testing → Proposals → Synergy → Actions → Rollback → Feedback → Versioning → Knowledge Base → Communication → Resources → Self-Evolution
```

## Design Principles

1. Study the USER, not KC stats
2. Understanding before code
3. DOX is the map, Crystal is the navigator
4. Observe from the side, see the big picture
5. Iterative architecture expansion — propose → validate → add → repeat
