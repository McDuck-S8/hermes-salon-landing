# Fargo Audit — Convert Anti-Slop Violations Into Client Sales Arguments

> Case study from 2026-07-21. Beauty salon landing page audit.

## Problem
Anti-slop violations are technical design failures. Clients don't care about "LILA RULE violation." They care about "your site looks like every other salon site."

## Pattern: Translate Violations → Sales Arguments

### Step 1: Find the violation with anti-slop pre-flight
Run through the anti-slop pre-flight checklist. Mark violations.

### Step 2: Translate to client language

| Anti-slop Violation | Client Translation | Sales Argument |
|---|---|---|
| LILA RULE / Premium Palette Ban | Warm beige + terracotta = standard salon template | "Your site looks like every other salon — let's make it look like YOU." |
| Hero stack >4 elements | 6 elements fighting for attention | "Too many messages = no message. Clean hero = higher conversion." |
| Eyebrow overcount (7 vs limit 3) | Every section has a label | "Labels overwhelm the experience. Fewer labels = more premium feel." |
| Three equal cards | 3 identical service cards | "3 equal boxes is the most common AI pattern. Variety = uniqueness." |
| Price accordion collapsed | Prices hidden behind accordion | "Hidden prices = lost clients. Show prices, get more bookings." |

### Step 3: Prioritize by business impact
Create a priority table:
- 🔴 P0: Most visible — color scheme, hero
- 🟡 P1: Design quality — eyebrow count, card layout
- 🟢 P2: UX polish — price accordion, animations

### Step 4: Add time estimates
Every fix gets a time estimate. 1.5 hours total is a realistic upsell.

### Step 5: Frame as an upsell, not an error list
```
"Your v3 site is 6/10. It works but looks like a template.
I can fix the 6 critical issues in 1.5 hours.
The result: a site that looks bespoke, not generated."
```

## Key phrases
- "Ваш сайт выглядит как все — давайте сделаем чтобы он выглядел как вы"
- "Первое что видит клиент — первое впечатление. Не дайте шаблону испортить его"
- "Это не ошибки. Это точки роста. Каждая стоит $X в потерянной конверсии"
