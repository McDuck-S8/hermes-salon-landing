# Премиальный многостраничный сайт

## Когда использовать

Клиент просит сайт для бизнеса (строительство, услуги, студия). Требуется:
- Многостраничность (5-6 страниц)
- Единый премиальный стиль
- Компонентная архитектура (шапка/футер вынесены)
- Адаптивность
- Cookie / Политика модалки
- Простой хостинг (sweb / статика)

## Архитектура

```
site/
├── index.html              # Главная
├── about.html              # О компании
├── services.html           # Услуги
├── gallery.html            # Галерея/Проекты
├── contacts.html           # Контакты
├── .htaccess               # SSL/редиректы для sweb
├── components/
│   ├── header.html         # Общая шапка
│   └── footer.html         # Общий футер
├── css/
│   └── style.css           # Единый стиль
├── js/
│   └── script.js           # Единый скрипт (включая подгрузку компонентов)
└── assets/
    └── img/                # Изображения
```

## Структура страниц

### index.html — Главная
1. Первый экран: фоновая фотография, заголовок (оффер), подзаголовок, CTA "Обсудить проект"
2. Блок преимуществ (3-6 иконок/карточек)
3. Блок популярных услуг
4. Блок проектов (карточки)
5. Блок "Как мы работаем" (этапы)
6. Блок отзывов
7. Блок соцсетей (ВК, Дзен)
8. Контакты

### about.html — О компании
- Описание компании
- Блок с цифрами (лет на рынке, проектов, и т.д.)
- Принципы работы
- Подход к качеству
- Блок доверия
- Фото руководителя/команды

### services.html — Услуги
- Карточки услуг (строительство, проектирование, отделка, инженерия, сопровождение)
- Этапы работы
- Соцсети

### gallery.html — Галерея проектов
- Карточки домов/проектов
- Площадь, материал, стиль, срок
- Фильтр/категории (опционально)

### contacts.html — Контакты
- Телефон, email, адрес, часы работы
- Соцсети
- Карта-заглушка (Яндекс/Google iframe или div)
- Текст о консультации

## Технические требования

### Шапка и футер (JS-подгрузка)
```html
<!-- В head каждой страницы -->
<script>
  fetch('components/header.html').then(r => r.text()).then(d => document.body.insertAdjacentHTML('afterbegin', d));
  fetch('components/footer.html').then(r => r.text()).then(d => document.body.insertAdjacentHTML('beforeend', d));
</script>
```

### Cookie-уведомление
- Показывается если localStorage('cookie_accepted') !== 'true'
- Кнопка "Принять" → сохраняет в localStorage + скрывает блок
- Ссылка на политику cookie (модалка)

### Модалки
- Политика конфиденциальности (открывается по ссылке из футера)
- Политика cookie (открывается из cookie-бара и футера)
- Обе через единый механизм (data-modal атрибуты)

### .htaccess для sweb
```apache
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}/$1 [R=301,L]
```

## Стиль

- **Цвета**: бежевый, тёмное дерево, графитовый, белый
- **Типографика**: крупные заголовки, чистый шрифт, много воздуха
- **Эффекты**: плавные hover, анимации без перегруза
- **Адаптивность**: mobile-first медиа-запросы
- **Запрет**: никаких внешних библиотек/фреймворков (чистый HTML+CSS+JS)

## Плейсхолдеры

В коде комментарии вида `<!-- EDIT: телефон -->` — менять под клиента.

## Изображения

- Главный баннер: качественная фотография (ссылка или заглушка)
- Галерея: фотографии проектов (ссылки)
- Иконки: SVG или emoji в крайнем случае

## Проверка

1. Все 5 страниц открываются локально через file://
2. Ссылки между страницами работают
3. Шапка/футер подгружаются на каждой
4. Cookie-бар появляется 1 раз, запоминает согласие
5. Модалки открываются/закрываются
6. Адаптив на мобильных
