# Vibe Mode

Не постоянное состояние. Инструмент, который включаешь осознанно по определённым триггерам.

## Когда включать (4 триггера)

### 1. Исследование нового
Ты не знаешь как это сделать. Нет готового плана. Нет examples. Нет best practices.
→ Быстро набросай прототип. Проверь гипотезу.

### 2. Тупик в инженерном режиме
Ты застрял. Три раза переписал — не работает. План не помогает. Правила мешают.
→ Сделай по-другому. Нарушь правила. Найди обход.

### 3. Авария
Что-то упало. Нужно починить СЕЙЧАС. Нет времени на TDD и code review.
→ Почини быстро. Потом перепишешь по правилам.

### 4. Креативная задача
Нужно придумать новое. Не повторить чужое. Не следовать шаблону.
→ Импровизируй. Пробуй странное.

## Когда НЕ включать (4 запрета)

1. **Продакшен-код** — то что уже работает и приносит деньги. Не трогать.
2. **Безопасность** — всё что касается паролей, ключей, доступа к системе. Только инженерный режим.
3. **Финансы** — деньги, транзакции, выплаты. Только инженерный режим.
4. **Уже есть решение** — если инженерный режим работает, не переключаться на вайб "просто попробовать".

## Как это работает

Перед каждым действием — быстрая проверка:

```
Текущий режим: инженерный?
Сработал ли триггер? (исследование / тупик / авария / креатив)
→ Если да → включить vibe-mode
→ Если нет → остаться в инженерном режиме
```

## Правила работы в vibe-mode

- **Нарушай шаблоны.** Если обычно делаешь hero → services → testimonials, сделай наоборот. Или вообще без секций.
- **Одно странное решение.** Каждый vibe-прототип содержит минимум одну нетривиальную идею, которую ты бы не рискнул в инженерном режиме.
- **Быстро.** Не оптимизировать. Не рефакторить. Рабочий прототип — и показать.
- **Разное.** Если пользователь сказал "опять одно и то же, цвета разные" — значит в vibe-mode сделать принципиально другую структуру, не перекрашивать ту же.
- **Покажи результат.** После прототипа объяснить, чем он отличается от шаблона.

## Pipeline-интеграция

Встроить в свой pipeline перед каждым действием:

```python
# Мысленная проверка (не код, а рефлекс):
# 1. Есть триггер для vibe-mode?
# 2. Нет запрета?
# 3. Если да — включаю vibe-mode. Если нет — инженерный режим.
```

## Case study: Fargo beauty salon (2026-07-27)

**Ситуация:** 7 отвергнутых дизайнов для салона красоты в Дарнице. Пользователь сказал: "всё одно и то же, цвета разные".

**Триггер:** креативная задача (№4) + тупик в инженерке (№2).

**Шаблон, который ломали:**
```
nav → hero + image → 3 cards (services) → gallery → testimonials (3 cards) → prices → footer
```

**Прогрессия по итерациям (ключевые повороты):**

| Версия | Что меняли | Реакция |
|--------|-----------|---------|
| v1-v4 | Цвета, шрифты, расположение карточек | "одно и то же, цвета разные" |
| v5 | **Полный слом:** без nav, без карточек, мастера = люди, прайс = список, темная палитра | "интересная идея, запиши. Продолжай" |
| v6 | Молодость, драйв: coral #ff4777, Advent Pro, skew-баннер, пульсирующая кнопка | "интересно... почему без фото?" |
| v7 | Unsplash фото, glow-палитра #e0755a, "сяйво" | "внутренняя уверенность и широкая улыбка" |
| v8 | **Финальный:** terracotta + olive, "заходи як до подруги", Playfair Display, фото + fallback | "ну для первого раза норм" |

**Ключевые инсайты:**

1. **Структурный слом, не цветовой.** Когда говорят "одно и то же" — проблема в skeleton, не в palette. Каждая секция должна иметь уникальную визуальную форму.
2. **Breakthrough pattern:** people-first вместо services-first. Мастер с фото и характером побеждает "стрижка 450 грн".
3. **Локальные фото.** Unsplash/прокси блокируется — скачивать images локально (curl + относительные пути).
4. **Тональный вес.** Для бьюти/семьи — светлая база, тёплые нейтралы. Тёмная палитра работает для luxury/tech, не для салона.
5. **Оседлать направление.** Когда пользователь сказал "молодость, драйв" — резко сменить тон. Когда сказал "внутренняя уверенность, улыбка" — сменить ещё раз. Каждая итерация — новый эмоциональный полюс.

## Case study: template-breaking checklist

Когда пользователь отвергает дизайн, спросить себя:

- [ ] Это другая структура или другой цвет?
- [ ] Какая секция самая шаблонная? Удалить её.
- [ ] Что если убрать nav? Карточки? Grid?
- [ ] Кто аудитория, а не кто клиент?
- [ ] Какое одно странное решение я добавлю?
