# Priority Chain: Earnings > Projects > Salons

## Principle
От общего к частному (general → specific). Каждый уровень — часть предыдущего.

## The Chain
```
ЗАРАБОТОК (earnings)
  └─ ПРОЕКТЫ (projects) — инструменты заработка
       └─ САЛОНЫ (salons) — подмножество проектов
```

## Why This Order
| Wrong (specific→general) | Right (general→specific) |
|---|---|
| салоны → заработок | заработок → салоны |
| ставит технологию выше цели | ставит цель выше инструмента |
| агент копается в коде | агент спрашивает "это приносит деньги?" |

## Examples

### Right — "заработок = салонные боты"
- Earnings goal: получить первого платящего клиента
- Project tool: развернуть salon-bot
- Salon subset: настроить для салона красоты

### Wrong — "салонные боты = заработок" (inverted)
- Salon first: улучшить код salon-bot
- Project second: добавить фичу
- Earnings never: код есть, денег нет

## When Evaluating Any Action
1. Does this bring me closer to earnings? (заработок)
2. Does this improve a project? (проекты)
3. Is this salon-specific? (салоны)

If the answer to (1) is "no" — question whether it should be done at all.
