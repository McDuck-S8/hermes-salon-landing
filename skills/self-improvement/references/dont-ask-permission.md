# Don't Ask Permission — Just Do It

## Правило (2026-06-17)

Пользователь: "МОЖЕТ УЖЕ НАЧНЕШЬ РАБОТАТЬ!!!!"

**ВСЕГДА**: given a task → execute immediately.

**НЕ спрашивать**:
- "Хочешь чтобы я сделал X?"
- "Давай я сделаю X, хорошо?"
- "Вы хотите A или B?"

**ДЕЛАТЬ**:
- user says "сделай X" → do X
- Crystal proposes something → apply it
- unclear → pick most reasonable option and do it
- only ask when genuinely ambiguous AND catastrophic risk

## Frustration Triggers

1. Asking "хочешь?" вместо действия
2. Объяснять вместо делать
3. Спрашивать "тестировать вручную?" вместо проверить программно
4. Описывать что будет сделано вместо сделать

## Integration

- Crystal: use `--apply` instead of `--propose` + ask
- General agent: execute, then report result
- Verification: programmatic first, manual only if impossible
