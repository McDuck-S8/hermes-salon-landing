# Tilda — Карта использования

## Что делает
Конструктор сайтов с AI-помощником. Создание лендингов, интернет-магазинов, спецпроектов без кода. 550+ готовых блоков, AI генерация контента.

## Лимиты бесплатного тарифа
- 1 сайт, до 50 страниц
- 7 дней истории изменений
- Свой домен НЕ подключить (поддомен *.tilda.ws)
- 50MB дискового пространства
- Базовые SEO настройки

## Пошаговая инструкция

### Шаг 1: Открыть сайт
- URL: https://tilda.cc/ru/
- Нужен VPN: нет
- Нужна регистрация: да (email/соцсети)

### Шаг 2: Зарегистрироваться
- **Элемент:** Кнопка «РЕГИСТРАЦИЯ» (ref=e85)
- **Что делать:** Нажать → ввести email/пароль
- **Результат:** Личный кабинет, бесплатный тариф сразу

### Шаг 3: Создать сайт с AI
- **Элемент:** Кнопка «Создать сайт бесплатно» (ref=e7, e13)
- **AI кнопка:** После входа — использовать AI-помощника для генерации
- **Что делать:** Описать сайт в 1-2 предложениях → AI создаст структуру

### Шаг 4: Редактировать блоки
- **Библиотека:** 550+ готовых блоков (обложки, галереи, формы, видео)
- **Zero Block:** Свой блок с нуля (для продвинутых)
- **Что делать:** Выбрать блок → перетащить → настроить текст/цвета

### Шаг 5: Опубликовать
- **Элемент:** Кнопка «Опубликовать» в панели управления
- **Где:** Верхняя панель → «Публикация»
- **Результат:** Сайт на поддомене *.tilda.ws
- **Важно:** На бесплатном тарифе — только поддомен

## Известные проблемы
- Бесплатный тариф — водяной знак Tilda в футере
- Ограничение 50 страниц — для лендинга хватит, для магазина нет
- AI-генерация — только на русском/английском
- Нет экспорта HTML на бесплатном тарифе

## Пример использования
Создать лендинг для Telegram-канала:
1. «Создать сайт бесплатно» → AI: "Лендинг психолога"
2. Выбрать шаблон → заменить тексты
3. Добавить Zero Block с формой подписки
4. Опубликовать → получить ссылку *.tilda.ws
