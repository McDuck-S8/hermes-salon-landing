# Bing Image Creator — Карта использования

## Что делает
Генерирует изображения по текстовому описанию через DALL-E 3 (Microsoft/Bing). Бесплатно, 4 варианта за 1 промпт.

## Лимиты
- 15-25 генераций в день (Microsoft Rewards увеличивают лимит)
- 4 изображения за 1 промпт
- Разрешение: 1024x1024 (квадрат), 3:2, 4:3
- Нужен аккаунт Microsoft (бесплатно)

## Пошаговая инструкция

### Шаг 1: Открыть сайт
- URL: https://www.bing.com/images/create
- Нужен VPN: нет
- Нужна регистрация: да (Microsoft account)
- Open Graph title: "Открой для себя Создатель изображений в Bing"

### Шаг 2: Ввести промпт
- **Элемент:** Текстовое поле «Опишите изображение, которое нужно создать»
- **Где:** В центре страницы, под заголовком
- **Что делать:** Нажать на поле → ввести описание на любом языке
- **Совет:** Чем детальнее промпт, тем лучше результат

### Шаг 3: Выбрать настройки
- **Тип:** Изображение / GIF / Наклейка
- **Режим:** Яркий и естественный / Точный
- **Соотношение:** 3:2 / 1:1 / 4:3
- **Что делать:** Выбрать опции из выпадающих списков

### Шаг 4: Создать
- **Кнопка:** «Создать»
- **Что делать:** Нажать кнопку
- **Результат:** 4 изображения (~30-60 сек)
- **Важно:** Если нет аккаунта — предложит войти

### Шаг 5: Скачать результат
- **Формат:** JPG/PNG — 1024x1024
- **Как:** Навести на изображение → иконка скачивания → нажать
- **Вариант 2:** Поделиться → Сохранить как

## ИИ-редактор фотографий
- **Удаление фона:** Авто, без выделения
- **Ретушь:** Улучшение старых фото
- **Расширитель:** Дорисовка краёв
- **Улучшение:** Повышение резкости

## Известные проблемы
- Лимит в день — при превышении предложит купить бусты
- Фильтр контента — блокирует NSFW и политически чувствительные промпты
- Без резид. прокси — может потребовать логин при каждом визите

## Пример использования
Промпт: "A serene mountain lake at sunset, with pine trees reflecting in calm water, digital art"
→ 4 варианта изображения
→ Скачать понравившийся через кнопку скачивания
