## СМЕЖНЫЕ ОБЛАСТИ (adjacent areas — self-ask checkpoint 4)

### Финансы (что дальше с деньгами?)
- **Вывод:** Travelpayouts платит на PayPal или банковский перевод
- **Налоги:** Самозанятый — 4% налога, лимит 2.4 млн руб/год
- **Регистрация:** Через Gosuslugi, 15 минут, бесплатно
- **Риски:** Блокировка аккаунта при подозрении на фрод
- **Что могу проверить:** Лимиты самозанятого, ставки, процесс регистрации
- **Что не могу:** Будут ли реальные бронирования (нужен запуск)

### Юридические (что нужно оформить?)
- **Договор с отелем:** Agency Agreement — ты агент, отель principal
- **152-ФЗ:** Нужна политика конфиденциальности для данных гостей
- **Ответственность:** За no-show/отмену — по договору
- **Что могу проверить:** Можно ли принимать оплату как самозанятый через ЮKassa
- **Что не могу:** Будет ли отель сотрудничать (нужен контакт)

### Масштабирование (что после MVP?)
- **Multi-tenant:** SQLite → PostgreSQL для нескольких отелей
- **OTA интеграции:** Travelpayouts API, Booking.com Affiliate API
- **Пиковый сезон:** Автопостер для горячих предложений (июнь-август)
- **Что могу проверить:** API Travelpayouts доступен, PostgreSQL масштабируется
- **Что не могу:** Конверсию бота (нужен запуск)
