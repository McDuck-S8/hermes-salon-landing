## БЛОК 1: Сайты услуг и сервисов (наша прямая ниша)
====================================================================

### 1. skincare.com (L'Oréal)
**Тип:** Медиа-портал/блог о косметике  
**Hero:** Крупное фото текстуры кожи/пены — нет продукта, есть ощущение. Заголовок "YOUR BEST SKIN STARTS HERE" — 48px sans-serif, caps.  
**Типографика:** Sans-serif (премьерный гротеск), H1 48px bold, body 16px/1.6  
**Цвета:** #FFFFFF фон, #000000 текст, #FF6B6B (розовый акцент), #F5F0EB (теплый бежевый)  
**Сетка:** Карточная сетка статей 3 колонки с фото, категорией, датой  
**Анимации:** Статично, без микроанимаций  
**Мобильная:** Меню в гамбургер, карточки в 1 колонку  
**Приём:** Hero с косметической текстурой как фон — создаёт "ощущение" продукта без демонстрации товара  

### 2. glossier.com
**Тип:** E-commerce косметика  
**Hero:** Полноэкранное фото продукта (Boy Brow) с минимальным текстовым оверлеем "BOY BROW" + цена $22  
**Типографика:** Sans-serif (собственный шрифт), крупные кернингованные заголовки 40px, межбуквенный интервал увеличен  
**Цвета:** #FFFFFF, #000000, #FFB6C1 (бледно-розовый), #F5F5F5  
**Сетка:** Сетка 2-3 колонки, много воздуха между элементами  
**Анимации:** Плавный hover на карточках (легкое затемнение), lazy-load изображений  
**Мобильная:** Карточки продуктов в 2 колонки, навигация скрыта  
**Приём:** Каждый продукт — отдельная история с полноэкранным фото. Минимальный текст.  
**Ключевой паттерн:** "Один продукт — один экран" — не смешивать, дать каждому элементу дышать  

### 3. blissworld.com
**Тип:** E-commerce косметика/SPA  
**Hero:** Карусель продуктов с яркими фотографиями, категории с иконками  
**Типографика:** Sans-serif, H2 32px bold, body 15px/1.6  
**Цвета:** #FFFFFF, #2D2D2D, #FF69B4 (розовый), #FED70A (желтый), #90EE90 (зеленый)  
**Сетка:** Карусели продуктов (горизонтальные), секции с фоном-разделителем  
**Анимации:** Горизонтальные карусели, hover с отображением второй фотографии  
**Мобильная:** Вертикальный стек  
**Приём:** Цветовая кодировка категорий — каждый раздел имеет свой цветовой акцент  
**Ключевой паттерн:** "It's always been Bliss" — бренд-сторителлинг секция с атмосферным фото  

### 4. drybar.com
**Тип:** E-commerce + сеть салонов  
**Hero:** Промо-баннер "4th of July Event: Up to 30% off" + продукт Detox Reset  
**Типографика:** Sans-serif, жирные заголовки 36px, логотип в виде wordmark + иконка фена  
**Цвета:** #2D2D2D (темно-серый), #FFFFFF, #F5A0A0 (бледно-розовый акцент), #E8E8E8  
**Сетка:** Продуктовая сетка 3-4 колонки, карусели  
**Анимации:** hover на продуктах (увеличение фото, отображение второй картинки)  
**Мобильная:** Гамбургер с мега-меню, продукты в 2 колонки  
**Приём:** Логотип + иконка инструмента — сильный бренд-сигнал. Бесплатная доставка как триггер  
**Ключевой паттерн:** Верхняя промо-полоса на всю ширину — "4th of July Event: Up to 30% off"  

### 5. sugarbearhair.com
**Тип:** DTC бренд витамин  
**Hero:** Фулскрин видео продукта на фоне + автовоспроизведение + крупный CTA "SHOP NOW"  
**Типографика:** Sans-serif, крупные 42px заголовки, контрастный текст  
**Цвета:** #1A1A2E (тёмно-фиолетовый), #E94560 (розовый), #FFFFFF, #0F3460  
**Сетка:** Сторителлинг-секции на весь экран, каждая с отзывом + фото  
**Анимации:** Видеофон в hero, параллакс при скролле, hover с анимацией на CTA  
**Мобильная:** Вертикальный стек, видео на весь экран  
**Приём:** Социальное доказательство ДО и ПОСЛЕ с реальными фото + видео на фоне  
**Ключевой паттерн:** "REAL CUSTOMERS. REAL RESULTS." — отзывы с фотографиями как основной контент, а не дополнение

## БЛОК 2: Современный веб-дизайн (тренды 2026)
====================================================================

### 6. apple.com/macbook-pro
**Тип:** Продуктовый лендинг  
**Hero:** 3D-анимация MacBook Pro складывающегося в V-форму (отсылка к чипу M5). Заголовок "MacBookPro" + "Fast runs in the family."  
**Типографика:** San Francisco (собственный гротеск), H1 56px bold, кернинг -0.5px. Заголовок + подзаголовок + цена  
**Цвета:** #F5F5F7 (светло-серый фон), #1D1D1F (текст), #0071E3 (синий CTA)  
**Анимации:** Скролл-ориентированная анимация продукта (3D вращение), видео-вставки, tab-навигация с плавным переключением контента  
**Сетка:** Асимметричная — продукт слева, текст справа. Или центрированная для hero  
**Мобильная:** Всё в стек, анимации упрощены, текст центрирован  
**Золотой стандарт:** Каждая секция — отдельная история с одним сообщением  
**Ключевой приём:** Скролл-триггерная 3D анимация продукта — дорого и технологично  

### 7. stripe.com
**Тип:** B2B SaaS  
**Hero:** "Financial infrastructure to grow your revenue" — один заголовок до 200 знаков (длинный, но разбитый на акцентную часть + пояснение)  
**Типографика:** Custom (Stripe uses modified font), H1 48px bold, акцентная часть жирнее и крупнее. Межстрочный 1.3  
**Цвета:** #0A2540 (фиолетово-синий), #00D4AA (бирюзовый акцент), #FFFFFF, #635BFF (primary)  
**Сетка:** 12-колоночная, карточки-аккордеоны с иконкой слева  
**Анимации:** Плавный hover на CTA, аккордеон-раскрытие с анимацией, карусель логотипов-партнёров  
**Мобильная:** Аккордеоны становятся табами, логотипы упрощены  
**Ключевой приём:** Разделение длинного заголовка на акцентную жирную часть + обычный текст-пояснение  

### 8. linear.app
**Тип:** B2B SaaS (issue tracker)  
**Hero:** "The product development system for teams and agents" — полный экран. Ниже — живой скриншот интерфейса с реальными данными  
**Типографика:** Inter (свой гротеск), H1 48px, тонкий вес 300-400, широкий межбуквенный  
**Цвета:** #0A0A0A (черный фон), #FFFFFF, #5E6AD2 (индиго), #00CFC8 (бирюзовый)  
**Сетка:** Левый стек текста + правый блок интерфейса  
**Анимации:** Тёмная тема, плавный hover, микро-анимации в UI-демо  
**Мобильная:** Стек, скриншот под текстом  
**Ключевой приём:** Живое демо продукта прямо под hero — не скриншот, а реальный рабочий интерфейс  

### 9. vercel.com
**Тип:** B2B SaaS (деплой/хостинг)  
**Hero:** "Agentic Infrastructure" — заголовок + "Build agents on infrastructure that thinks like them"  
**Типографика:** Geist (свой гротеск), H1 56px, тонкий  
**Цвета:** #000000, #FFFFFF, #FF5C00 (оранжевый акцент)  
**Сетка:** Минималистичная, много негативного пространства  
**Анимации:** Частицы/3D-сцена в фоне hero, геометрические фигуры  
**Мобильная:** Герой упрощается, текст центрируется  
**Ключевой приём:** Микро-анимация или 3D-сцена на фоне hero — создаёт технологичность  

### 10. framer.com
**Тип:** B2B инструмент  
**Hero:** Интерактивный редактор — прямо на сайте показан UI Framer с переключением тем/устройств  
**Типографика:** Inter, H1 52px  
**Цвета:** #FFFFFF, #000000, #FF3366 (розовый)  
**Сетка:** Демо-интерфейса занимает 70% экрана  
**Анимации:** Интерактивный UI с переключением между десктоп/таблет/мобайл  
**Мобильная:** Стек, демо под текстом  
**Ключевой приём:** "Ешь свой собачий корм" — покажи продукт как демо, не рассказывай о нём

## ШАГ 2: ЗАКОНОМЕРНОСТИ (топ-10 приёмов)
====================================================================

### 1. Тёмный фон + золотой/яркий акцент — ПРЕМИАЛЬНОСТЬ
Встречается: Larian, Apple (тёмные секции), Raycast, Linear, Vercel
**Применение к Fargo:** Уже есть тёмная тема и золотой #C9A96E. УСИЛИТЬ контраст.

### 2. Hero с типом "акцентный заголовок + подзаголовок-пояснение"
Встречается: Stripe, Linear, Apple, Framer
**Применение:** Не просто "Fargo", а "Fargo — салон краси на Позняках" с визуальным акцентом на бренд

### 3. Скролл-триггерные анимации (не просто fade-in)
Встречается: Apple, Framer, Larian, Sonos
**Применение:** Параллакс фона при скролле, элементы наезжающие друг на друга

### 4. Карточки услуг с иконкой + заголовок + цена + CTA
Встречается: Glossier, Bliss, Drybar
**Применение:** Уже есть — улучшить: добавить второе состояние (hover с деталями)

### 5. Социальное доказательство с фото (не просто звёзды)
Встречается: Sugarbearhair, Glossier
**Применение:** В отзывах Fargo — добавить инициалы в кружок (уже есть), но сделать фото-аватары

### 6. Микро-анимации на кнопках (не просто смена цвета)
Встречается: Stripe, Linear, Apple, Framer
**Применение:** CTA при наведении — не только смена цвета, а сдвиг + свечение + изменение иконки

### 7. Анимированный градиент/частицы на фоне hero
Встречается: Larian, Raycast, Vercel
**Применение:** Hero Fargo — уже есть градиент и grain, добавить медленно движущиеся частицы или световые пятна

### 8. Разделение на секции с атмосферными фото
Встречается: Bliss ("It's always been Bliss"), Sugarbear (истории)
**Применение:** Добавить секцию "Про Fargo" с визуальным сторителлингом

### 9. Прозрачная навигация, уплотняющаяся при скролле
Встречается: Apple, Linear, Framer, Vercel
**Применение:** Уже есть — улучшить: более заметный бордер при скролле, размытие сильнее

### 10. Ценовые карточки с визуальным акцентом
Встречается: Stripe, Linear
**Применение:** Fargo — выделить цену золотым цветом и шрифтом Playfair Display

## ШАГ 3: ПРИМЕНЕНИЕ К FARGO
====================================================================

### Конкретные изменения:

1. **HERO: Усилить кинетическую типографику**
   - Заголовок "Fargo" разбит на буквы — каждая появляется с вращением и смещением (уже есть)
   - Добавить: медленно движущиеся световые частицы/звёзды на фоне
   - Подзаголовок не просто появляется, а въезжает снизу с размытием
   - Кнопки: при наведении — золотое свечение + легкий подъём

2. **ВИЗУАЛЬНЫЙ СТОРИТЕЛЛИНГ: Добавить секцию "Про нас"**
   - Уже есть — улучшить: плавающая карточка "10+ лет" с золотым числом и анимацией появления
   - Фото-плейсхолдер с декоративной буквой "F" как бренд-элемент

3. **КАРТОЧКИ УСЛУГ: Улучшить hover-эффекты**
   - При наведении: карточка поднимается на -4px, border становится золотым, иконка меняет цвет
   - CTA-стрелка наезжает вправо при hover

4. **ОТЗЫВЫ: Форматирование как сторителлинг**
   - Звёзды золотые, текст курсивом, имя + услуга под текстом
   - При наведении — легкое подсвечивание фона

5. **ПРАЙС: Визуальная иерархия**
   - Категории — с иконкой эмодзи и заголовком Playfair Display
   - Цены золотым цветом, жирным шрифтом
   - Чередование строк с легким затемнением

6. **ФУТЕР: Четыре колонки с иерархией**
   - Бренд + описание
   - Послуги (3-4 ссылки)
   - Контакти (телефон, Instagram)
   - Години

7. **НАВИГАЦИЯ: Прозрачная → уплотняющаяся**
   - При старте: прозрачный фон, белый текст
   - При скролле >100px: blur-фон с размытием, тонкий border снизу
   - Кнопка "Записатись" золотая, всегда видна

8. **МОБИЛЬНАЯ АДАПТАЦИЯ: Усилить**
   - Гамбургер-меню с плавным выездом справа
   - Карточки услуг в 1 колонку на телефоне
   - Шрифты уменьшаются пропорционально
   - Сетка галереи перестраивается в 2 колонки

## Design System Fargo 2026
====================================================================

### Colors (уже есть, подтверждены референсами):
- Бренд: #C9A96E (золотой), #DFC28A (светлый), #A8884A (тёмный)
- Фон: #0A0A0A, #111111, #1A1A1A
- Текст: #F0EDE8 (основной), #8A8680 (приглушённый), #5C5852 (тёмный)
- Акцент: #C9A96E (CTA, ссылки, иконки)
- Glass: rgba(255,255,255,0.03-0.08)

### Typography (подтверждено референсами):
- Заголовки: Playfair Display 600-700 weight (Larian-style serif luxury)
- Текст: Inter 300-500 weight (Linear/Stripe/Apple style clean sans)
- Размеры: H1 3rem-7rem (clamp), H2 2rem-3.2rem, H3 1.2rem, body 0.85-0.95rem
- line-height: 1.2 для заголовков, 1.7-1.8 для текста

### Spacing (из референсов):
- padding секций: 100px 40px (десктоп), 60px 20px (мобильный)
- gap между карточками: 20-24px
- отступы в карточках: 32-36px
- hero: 120px 40px 80px + полная высота экрана

### Эффекты (подтверждено):
- border-radius: 20px (карточки), 12px (мелкие), 50px (кнопки)
- backdrop-filter: blur(20px) для glassmorphism
- transition: 0.3s-0.4s ease для hover
- box-shadow: 0 4px 20px rgba(201,169,110,0.25) для золотых CTA
