## ЧТО ТАКОЕ АРБИТРАЖ ТРАФИКА

Покупаешь рекламу дешевле → приводишь людей → получаешь комиссию → разница = прибыль.

**Пример:** Реклама казино $50 → 100 регистраций → казино платит $1/регистрация = $50 чистыми.

## РАБОЧИЕ СХЕМЫ

### Нутра:
```
Facebook ($0.5/клик) → Прелендинг (история) → Лендинг → Колл-центр → Продажа
Стоимость лида: 200-500 руб, Аппрув: 40-60%, Выплата: 1500-2500 руб
ROI: 50-150%
```

### Гемблинг:
```
Push ($0.05/клик) → Прелендинг (бонусы) → Регистрация → Депозит
Стоимость регистрации: $3-10, Выплата за депозит: $50-150
Конверсия в депозит: 10-30%, ROI: 100%+
```

### Товарка:
```
VK таргет (100-300 руб/заявка) → Одностраничник → Форма заказа → Колл-центр
Выкуп: 40-70%, Средний чек: 2500 руб, Маржа: 300-500%
```

## С ЧЕГО НАЧАТЬ (пошаговый план)

1. **Вертикаль:** Товарка или нутра (минимальный бюджет)
2. **CPA сеть:** M1-Shop, DrCash, CPAExchange (RU), MaxBounty (global)
3. **Бюджет:** $500 на тесты + $200 на софт
4. **Софт:** Трекер ($69/мес) + прокси ($30/мес) + антидетект ($9/мес)
5. **Первый тест:** Топовый оффер + рабочие креативы из шпионского сервиса + $50/день
6. **Масштаб:** Отключить неэффективное, увеличить бюджет на рабочее
