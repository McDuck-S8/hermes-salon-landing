# AGENTS.md — notes/

## Purpose

Miscellaneous notes, research results, and reference materials that don't fit into other directories.

## Ownership

User-driven — created by agent during research tasks or by user manually.

## Files

| File | Purpose |
|---|---|
| `browser-notes.md` | Browser automation notes and debugging findings |
| `intel_driver_update.md` | Driver update research and intelligence |

## Local Contracts

- **Format**: Markdown.
- **Organization**: No strict structure — free-form notes organized by topic.
- **Lifecycle**: Notes may become stale. Review periodically and archive to `trash/` if obsolete.

## Work Guidance

- Use `notes/` for research results that don't belong in `memories/` or `plans/`.
- When generating reports or research, save final output to `reports/` and working notes here.
- Reference notes in cron job outputs when providing context for scheduled tasks.

## Verification

- No automated verification needed — these are reference documents.
