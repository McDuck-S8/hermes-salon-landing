# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Email vilius@agenticflow.dev.

You should receive a response within 48 hours.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Security Model

This is a **local-only** CLI tool. It runs on your machine, not a server.

- Reads and writes local skill files only
- No network exposure
- No telemetry, no phoning home
