## ЧТО ТАКОЕ CPA

**CPA = Cost Per Action** — оплата за действие.
- Пользователь регистрируется → ты получаешь деньги
- Пользователь скачивает приложение → ты получаешь деньги
- Пользователь делает покупку → ты получаешь комиссию

## КАК ЭТО РАБОТАЕТ

### Простой CPA workflow:
```
1. Регистрируешься в CPA сети (бесплатно)
2. Выбираешь оффер (например: "Регистрация на бирже крипты")
3. Получаешь ссылку
4. Размещаешь ссылку в Telegram канале/боте
5. Пользователь переходит и регистрируется
6. Ты получаешь $5-50 за регистрацию
```

### Примеры офферов:
| Оффер | Платёж | Требование |
|-------|--------|------------|
| Регистрация на бирже | $5-20 | KYC верификация |
| Скачивание приложения | $1-5 | Установка + запуск |
| Покупка в игре | $10-50 | Первый депозит |
| Подписка на сервис | $5-15 | Оплата первого месяца |
| Заполнение анкеты | $1-3 | Анкета заполнена |

## ИНТЕГРАЦИЯ С ТЕЛЕГРАМ

### Как использовать CPA в Telegram:
1. **В канале:** Пост с CPA-ссылкой → подписчик кликает → ты получаешь деньги
2. **В боте:** Бот предлагает оффер → пользователь переходит → ты получаешь деньги
3. **В группе:** Рекламный пост с CPA-ссылкой

### Пример: CPA в salon_booking_bot.py
```python
# В боте добавить раздел "Партнёрские предложения"
@router.message(Text("Партнёрские предложения"))
async def show_offers(message: types.Message):
    offers = [
        {"name": "Биржа крипты", "link": "https://cpa-link.com/1", "reward": "$10"},
        {"name": "VPN сервис", "link": "https://cpa-link.com/2", "reward": "$5"},
    ]
    for offer in offers:
        await message.answer(f"{offer['name']}: {offer['reward']} за регистрацию\n{offer['link']}")
```
