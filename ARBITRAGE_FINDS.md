**Что:** Admitad запустил CPC (Cost-Per-Click) — платит за КЛИК, не за продажу.

**Почему это game-changer:**
- CPA = получаешь деньги ТОЛЬКО когда кто-то купил
- CPC = получаешь деньги ЗА КАЖДЫЙ клик по ссылке
- CPC rate: $0.05-0.50 за клик (зависит от GEO и ниши)
- **Для авто-постера:** каждый пост с CPC-ссылкой приносит деньги ДАЖЕ без продаж

**Математика:**
```
5 каналов × 100 кликов/день × $0.10 = $50/мес
5 каналов × 500 кликов/день × $0.15 = $2,250/мес
```

**Ограничения:**
- CPC доступен только для direct publishers (свои каналы/сайты)
- НЕ для арбитражников (paid traffic resellers)
- Качество трафика оценивается динамически
- Нужно сначала получить доступ к CPA, потом CPC

## НАХОДКА #7: CPC + CPA = полная монетизация воронки

**Что:** На одном и том же канале можно использовать ОБЕ модели:
- Upper-funnel контент → CPC ссылки ( платит за клики)
- Lower-funnel обзоры → CPA ссылки (платит за продажи)

**Пример:**
```
Пост 1 (обзор): "Лучшие VPN сервисы 2026" → CPC ссылка ($0.10/клик)
Пост 2 (сравнение): "NordVPN vs Surfshark" → CPA ссылка ($5/продажа)
Пост 3 (скидки): "Промокод NordVPN" → CPA ссылка ($5/продажа)
```

**Математика:**
```
CPC: 200 кликов/день × $0.10 = $20/мес
CPA: 5 продаж/день × $5 = $750/мес
ИТОГО: $770/мес с 1 канала
```

**Статус:** ПРОВЕРЕНО (Admitad CPC article, May 2026)
