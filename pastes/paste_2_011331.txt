## �� Шаблоны для бизнес-плана

### 1. Business Model Canvas — шаблон для Obsidian
**Репозиторий:** `YJPL/business-model-canvas-for-obsidian` 

Готовый шаблон Business Model Canvas с 9 блоками (по методологии Strategyzer) для приложения Obsidian. Включает отдельные Markdown-файлы для каждого блока и единый .canvas документ.

**Что внутри:**
- Ключевые партнеры
- Ключевые активности
- Ценностные предложения
- Взаимоотношения с клиентами
- Каналы сбыта
- Сегменты клиентов
- Ключевые ресурсы
- Структура издержек
- Источники дохода

**Требования:** Obsidian (бесплатное приложение).

---

### 2. Business Model Canvas — Markdown шаблон
**Репозиторий:** `GeorgLink/Business-Model-Canvas-MD-template` 

Простой шаблон в формате Markdown для заполнения прямо в любом текстовом редакторе.

**Структура:**
- Краткое описание бизнеса (elevator pitch)
- Таблица Canvas с вопросами для каждого блока
- Ссылки на подробные документы

### 3. Lean Canvas для стартапов
**Файл:** Markdown Gist от `pierrebeamp` 

Lean Canvas — адаптация Business Model Canvas для стартапов (Ash Maurya). Более быстрый и ориентированный на гипотезы подход.

- Каналы привлечения
- Сегменты клиентов
- Структура издержек
- Источники дохода

## �� Инструменты для презентаций

### 4. Text-to-PPT — автоматическая генерация презентаций
**Репозиторий:** `YashSinha047/Text-to-PPT` 

**Что делает:** Превращает текст, Markdown или прозу в готовые PowerPoint презентации.

**Возможности:**
- Поддержка OpenAI, Anthropic, Gemini API
- Загрузка собственного шаблона (.pptx/.potx) для сохранения стиля
- Автоматическое определение количества слайдов
- Конфиденциальность — никакие данные не хранятся

**Как использовать:**
1. Вставьте текст
2. Добавьте краткую инструкцию (например, "создай pitch deck для инвестора")
3. Введите API ключ LLM
4. Загрузите шаблон (опционально)
5. Скачайте готовую презентацию

---

### 5. GitPitch — презентации из Markdown
**Репозиторий:** `hudawei996/gitpitch` 

**Что делает:** Превращает файл `PITCHME.md` в интерактивные онлайн-презентации. Работает с GitHub, GitLab, Bitbucket.

**Особенности:**
- Презентации прямо из вашего репозитория
- Поддержка кода (с подсветкой)
- Встроенные графики и диаграммы
- 6 тем оформления
- Экспорт в PDF и офлайн-режим

---

### 6. Pitch Deck Template (12 слайдов)
**Репозиторий:** `sixarm/pitch-deck-template` 

Очень подробный текстовый шаблон питч-дека. Не код, а готовая структура для заполнения.

**Структура питч-дека:**
| Раздел | Что описывает |
|--------|---------------|
| Problem | Какая проблема решается? |
| Market | Размер рынка, TAM/SAM/SOM |
| Solution | Ваше решение и его преимущества |
| Competition | Сравнение с конкурентами |
| Validation | Доказательства и метрики |
| Roadmap | План развития |
| Sales | Каналы продаж и ценообразование |
| Marketing | Стратегия привлечения клиентов |
| Team | Ключевые люди в команде |
| Partners | Стратегические партнеры |
| Financial | Финансовые прогнозы на 3 года |
| Investment | Запрос на инвестиции |

Также есть приложения с метриками (A16Z), подходами к оценке бизнеса (DCF, rNPV, Venture Capital Method) и шаблонами анализа (SWOT, бизнес-модель).

## �� Профессиональные методологии (skills)

### 7. Business Model Canvas Skill
**Репозиторий:** `pm-skills/pm-product-strategy` (файл `skills/business-model/SKILL.md`) 

**Что это:** Профессиональный SKILL-файл для AI-ассистентов по созданию Business Model Canvas.

**Особенности:**
- Подробные инструкции для генерации каждого из 9 блоков
- Критерии экономической жизнеспособности (LTV > 3x CAC)
- Сравнение BMC с Lean Canvas и Startup Canvas
- Ограничения BMC и когда его использовать

---

### 8. Lean Canvas Skill
**Репозиторий:** `pm-skills/pm-product-strategy` (файл `skills/lean-canvas/SKILL.md`) 

**Что это:** SKILL для создания Lean Canvas — стартап-ориентированной версии бизнес-модели.

**Отличия от BMC:**
- Вместо Key Partners/Activities/Resources — Problem/Solution/Unfair Advantage
- Быстрее, ориентирован на гипотезы
- Включает ключевые метрики
- Лучше для ранних стадий стартапа

---

### 9. Startup Idea Checklist (YC-style)
**Gist:** `JiangWeixian/startup-idea-checklist` 

Чеклист для проверки стартап-идей, основанный на подходе Y Combinator, Amazon и Sequoia.

**Что проверяет:**
- Product: кто пользователи, метрики качества
- Growth: размер рынка, первые 10 клиентов
- Strategy: почему сейчас, как построить moat
- Meaning: что изменится через 25 лет

Может использоваться как GitHub Issue Template для фильтрации идей.
