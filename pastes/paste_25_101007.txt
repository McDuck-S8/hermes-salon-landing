## ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Конфиги для Ozon и Wildberries (поиск товаров, цена, отзывы, комплектация)

### 1. Цель
Расширить скилл `web-automation` конфигами для **Ozon** и **Wildberries** (WB), чтобы система могла:
- Искать товары по ключевым словам.
- Фильтровать по **низкой цене** (сортировка по возрастанию).
- Извлекать **рейтинг, количество отзывов, текст отзывов** (первые 3-5).
- Извлекать **комплектацию** (состав, характеристики, размеры, цвет, материал и т.д.).
- Выдавать структурированные данные (JSON) для дальнейшего анализа в **Knowledge Cube**, **Graphify**, **free-traffic-scout**.

### 2. Требования к конфигам
#### 2.1. Ozon
- **Базовая страница:** `https://www.ozon.ru/search/?text={query}&sort=price` (сортировка по возрастанию цены)
- **Извлекаемые поля из списка:**
  - `title` — название товара.
  - `price` — цена (число, в рублях).
  - `rating` — средний рейтинг (1–5).
  - `reviews_count` — количество отзывов (число).
  - `link` — ссылка на карточку товара.
  - `image` — URL изображения (опционально).
- **Извлекаемые поля из карточки товара (`product`)**:
  - `title` — полное название.
  - `price` — текущая цена.
  - `old_price` — старая цена (если есть скидка).
  - `rating` — рейтинг.
  - `reviews_count` — количество отзывов.
  - `reviews` — список отзывов (первые 5, текст + оценка).
  - `characteristics` — характеристики (комплектация, материал, размер, цвет, вес, страна производитель и т.д.) в виде словаря.
  - `availability` — наличие (в наличии / под заказ / нет).

#### 2.2. Wildberries
- **Базовая страница:** `https://www.wildberries.ru/catalog/0/search.aspx?search={query}&sort=price` (сортировка по цене)
- **Извлекаемые поля из списка:**
  - `title`, `price`, `rating`, `reviews_count`, `link`, `image`.
- **Извлекаемые поля из карточки**:
  - `title`, `price`, `old_price`, `rating`, `reviews_count`, `reviews`.
  - `characteristics` — из секции «Характеристики» (состав, материал, размер, страна, артикул, и т.п.).
  - `availability` — наличие (в наличии / нет).

### 3. Дополнительные шаги (функции)

Конфиги должны поддерживать:
- **Поиск с параметрами** — можно передать `min_price`, `max_price`, `sort_by` (price, rating, popularity).
- **Пагинация** — возможность пройти несколько страниц (например, первые 3 страницы).
- **Извлечение отзывов** — извлекать не только рейтинг, но и тексты отзывов (до 5 шт.), чтобы анализировать тональность.
- **Парсинг комплектации** — извлекать все доступные характеристики.

### 4. Интеграция

- Конфиги должны быть в папке `configs/` и загружаться через `config_loader.py`.
- В `web_automation.py` должны быть методы:
  - `search_and_extract(query, site='ozon', limit=20, sort='price', min_price=0, max_price=100000)` — возвращает список товаров.
  - `get_product_details(url, site)` — возвращает детали товара.
  - `get_reviews(url, limit=5)` — возвращает список отзывов.
- Логирование всех действий в `feedback_store` (успех/ошибка, количество извлечённых товаров).
- После извлечения данные автоматически отправляются в **Knowledge Cube** (домен `marketplace`) и **Graphify** (узлы товаров, связей с категориями).

### 5. Тестирование

- После создания конфигов запустить тестовый поиск по запросу «светодиодные лампы» на Ozon и Wildberries.
- Проверить, что извлекаются все поля, цена сортируется по возрастанию, отзывы и характеристики доступны.
- Результат сохранить в JSON для проверки.

### 6. Верификация

- `subagent_verifier` должен проверить корректность конфигов (валидный JSON, наличие обязательных полей).
- `compliance_checker` должен подтвердить, что новый функционал не нарушает правила системы (Zero Trust, Passive Income, Iterative Attack).
- Все изменения закоммитить в Git и обновить бэкап.

### 7. Срок

Выполнить в течение одного цикла (`suggestion_applier` + `web_automation`). Отчёт: «Конфиги для Ozon и Wildberries созданы и протестированы».
