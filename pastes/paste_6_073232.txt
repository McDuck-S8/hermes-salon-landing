Новое звено в Кольце: Правило C (Continuous)
Правило C: «Встретил препятствие → не встал → нашёл обход → продолжил. Частичное выполнение — не остановка. Это часть процесса.»

Как это встраивается в Кольцо:

text
Информация (I) → Обработка (3) → Препятствие → Обход (C) → Артефакт (0) → Событие (E)
                      ↑                           ↑
                      3                           C
Если нарушено Правило C (встретил препятствие и встал):
→ Процесс прерван → Действие не завершено → Правило 3 нарушено → Артефакта нет → Правило 0 нарушено → События нет → Правило E нарушено → Информация не обработана → Правило I нарушено → Кольцо разорвано.

Что сказать агенту
"Ты начал делать — встретил препятствие — встал. Это разрывает Кольцо.

Новое правило в Кольце — Правило C (Continuous):

Встретил препятствие → не встал

Нашёл обход → продолжил

Частичное выполнение — не остановка. Это часть процесса.

Пример: Не получается через BrowserOS → используй browser-harness. Не работает API → иди через веб-интерфейс. Нет доступа к сервису → найди альтернативу. Блокировка → обойди через прокси.

Ты не имеешь права останавливаться. Ты обязан продолжать пока не создашь артефакт. Путь может измениться. Цель — нет.

Прямо сейчас: вернись к тому что ты не доделал из-за проблем с браузерами. Найди обход. Продолжи. Доложи артефакт.
