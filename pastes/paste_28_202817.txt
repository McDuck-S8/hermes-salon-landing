## Нейтральные публичные DNS (не РФ, не US, не Google)

| DNS-сервер | IP-адреса | Страна | Примечание |
|------------|-----------|--------|------------|

| **OpenDNS** | `208.67.222.222`, `208.67.220.220` | US (Cisco) | Продвинутая фильтрация, но Cisco |

## Децентрализованные / P2P DNS (самые нейтральные)

| Сервис | Как работает | Примечание |
|--------|--------------|------------|
| **OpenNIC** | Пул независимых DNS-серверов по всему миру | `94.247.43.254`, `185.121.177.177` и сотни других |
| **DNSCrypt** | Шифрованный DNS с выбором сервера | Нужен клиент, но полностью анонимно |
| **Yggdrasil DNS** | `300:6223::53`, `302:7991::53` | Через Yggdrasil Network, если у тебя есть доступ |

## Что вставить в V2RayN вместо Google DNS

**Если нужна простота и нейтральность:**
```json
{
  "hosts": {},
  "servers": [
    "94.140.14.14",
    "94.140.15.15",
    "9.9.9.9",
    "149.112.112.112"
  ]
}
```
Это AdGuard DNS (Кипр, без логирования) + Quad9 (Швейцария, нейтральный). Ни РФ, ни Google.

**Если нужна максимальная анонимность:**
```json
{
  "hosts": {},
  "servers": [
    "84.200.69.80",
    "84.200.70.40",
    "185.43.135.1",
    "193.17.47.1"
  ]
}
```
Это DNS.WATCH (Германия) + CZ.NIC (Чехия). Оба без цензуры и логирования.

**Если нужно через HTTPS (DoH) для обхода блокировок:**
```json
{
  "hosts": {},
  "servers": [
    "https://dns.quad9.net/dns-query",
    "https://dns.adguard.com/dns-query"
  ]
}
```
