## �� Готовые навыки с GitHub для Hermes

### 1. �� Веб-исследования (headless browser + scraping)

Самый частый запрос. Вот три рабочих варианта:

**Browser Agent** — через MCP (рекомендую)
```bash
git clone https://github.com/letspython/hermes-browser-tool
# Подключается как MCP-сервер, даёт возможность управлять браузером (Chrome/CDP) прямо через Hermes
```

**YouTube Skills** — для стабильного получения транскриптов (решает твою проблему с блокировками на VPS)
```bash
git clone https://github.com/therohitdas/youtube-skills
# 12 суб-скиллов, включая надёжный поиск и транскрипты через TranscriptAPI (15M+ транскриптов в месяц) 
```

**Web scraping через MCP** — универсальное решение
```bash
git clone https://github.com/modelcontextprotocol/servers
# В папке servers/src/webresearch — MCP-сервер для веб-исследований
```

### 2. �� Фоновое обучение (arXiv + RSS + cron)

Готовый автономный пайплайн для ежедневного отслеживания новых статей:

```bash
git clone https://github.com/genggng/hermes-arxiv-agent
# Установка одной фразой в Hermes:
# "Установи skill с https://github.com/genggng/hermes-arxiv-agent"
```

Этот навык автоматически:
- каждый день парсит arXiv по заданным ключевым словам
- скачивает PDF
- генерирует **русские аннотации** через LLM
- определяет авторские аффилиации
- отправляет дайджест в Telegram/Feishu/любой канал (у Hermes 18+ встроенных платформ) 
- ведёт локальную базу прочитанного

Настройка cron в Hermes максимально простая:
```bash
# Прямо в диалоге:
/cron add "every 1h" "Обнови arXiv по ключевым словам LLM/quantization" --skill hermes-arxiv-agent
```

### 3. �� Самооценка и метрики

Hermes имеет встроенную **самооценку через feedback-механизм**. Чтобы активировать:

```bash
git clone https://github.com/CodeSigils/hermes-skill-hq
cp -r hermes-skill-hq ~/.hermes/kb/
# Добавь в ~/.hermes/config.yaml:
# external_dirs:
#   - ~/.hermes/kb
# Затем в Hermes: /reset
```

Что даёт :
- автоматическое отслеживание ошибок и успехов
- навык больше не нужно загружать вручную — Hermes сам подскажет: "Вижу, ты работаешь с X, загрузить skill Y?"
- **саморецензия**: периодический `kb-review` находит устаревшие записи и предлагает улучшить слабые места

### 4. �� Память с семантикой (векторный поиск)

Hermes изначально поддерживает **три уровня памяти**:

```bash
# Установи Skill Forge — реестр с FTS5-поиском и качественными воротами
git clone https://github.com/vystartasv/skill-forge
cd skill-forge
pip install -e ".[dev]"
forge import-hermes   # проиндексирует все твои навыки
```

Что даёт :
- полнотекстовый поиск по описанию и телу навыка
- атомарные транзакции (без коллизий при одновременной записи нескольких агентов)
- автоматическую валидацию качества навыков

В `~/.hermes/` уже лежит SQLite-база, куда Hermes пишет контекст, сессии и опыт. Векторизация включается в конфиге:
```yaml
memory:
  backend: chroma|redis
  embedding: sentence-transformers/all-MiniLM-L6-v2
```

### 5. �� Тестирование своих навыков

Для автоматической валидации созданных навыков:

```bash
git clone https://github.com/vystartasv/skill-forge
cd skill-forge
forge register ~/.hermes/skills/твой-скилл.md
forge validate --name имя-скилла
```

Если навык не проходит проверку (нет YAML-фронтмаtter, не хватает секций), тебе придёт конкретная ошибка.

Дополнительно — навык самотестирования из `hermes-skill-hq` . Он ищет в индексе неиспользуемые или битые ссылки и предлагает их починить.

### 6. �� Проактивность и инициатива

Это главная суперсила Hermes. Проактивность включается на уровне `system prompt` :

```markdown
## Skills (mandatory)
Before replying, scan the skills below. If a skill matches or is even partially relevant to your task, you MUST load it with skill_view(name) and follow its instructions.
```

Что это даёт? Даже если ты не просил `arxiv` skill, но дал задачу "найди новое исследование по LLM", Hermes **сам** загрузит arxiv-скилл и начнёт парсить статьи.

**Периодические инициативы через cron** :
```bash
# Ежечасный сброс контекста и проверка паттернов
/cron add "every 1h" "Анализируй мои последние команды, выяви повторяющиеся запросы" --name "pattern-detector"

# Ежедневный совет в Telegram
/cron add "0 9 * * *" "Сгенерируй 3 проактивных предложения для улучшения моей работы" --skill proactive-advisor
```

## �� Установка и управление

| Что нужно сделать | Команда |
|------------------|---------|
| Проиндексировать все существующие навыки | `forge import-hermes` |
| Найти навык по смыслу | `forge search "web scraping headless browser"` |
| Проверить качество навыка перед загрузкой | `forge validate --name <skill>` |
| Удалить устаревший навык | `forge prune` |
| Подключить внешнюю базу знаний (kb) | добавить `external_dirs` в `~/.hermes/config.yaml`  |

## �� Резюме для тебя

Hermes не просто "набор скиллов". Это **самообучающийся агент** :
- Он сам запоминает твои повторяющиеся задачи и создаёт под них навыки
- У него встроенный **7-дневный цикл оценки и чистки** навыков, которые больше не нужны 
- Он умеет запускать себя по расписанию (`cron`) и возвращать результат в любой мессенджер

Начни с установки **hermes-skill-hq** и **Skill Forge**. Всё остальное подтянется через индекс в течение недели работы.
