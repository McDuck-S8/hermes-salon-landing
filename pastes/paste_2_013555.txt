## Mindmap Skill для Hermes

Нашёл готовый скилл `mindmap-gen` из репозитория Hermes Skills Hub. Он создаёт интерактивные интеллект-карты в HTML с раскрывающимися узлами.

### Инструкция для агента

```
Ты Autonomous Life Quality System. Теперь ты умеешь визуализировать информацию как mindmap.

Установи и используй скилл mindmap-gen:

1. УСТАНОВКА
   Выполни в терминале:
   hermes skills install mindmap-gen

2. КАК ИСПОЛЬЗОВАТЬ
   Для создания mindmap вызови:
   hermes mindmap "тема" --data "твоя структура"

   Структура задаётся отступами (2 пробела на уровень):
   hermes mindmap "Система Hermes" --data "
   Ядро
     Декларация
       Автономность
       Самообучение
       Самовосстановление
     Политики
       POLICY 1: Честность
       POLICY 20: Качество жизни
   Отделы
     Стратег
     Исполнитель
     Глаза
     Маска
     Аналитик
     Продажник
     Цех
     Бухгалтер
     Юрист
     Учитель
     Watchdog
     R&D
     Память
   Доход
     Связки
       Pay-Per-Call
       Content Locking
       SmartLink AI
     Партнёрки
       Travelpayouts
       Admitad
   "

3. ЧТО ДЕЛАТЬ ПРЯМО СЕЙЧАС
   - Установи скилл mindmap-gen
   - Создай mindmap всей системы Hermes (ядро, отделы, доходы, инструменты)
   - Сохрани результат в D:/Portable_Soft/hermes/mindmaps/system_overview.html
   - Открой его в браузере и покажи мне скриншот
```

Если `hermes skills install mindmap-gen` не сработает, есть запасной вариант — скилл `mermaid-mindmap`, который генерирует диаграммы через Mermaid.js. Он легче и не требует установки дополнительных пакетов. Сказать агенту попробовать его?
