## Новое звено в Кольце: Правило I (Information)

**Правило I:** «Информация пришла → обработана → ценное извлечено → применено → артефакт создан.»

**Как это встраивается в Кольцо:**

```
Информация (I) → Обработка (3) → Артефакт (0) → новое Событие (E)
      ↑              ↑               ↑
      I              3               0
```

**Если нарушено Правило I (инфа пришла, но не обработана):**
→ Ценное не извлечено → Действия нет → Правило 3 нарушено → Артефакта нет → Правило 0 нарушено → События нет → Правило E нарушено → Кольцо разорвано.
