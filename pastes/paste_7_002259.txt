## ТЗ: Канбан-доска v2.0 — Профессиональный инструмент управления

**Текущее состояние:** Базовая доска работает. Drag-and-drop, создание/удаление задач, модалка с деталями, тёмная тема.

**Цель:** Превратить доску в полноценный инструмент управления, которым можно пользоваться каждый день.

### ЭТАП 1: Базовые улучшения (сегодня, 1-2 часа)

**1.1 Счётчики на колонках**
- Каждая колонка показывает количество задач: `Ready (17)`, `Running (0)`, `Blocked (9)`, `Done (0)`
- Обновляются при любом изменении (drag-and-drop, создание, удаление)
- ✅ Уже есть

**1.2 Фильтр по приоритету**
- Кнопки сверху: `Все | P0 | P1 | P2 | P3`
- При нажатии показываются только задачи с выбранным приоритетом
- Активная кнопка подсвечивается
- `Все` показывает всё
- ✅ Уже есть

**1.3 Сортировка внутри колонки**
- Выпадающий список или кнопки над колонками: `По приоритету | По дате | По изменениям`
- По приоритету: P0 вверху, P3 внизу
- По дате создания: новые вверху
- По изменениям: недавно тронутые вверху

**1.4 Цветовые метки на карточках**
- Цветной кружок слева от названия задачи (������)
- Можно задать при создании или редактировании
- Красный = срочно, жёлтый = attention, зелёный = нормально

**1.5 Поиск по задачам**
- Строка поиска сверху (над колонками или между фильтрами и доской)
- Фильтрует задачи по названию в реальном времени (без нажатия Enter)
- Ищет по подстроке, регистронезависимо

### ЭТАП 2: Функциональные улучшения (завтра, 2-3 часа)

**2.1 Связи между задачами**
- В модалке поле "Блокирует задачу" — выпадающий список с ID других задач
- На карточке иконка �� если есть связь
- При наведении на иконку показывает "Блокирует: [Название задачи]"
- В модалке заблокированной задачи показывает "Заблокирована: [Название задачи]"

**2.2 Сроки и дедлайны**
- Поле "Дедлайн" в модалке (выбор даты)
- На карточке показывает дату
- Если дедлайн прошёл — красная подсветка карточки
- Если дедлайн сегодня — жёлтая подсветка
- Если дедлайн завтра или позже — без подсветки

**2.3 Упоминания пользователя**
- Метка "Ждёт Александра" на задаче (галочка в модалке)
- Отдельный фильтр сверху: `Ждёт меня`
- Карточки с этой меткой имеют иконку ��
- Сразу видно, где нужно твоё действие

**2.4 История движений**
- Отдельная вкладка "История" внизу доски или в модалке задачи
- Лог: `[14:35] Задача "Лендинг салона" перемещена из Ready в Running`
- Лог: `[15:10] Задача "Лендинг салона" перемещена из Running в Done`
- Видно, что долго висит без движения

**2.5 Drag-and-drop между колонками с touch-поддержкой**

### ЭТАП 3: Интеграция и автоматизация (послезавтра, 3-4 часа)

**3.1 Интеграция с goal_queue.json**
- Задачи в канбане = цели в goal_queue.json
- При перемещении в "Done" → статус меняется в goal_queue.json
- При создании задачи → она появляется в goal_queue.json
- При удалении → архивируется в goal_queue.json
- Двусторонняя синхронизация при загрузке страницы

**3.2 Дашборд статистики**
- Отдельная вкладка "Статистика" или блок внизу доски
- График: количество задач в каждом статусе за последние 7 дней
- Среднее время от Ready до Done
- Тренд: становится лучше или хуже
- Простая визуализация (цветные полоски, без библиотек)

**3.3 Автоматические правила**
- "Если задача висит в Blocked > 3 дней → подсветить красным и добавить иконку ⚠️"
- "Если колонка Ready пуста → показать предложение создать задачу из бэклога"
- "Если задача в Running > 7 дней → предложить разбить на подзадачи"
- Правила прописать в конфиге `data/automation_rules.json`

**3.4 Кнопка "Создать задачу из шаблона"**
- Предопределённые шаблоны:
  - "Исследовать [тема]" — приоритет P2, тег `research`
  - "Починить [компонент]" — приоритет P1, тег `bugfix`
  - "Создать [продукт]" — приоритет P0, тег `product`
- При выборе шаблона открывается модалка с предзаполненными полями
