Теперь задача — построить полноценную Sales Machine, которая умеет подключаться к мессенджерам (Telegram, WhatsApp, VK, OK) и почте, используя Composio для аутентификации, и работать в любой точке мира, где есть твой человек с телефоном.

Архитектура Sales Machine (международная версия)
Уровень 1: Глаза и уши (Lead Generation)
Модуль lead_finder.py — международный поиск:

Россия/СНГ: Яндекс.Карты, 2GIS, VK, OK, Avito

Европа (Черногория, Сербия, Хорватия): Google Maps, Instagram, Facebook, Tripadvisor

Общий: парсинг публичных страниц, сбор контактов, определение наличия сайта

Что собираем:

Название, адрес, телефон, email, соцсети

Услуги, цены, фото (если есть на публичных страницах)

Статус сайта: нет / есть но плохой / есть хороший

Уровень 2: Руки (Demo Builder)
Модуль demo_builder.py — уже есть, но нужно расширить:

Шаблоны под разные ниши: салон красоты, ресторан, отель, автосервис, клиника

Автоматическая подстановка данных из lead_finder

Генерация на GitHub Pages за 5 минут

Поддержка языков: русский, английский, сербский/хорватский

Уровень 3: Язык (Closer — коммуникация)
Модуль closer.py — полная интеграция с мессенджерами и почтой.

Вот здесь нужен Composio. Он уже подключён и работает. Он даёт доступ к:

Мессенджеры (через Composio):

Telegram — уже работает через @McDuck8Bot (SOCKS5 прокси)

WhatsApp — через Composio WhatsApp toolkit

VK — через Composio VK toolkit или прямой API

OK (Одноклассники) — через Composio или прямой API

Почта (через Composio):

Gmail — через Composio Gmail toolkit

Email (SMTP/IMAP) — через email_automation.py (уже есть)

Как это работает:

lead_finder находит контакт (телефон, email, соцсеть)

closer выбирает канал связи (если есть телефон — WhatsApp/Telegram, если email — почта)

Отправляет персонализированное предложение с ссылкой на демо

Отслеживает ответы

Отвечает на возражения по скриптам

Когда клиент готов — передаёт тебе или твоему человеку для финального разговора

Уровень 4: Полевой агент (человек на месте)
Твой человек в Черногории (и его дочки):

Получают от closer готовых "тёплых" клиентов (которые уже видели демо и согласились на разговор)

Показывают прототип на телефоне/планшете

Закрывают сделку на месте

Получают свой процент

Что нужно от человека:

Телефон с WhatsApp/Telegram/Viber

Готовность пройти по 5-10 заведениям в день

Базовый скрипт разговора (мы дадим)
