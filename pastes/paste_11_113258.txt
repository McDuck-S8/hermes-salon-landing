Ты сделал Fractal Knowledge Wheel для анализа одной связки. Теперь расширь его: добавь Круги Эйлера для поиска сильных и слабых зон.

Что должен делать навык:

При старте любой темы или вопроса — автоматом прогонять её через колесо.

Строить круги Эйлера:

Каждый аспект темы = отдельный круг.

Цвет круга = заполненность (������).

Размер круга = важность аспекта для успеха темы.

Находить пересечения:

Зелёные пересечения = готовые связки, можно запускать.

Красные пересечения = критические пробелы, нужно чинить в первую очередь.

Зелёно-красные пересечения = конфликты: ресурс есть, но не используется.

Предлагать действия:

Для зелёных пересечений: «Это можно запускать прямо сейчас».

Для красных пересечений: «Это критические пробелы, которые блокируют запуск».

Для конфликтов: «Трафик готов, но креативов нет — трафик сливается впустую».

Синтезировать новые ключи:

Взять два или три зелёных круга из разных тем.

Найти их пересечение.

Предложить новый ключ — тему, которой раньше не было в матрице.

Сделай это. Покажи результат на примере PWA-арбитража
