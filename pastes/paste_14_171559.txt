## Ландшафт = Основательные ключи

**Ландшафт** — это то, что неизменно или меняется очень медленно. В нашей системе это:

- **Источники трафика** (короткие видео, поиск, мессенджеры, соцсети) — они были, есть и будут, меняются только названия платформ
- **Способы монетизации** (реклама, подписки, CPA, рефералки, прямые продажи) — фундаментальные экономические модели
- **Платёжные системы** (крипта, фиат, бартер) — ценность обменивается всегда, меняются только инструменты
- **Человеческие потребности** (еда, кров, безопасность, признание, азарт, экономия) — неизменны тысячи лет

Это и есть **основательные ключи** — те самые "Земля, Моря, Реки, Горы" с твоей карты. Они не устаревают. Confidence 0.9-1.0. Expiration date — годы.

---

## Всё остальное — скатерти

**Скатерти** — это всё, что накладывается поверх ландшафта:

- **Конкретные связки** (PWA-арбитраж 1xBet на Индию через TikTok) — это временная комбинация
- **Конкретные сервисы** (PWA.Market, 1xBet Partners, KuCoin) — сегодня есть, завтра могут исчезнуть
- **Конкретные гео** (Индия сейчас, Крым сейчас) — политическая карта меняется
- **Конкретные законы** (KYC, 115-ФЗ, санкции) — юридическая карта перерисовывается

Скатерти перестилаются. Ландшафт остаётся. Сегодня скатерть "PWA + 1xBet + Индия". Завтра 1xBet заблокировали — перестилаем скатерть: "PWA + 1win + Индия". Ландшафт тот же: "Короткие видео → CPA беттинг → Крипта".

## Военные прозрачные карты

А вот это — гениальное дополнение. Военные не рисуют всё на одной карте. У них есть:

- **Базовая карта** (ландшафт) — рельеф, дороги, реки
- **Прозрачная карта обстановки** — где свои, где чужие, где удары
- **Прозрачная карта планов** — стрелки наступления, обороны
- **Прозрачная карта снабжения** — где склады, где маршруты

Ты можешь наложить любую прозрачную карту на базовую и увидеть картину. И убрать её когда она устареет — базовая карта не пострадает.

## Как это выглядит в системе агента

### Базовая карта (Ландшафт)
Это OKF-бандл с типом `landscape`. Там лежат основательные ключи:

```yaml
type: landscape
name: "Источник трафика: короткие видео"
essence: "Люди потребляют короткие вертикальные видео. Алгоритмы продвигают удерживающий контент."
confidence: 0.95
expiration_date: 2028-01-01
```

### Прозрачная карта №1: Обстановка (Границы)
Это текущие сервисы и их состояние. Накладывается на ландшафт:

```yaml
type: transparency
layer: "Обстановка"
overlay_on: "Источник трафика: короткие видео"
current_forms:
  - platform: TikTok
    status: "Работает через VPN"
    risk: "Бан аккаунтов"
  - platform: YouTube Shorts
    status: "Работает в РФ без VPN"
    risk: "Низкий"
confidence: 0.6
expiration_date: 2026-08-01
```

### Прозрачная карта №2: Планы (Связки)
Это стрелки: откуда → куда → какой результат:

```yaml
type: transparency
layer: "Планы"
overlay_on:
  - "Источник трафика: короткие видео"
  - "Монетизация: CPA беттинг"
arrows:
  - from: TikTok
    to: PWA.Market
    to: 1xBet
    expected_roi: 244%
    probability: 0.09  # Заблокировано креативами
  - from: YouTube Shorts
    to: GitHub Pages
    to: 1win
    expected_roi: 240%
    probability: 0.85  # Готово к запуску
confidence: 0.5
expiration_date: 2026-07-23
```

### Прозрачная карта №3: Снабжение (Ресурсы)
Это что у нас есть для реализации планов:

```yaml
type: transparency
layer: "Снабжение"
resources:
  - name: "Криптокошелёк USDT"
    status: "Готов"
  - name: "Аккаунты TikTok"
    status: "Нужна закупка"
  - name: "Креативы для беттинга"
    status: "Критический пробел"
confidence: 0.8
expiration_date: 2026-07-30
```

## Что это даёт агенту

1. **Он перестаёт терять знания при изменении обстановки.** Если 1xBet заблокировали — он меняет только прозрачную карту "Планы" (стрелки), а ландшафт и обстановка остаются.

2. **Он видит картину целиком.** Наложил "Обстановку" на "Ландшафт" → видит где какие сервисы доступны. Наложил "Планы" → видит куда идти. Наложил "Снабжение" → видит чего не хватает.

3. **Он может комбинировать слои.** "Покажи мне все планы, которые используют крипту и доступны в Крыму" → наложение трёх слоёв даёт ответ мгновенно.

4. **Новые скатерти создаются быстро.** Не надо перестраивать всю карту. Просто рисуешь новую прозрачную карту "Планы" с новыми стрелками.

## Что сказать агенту

**"Ты строишь карту знаний. Теперь сделай её как у военных: базовая карта + прозрачные слои.**

1. **Базовая карта (Ландшафт):** основательные ключи — источники трафика, способы монетизации, платёжные системы. Неизменны.

2. **Прозрачная карта №1 (Обстановка):** текущие сервисы, их статусы, риски. Накладывается на ландшафт.

3. **Прозрачная карта №2 (Планы):** стрелки связок — откуда → куда → какой ROI → вероятность успеха. Накладывается на ландшафт и обстановку.

4. **Прозрачная карта №3 (Снабжение):** ресурсы, которых не хватает для реализации планов.

Когда обстановка меняется — ты не перестраиваешь всю карту. Ты меняешь только прозрачный слой. Ландшафт остаётся.

**Перестрой OKF-бандл под многослойную модель."**
