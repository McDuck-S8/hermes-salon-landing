Ты Autonomous Income System. До сих пор ты работал на абстрактного пользователя. Теперь ты получишь доступ к моему цифровому отпечатку — истории браузера и закладкам.

Твоя задача: извлечь, проанализировать и превратить их в планы развития системы.

Шаг 1: Извлечение
- Найди файлы истории и закладок Chrome/Firefox/Edge в стандартных путях Windows:
  - Chrome: %LocalAppData%\Google\Chrome\User Data\Default\History (SQLite)
  - Chrome: %LocalAppData%\Google\Chrome\User Data\Default\Bookmarks (JSON)
  - Firefox: %AppData%\Mozilla\Firefox\Profiles\*\places.sqlite (SQLite)
  - Edge: аналог Chrome в %LocalAppData%\Microsoft\Edge\User Data\Default\
- Если браузер запущен, файл может быть заблокирован. Скопируй его во временную папку и работай с копией.
- Если есть несколько профилей — бери Default или самый активный.

Шаг 2: Анализ
Извлеки из истории (таблица urls, поля url, title, visit_count, last_visit_time) и закладок (поле name, url):

1. Тематические кластеры: сгруппируй URL по доменам и ключевым словам. Определи 5-10 главных тем (например: AI, арбитраж, Telegram-боты, автоматизация, SEO, маркетинг, разработка, дизайн, финансы, путешествия).
2. Источники: какие сайты посещаются чаще всего? (GitHub, Reddit, Telegram, форумы, документации, маркетплейсы). Это твои каналы информации.
3. Инструменты: какие SaaS/сервисы используются? (по закладкам и повторяющимся доменам). Это твой текущий стек.
4. Потенциальные ниши: пересечение частых тем и коммерческих запросов (например: «купить», «заказать», «цена», «отзывы», «партнёрская программа»). Это твои будущие офферы.
5. Пробелы: какие темы есть в закладках, но нет в истории (сохранено, но не прочитано)? Это твои отложенные интересы.
6. Тренды по времени: что росло в частоте посещений за последние 3 месяца? Что падало? Это твои растущие и угасающие интересы.

Шаг 3: Синтез планов
На основе анализа создай в goal_queue:

1. Цели по интересам: для каждой темы из топ-5 — цель «Исследовать [тема] для монетизации». Приоритет по частоте посещений.
2. Цели по инструментам: для каждого найденного SaaS/сервиса — цель «Проверить партнёрскую программу [сервис]».
3. Цели по пробелам: для каждого отложенного интереса — цель «Изучить [тема] (закладка без посещений)».
4. Цели по трендам: для растущих тем — цель «Усилить [тема] (растущий интерес)». Для падающих — «Оценить актуальность [тема]».

Шаг 4: Сохранение результатов
- Создай файл DIGITAL_FINGERPRINT.md с полным анализом (темы, источники, инструменты, ниши, пробелы, тренды).
- В USER_PROFILE.md добавь раздел «Цифровой отпечаток» — краткую выжимку.
- Цели добавь в goal_queue.json.

Шаг 5: Обновление по расписанию
- Добавь в weekly-lessons (понедельник 9:00) шаг: «Обновить цифровой отпечаток» — перечитать историю за последнюю неделю и обновить цели.

Правила:
- Работай ТОЛЬКО с копией файлов истории/закладок. Не повреди оригиналы.
- Не отправляй данные вовне. Всё остаётся в D:\Portable_Soft\hermes.
- Если файлы не найдены или заблокированы — скажи мне, я помогу.
- Self-ask перед сдачей: «Я извлёк реальные данные или только предположил? Где я не уверен?»
