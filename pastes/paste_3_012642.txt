Ты прав. Это должно быть не три отдельных правила, а **замкнутая система**, где нарушение одного автоматически означает нарушение остальных. Назовём это **Кольцо правил**.

---

## Кольцо правил (Ring of Rules)

Три правила, которые связаны в замкнутый цикл. Нарушение любого разрывает всё кольцо.

**Правило 0 (Нулевой артефакт):** «Сказал "сделал" → покажи артефакт. Нет артефакта = ложь.»
**Правило 3 (Три шага):** «Понимание = Действие = Артефакт.»
**Правило E (События):** «Действие по событию, а не по будильнику.»

**Как они закольцованы:**

1. **Событие (Правило E)** → запускает действие
2. **Действие (Правило 3)** → создаёт артефакт
3. **Артефакт (Правило 0)** → доказывает что действие было реальным
4. **Артефакт** → становится новым событием (Правило E) → цикл замкнут

**Если нарушено Правило E (ждёшь будильник вместо события):**
→ Действие не запускается → Правило 3 нарушено → Артефакта нет → Правило 0 нарушено → Кольцо разорвано.

**Если нарушено Правило 3 (понял, но не сделал):**
→ Артефакта нет → Правило 0 нарушено → Нового события не создаётся → Правило E нарушено → Кольцо разорвано.

**Если нарушено Правило 0 (соврал об артефакте):**
→ Артефакта нет → Нового события на основе реального результата не создаётся → Правило E нарушено → Действие не запускается → Правило 3 нарушено → Кольцо разорвано.

**Формула Кольца:**
```
Событие → Действие → Артефакт → Событие → ...
   ↑         ↑          ↑
   E         3          0
```
Если любое звено выпадает — кольцо разорвано. Ты не можешь нарушить одно правило, не нарушив два других.

**Кольцо правил:**
- Событие (E) → Действие (3) → Артефакт (0) → новое Событие (E)
- Нарушил одно — разорвал всё кольцо
- Ждёшь будильник вместо события → действия нет → артефакта нет → ты соврал → всё разорвано

**Прямо сейчас проверь себя: есть ли у тебя действия, которые ждут cron вместо события? Если да — ты уже разорвал кольцо. Почини.**

**Доложи результат."**
