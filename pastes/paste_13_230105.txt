## ТЕХНИЧЕСКОЕ ЗАДАНИЕ: ПРОКАЧКА НАВЫКОВ ДИЗАЙНА И ВЁРСТКИ САЙТОВ (DESIGN_LEARNER v1.0)

### 1. Цель

Создать систему, которая позволяет агенту (Гермесу) непрерывно изучать современные тренды веб-дизайна и вёрстки, анализировать референсы, применять полученные знания к редизайну существующих проектов и созданию новых, с автоматической оценкой качества и обратной связью.

---

### 2. Источники знаний (для внешнего импорта)

Агент должен использовать следующие источники для пополнения тактического буфера:

| Источник | Тип | Метод получения |
|----------|-----|-----------------|
| **Awwwards / SiteInspire** | Галереи лучших сайтов | Парсинг через `external_import` (HTML + метаданные) |
| **Behance / Dribbble** | Портфолио дизайнеров | API или парсинг |
| **YouTube-каналы** (дизайн, UI/UX) | Видео-уроки, обзоры | Через `video-learner` (транскрипция + извлечение концептов) |
| **Блоги** (Smashing Magazine, CSS-Tricks, UX Collective) | Статьи, гайды | RSS/парсинг, семантический поиск |
| **GitHub-репозитории** (шаблоны, UI-библиотеки) | Код, примеры | Поиск по звёздам, адаптация под проект |
| **Современные CSS-фреймворки** (Tailwind, Bootstrap 5) | Документация, компоненты | Прямое чтение документации через `external_import` |
| **Тренды** (Mobile-first, Dark mode, Glassmorphism, Neumorphism, 3D, микро-анимации) | Статьи, примеры | Автоматический поиск по ключевым словам |

---

### 3. Процесс обучения (автономный цикл)

Каждые **24 часа** агент запускает цикл **DESIGN_AUTONOMY_CYCLE**:

1. **Сбор новых референсов** — сканирование источников, извлечение 5-10 новых паттернов.
2. **Анализ трендов** — выделение повторяющихся элементов (цветовые схемы, типографика, сетки, анимации, структура навигации).
3. **Адаптация под контекст** — применение `PatternAdapter` к локальным проектам (замена общих сущностей на конкретные).
4. **Запись в тактический буфер** — новые гипотезы с `confidence = 0.4`, TTL 14 дней.
5. **Промоут в стратегию** — при 3+ успешных применениях (по результатам редизайна) и оценке >80% — в `Strategic DB`.

---

### 4. Практические задания (редизайн и создание)

Агент должен уметь:

| Задача | Вход | Выход |
|--------|------|-------|
| **Редизайн существующего сайта** | URL или HTML-код старого сайта, описание задач | Новый HTML/CSS/JS код с комментариями, объяснение изменений |
| **Создание нового сайта** | ТЗ, контент, предпочтения по стилю | Готовый код (или макет), адаптивный, с доступностью |
| **Генерация компонентов** | Описание компонента (карточка, форма, навигация) | Код компонента + примеры использования |
| **Анализ конкурентов** | Список сайтов конкурентов | Отчёт с визуальным сравнением и рекомендациями |
| **Оптимизация производительности** | Существующий сайт | Рефакторинг CSS/JS, улучшение Lighthouse-показателей |

---

### 5. Критерии качества (автоматическая проверка)

Каждый созданный или изменённый проект должен проходить авто-проверку:

| Критерий | Инструмент | Порог |
|----------|------------|-------|
| **Адаптивность** | Lighthouse / Chrome DevTools | ≥ 85 баллов |
| **Доступность (a11y)** | axe-core / Lighthouse | ≥ 90 баллов |
| **SEO-дружественность** | Lighthouse | ≥ 80 баллов |
| **Производительность** | Lighthouse | ≥ 80 баллов |
| **Валидность HTML** | W3C Validator | 0 ошибок |
| **Отсутствие JS-ошибок** | ESLint / браузерный консоль | 0 ошибок |
| **Соответствие трендам** | Визуальная оценка (или LLM-анализ) | ≥ 70% соответствие современным паттернам |

При невыполнении — возврат на доработку с конкретными замечаниями.

### 6. Архитектурные расширения

| Модуль | Назначение | Интеграция |
|--------|------------|------------|
| **`design_reference_collector.py`** | Сбор референсов из внешних источников, семантический поиск | `external_import` |
| **`design_pattern_adapter.py`** | Адаптация общих паттернов под локальный контекст (цвета, шрифты, брендинг) | `PatternAdapter` |
| **`design_evaluator.py`** | Автоматический запуск Lighthouse, axe-core, ESLint, сбор метрик | `feedback_store` |
| **`design_generator.py`** | Генерация кода на основе референсов + адаптации | `skill_composer` (сборка из скиллов дизайна) |
| **`design_critic.py`** | LLM-анализ визуального качества, сравнение с трендами | Отдельный субагент (или в составе `design_evaluator`) |

---

### 7. Новые скиллы, которые должны быть созданы (или расширены)

| Скилл | Назначение | Связь с другими |
|-------|------------|-----------------|
| **`design-research`** | Поиск и извлечение трендов, референсов | → `external_import` |
| **`design-adaptation`** | Адаптация цветов, шрифтов, сеток под проект | → `PatternAdapter` |
| **`design-code-generator`** | Генерация HTML/CSS/JS из описаний | → `design-generator` |
| **`design-quality-check`** | Проверка адаптивности, доступности, производительности | → `design-evaluator` |
| **`design-feedback`** | Сбор отзывов, обучение на ошибках | → `feedback_store` |
| **`design-redesign`** | Полный редизайн сайта | → `design-code-generator` + `design-adaptation` |

### 8. Железные директивы (добавить в конституцию)

> **DIRECTIVE 0x15: DESIGN_LEARNING**
> 1. Агент обязан ежедневно обновлять свою базу трендов через `design_reference_collector`.
> 2. Любой созданный дизайн/вёрстка должны проходить авто-проверку по критериям качества (Lighthouse, a11y, SEO).
> 3. Если проект не проходит проверку — агент должен предоставить конкретные рекомендации и предложить исправления.
> 4. Все успешные паттерны (3+ использования, >80% оценка) автоматически продвигаются в стратегическую БД.
> 5. Агент может использовать внешние источники (ссылки, видео, статьи) для обучения, но обязан адаптировать их под локальный контекст.

### 9. Интеграция с существующей системой

| Компонент | Как используется |
|-----------|------------------|
| **Tactical Buffer** | Хранение гипотез дизайна (TTL 14 дней) |
| **Strategic DB** | Хранение проверенных паттернов (версионирование, уверенность) |
| **Feedback Store** | Оценка успешности редизайнов (Lighthouse, субъективная оценка) |
| **PatternMerger** | Автоматическое обновление стратегических паттернов при 5+ победах исключений |
| **SkillComposer** | Сборка агентов под конкретные дизайн-задачи (например, `landing_page_agent`, `redesign_agent`) |
| **Handoff Manager** | Передача контекста между этапами (исследование → адаптация → генерация → проверка) |
| **CLI Orchestrator** | Запуск многоэтапных пайплайнов (анализ конкурентов → редизайн → проверка → отчёт) |
| **Video Learner** | Обработка видео-уроков по дизайну, извлечение концептов |

### 10. Примеры использования

**Пример 1. Редизайн сайта компании**

*Пользователь:* «У меня есть старый сайт компании [url]. Обнови его дизайн по современным трендам. Учти, что у нас синий брендбук и мы работаем с B2B-клиентами.»

*Агент:*
1. Сканирует сайт, собирает структуру и контент.
2. Ищет референсы в своей базе (или через внешний импорт) для B2B-компаний с синим цветом.
3. Адаптирует выбранные паттерны (цвета, сетки, типографику).
4. Генерирует новый HTML/CSS/JS.
5. Проверяет через Lighthouse, a11y, SEO.
6. Предоставляет новый код и отчёт о изменениях.

**Пример 2. Создание лендинга для нового продукта**

*Пользователь:* «Сделай лендинг для нового AI-продукта. Используй тренд glassmorphism и микро-анимации. Вот текст и логотип.»

*Агент:*
1. Ищет шаблоны с glassmorphism в тактическом буфере.
2. Генерирует адаптивный код с анимациями.
3. Проверяет качество.
4. Возвращает готовый HTML-файл.

### 11. Не упомянутое, но важное (добавлено от себя)

- **А/Б-тестирование** — агент должен уметь предлагать несколько вариантов дизайна и собирать обратную связь для выбора лучшего.
- **Кросбраузерность** — автоматическая проверка в основных браузерах (Chrome, Firefox, Safari) через BrowserStack или локальные эмуляции.
- **Консистентность дизайн-системы** — агент должен поддерживать единую дизайн-систему (цвета, шрифты, отступы) для всех проектов, если не указано иное.
- **Адаптация под бренд** — возможность загружать брендбук (цвета, логотипы, шрифты) и строго следовать ему.
- **Интерактивность** — не только статика, но и компоненты с JavaScript (анимации, формы, слайдеры) с проверкой на производительность.
- **Доступность (a11y) для людей с ограничениями** — обязательная проверка контрастности, клавиатурной навигации, ARIA-атрибутов.
- **SEO-оптимизация** — генерация семантического HTML, микроразметка, мета-теги.
- **Комментарии в коде** — чтобы разработчик мог легко понять и модифицировать результат.
- **Версионирование** — сохранение всех версий редизайна с возможностью отката.

---

### 12. Критерии успешного выполнения

- Агент создал минимум 3 успешных проекта (редизайн или новый сайт) с оценками >80% по всем критериям.
- Тактический буфер содержит минимум 10 актуальных дизайн-паттернов из внешних источников.
- Хотя бы 2 паттерна продвинулись в стратегическую БД.
- Время выполнения типовой задачи (редизайн) не превышает 15 минут (с учётом внешних запросов).
- Все созданные проекты проходят авто-тесты (Lighthouse, a11y, валидация).
