На `chat.deepseek.com` работают две модели, которые **имеют зрение** (умеют анализировать изображения):

---

## 1. DeepSeek-Vision (специализированная модель)

**Что умеет:**
- Принимает изображения на вход (скриншоты, фото, PDF)
- Анализирует визуальный контент: текст на картинке, графики, схемы, UI/UX
- Может сравнивать изображения, находить различия
- Понимает контекст изображения (что на нём происходит)

**Как использовать:**
- В веб-интерфейсе `chat.deepseek.com` — загрузить файл или вставить ссылку на изображение
- Через API (если есть ключ) — передавать base64 или URL изображения

**Ограничения:**
- Не всегда доступна в бесплатном тире
- Может быть медленнее чем DeepSeek-Chat

---

## 2. DeepSeek-Chat (основная модель с поддержкой файлов)

**Что умеет:**
- Принимает загруженные файлы (изображения, PDF, документы)
- Читает текст с изображений (OCR)
- Анализирует содержимое документов
- Может отвечать на вопросы по содержимому файлов

**Как использовать:**
- В веб-интерфейсе — нажать "+" и загрузить файл
- Работает в бесплатном тире

**Ограничения:**
- Хуже чем DeepSeek-Vision для чисто визуального анализа (цвета, композиция, дизайн)
- Лучше для текстового контента на изображениях

---

## Что это даёт твоему агенту

Он может использовать `chat.deepseek.com` как **бесплатный визуальный анализатор** для `uiux-review-crew`:

1. **Сделать скриншот лендинга** (через BrowserOS)
2. **Загрузить скриншот в DeepSeek-Vision** (через веб-интерфейс)
3. **Получить анализ дизайна:** цвета, шрифты, композиция, CTA, проблемы
4. **Сохранить результат** в отчёт

Это решает проблему с неработающим Google Gemini API — не нужно платить за Vision API, можно использовать бесплатный DeepSeek.

---
