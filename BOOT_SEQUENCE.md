## КРИТИЧЕСКИЕ ПРАВИЛА

1. **Строить = подключать.** Новый скрипт БЕЗ импорта из другого = мёртвый скрипт.
2. **1 цель = 1 план.** Без шагов = закрыть цель.
3. **Проверять после написания.** Никогда не помечать "done" без теста.
4. **Не строить новое** пока старое не работает.
5. **Каждое действие → артефакт.** Анализ без действия =浪费.
