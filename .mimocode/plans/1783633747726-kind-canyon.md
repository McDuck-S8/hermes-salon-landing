# Fix: UnicodeEncodeError — emoji в print() на Windows cp1251

## Проблема
`goal_executor.py` и другие скрипты используют эмодзи (🎯, 🚫, ✅, ⏰, 📥, ⛔) в `print()`. На Windows stdout = cp1251, который не поддерживает Unicode. Результат: `UnicodeEncodeError` при каждом вызове.

## Решение
Заменить все эмодзи в `print()` на текстовые метки.

## Файлы для исправления

### Primary: `scripts/goal_executor.py`
~15 мест с эмодзи в `log()` / `print()`:
- L69: `print(line)` — OK (log function itself)
- L206: `🎯 Auto-assigned to:` → `[ASSIGN]`
- L216: `✅ done_when ALL MET` → `[DONE]`
- L220: `⚠️ No command` → `[WARN]`
- L235: `🚫 REJECTED` → `[REJECT]`
- L251: `✅ OK` → `[OK]`
- L258: `⚠️ rc=0` → `[WARN]`
- L264: `❌ FAIL` → `[FAIL]`
- L272: `⏰ TIMEOUT` → `[TIMEOUT]`
- L279: `💥 ERROR` → `[ERROR]`
- L309: `📥 QUEUED` → `[QUEUE]`
- L311: `⛔ REJECTED` → `[REJECT]`
- L319: `🚀 STARTED` → `[START]`
- L352: `✅/❌ DONE` → `[OK]/[FAIL]`

### Secondary: проверить другие скрипты
- `scripts/signal_daemon.py` — содержит эмодзи в print
- `scripts/procedural_executor.py` — содержит эмодзи в print
- `scripts/event_bus.py` — содержит `→` (U+2192) в print

## Подход
1. Найти все `.py` файлы в `scripts/` с эмодзи в print/log
2. Заменить эмодзи на текстовые метки `[TAG]`
3. Не трогать файлы с `ensure_ascii=True` в JSON write (те в порядке)
4. Не трогать `_deprecated/` (READ-ONLY)
