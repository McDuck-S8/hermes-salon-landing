## WP-3: Feedback Loop + Action Weight Learning (Medium Complexity — High Impact)

**Why:** This is the core proactivity engine. Without learning from outcomes, the agent is static.

### Changes

**Create `scripts/action_feedback.py`** (~150 lines)

Core functions:
- `record_outcome(action_id: str, success: bool, evidence: str)` — appends to `cache/action_outcomes.json`
- `compute_weights() -> dict[str, float]` — reads outcomes, calculates success_rate per action_id
- `get_adjusted_score(action: dict, base_score: float) -> float` — applies learned weight to base score

Data format for `cache/action_outcomes.json`:
```json
{
  "outcomes": [
    {
      "action_id": "survive-cron-errors",
      "timestamp": "2026-06-17T...",
      "success": true,
      "evidence": "Restarted 3 jobs, all recovered",
      "session_id": "..."
    }
  ]
}
```

Weight calculation:
```
success_rate = successes / total_attempts (for each action_id)
weight = 0.7 + (success_rate * 0.6)  // Range: 0.7 to 1.3
adjusted_score = base_score * weight
```

Actions with high success rate get a 30% boost; low success rate get a 30% penalty.

**Modify `scripts/autonomous_agent.py`** — `compute_score()` function (line ~571)

Add after existing score calculation:
```python
# Learning adjustment
from action_feedback import get_adjusted_score
score = get_adjusted_score(action, score)
```

**Modify `scripts/autonomous_agent.py`** — `save_decision()` function (line ~2053)

After saving decision, also record outcome:
```python
from action_feedback import record_outcome
success = "EXECUTION ERROR" not in result
record_outcome(action_id=decision["action_id"], success=success, evidence=result[:200])
```

**Create `scripts/learn_actions.py`** (~60 lines) — standalone script for cron
- Reads `cache/action_outcomes.json`
- Computes per-action success rates
- Writes summary to `cache/action_weights.json`
- Reports actions with <30% success rate (candidates for removal)
- Reports actions with >80% success rate (candidates for promotion)

### Cron job

## WP-5: Goal Queue in autonomous_agent (Medium Complexity — Very High Impact)

**Why:** Agent needs to set its own goals, not just pick from a fixed list.

### Changes

**Create `scripts/goal_queue.py`** (~150 lines)

Data store: `cache/goal_queue.json`
```json
{
  "goals": [
    {
      "id": "g-001",
      "title": "Reduce cron error rate below 5%",
      "tier": 1,
      "priority": 8,
      "created_at": "2026-06-17T...",
      "status": "active",
      "progress": 0.3,
      "related_actions": ["survive-cron-errors"],
      "deadline": null,
      "description": "Currently 8/35 jobs have errors"
    }
  ]
}
```

Core functions:
- `create_goal(title, tier, priority, related_actions, description) -> str` — returns goal_id
- `update_goal(goal_id, progress, status)` — update progress/completion
- `get_active_goals() -> list[dict]` — goals sorted by priority
- `evaluate_goals(state) -> list[dict]` — auto-detect goals from system state:
  - cron error rate > 10% → create goal "Reduce error rate"
  - KC white spots > 100 → create goal "Fill knowledge gaps"
  - disk < 20GB → create goal "Free disk space"
  - No recent task completions → create goal "Produce value"
- `goal_to_action(goal) -> dict` — convert goal to autonomous_agent action candidate
- `archive_completed_goals()` — move goals with progress=1.0 to `cache/goal_archive.json`

**Modify `scripts/autonomous_agent.py`**

In `evaluate_actions()` (line ~347), add after existing candidates:
