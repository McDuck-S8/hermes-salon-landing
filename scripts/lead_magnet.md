## 🔌 7 ГОТОВЫХ СХЕМ

### 1. Климат-мониторинг
**ESP8266 + DHT22/AHT10 → MQTT → Home Assistant**  
Графики температуры/влажности за сутки. Уведомления при выходе за пороги.  
**Время сборки: 20 мин**

### 2. Авто-свет по движению
**ESP8266 + PIR (HC-SR501) + реле**  
Свет включается при движении, таймер 30 сек. Режим "не беспокоить" ночью.  
**Время сборки: 30 мин**

### 3. Умная розетка (Sonoff клон)
**ESP8266 + реле в коробке розетки**  
Управление нагрузкой до 10А. Мониторинг тока/мощности (HLW8012).  
**Время сборки: 40 мин**

### 4. Увлажнитель/вентилятор по влажности
**DHT22 + реле на вентиляторе/увлажнителе**  
Пороги в HA: включать при >60%, выключать при <40%.  
**Время сборки: 25 мин**

### 5. Детектор утечки воды
**Датчик утечки (проводной) + ESP8266**  
Мгновенное уведомление в Telegram/HA. Можно добавить электрокран.  
**Время сборки: 15 мин**

### 6. CO2 / качество воздуха
**ESP32 + SCD40/SCD41 (CO2) + реле на вентиляции**  
Авто-проветривание при >1000 ppm. Графики CO2, VOC, температуры.  
**Время сборки: 45 мин**

### 7. Умные шторы/жалюзи
**ESP32 + драйвер шагового (A4988) + концевики**  
Открытие по расписанию / датчику света / кнопке. Позиционирование 0-100%.  
**Время сборки: 60 мин**

## ⚙️ СОФТ: MQTT + HOME ASSISTANT

**MQTT Broker:** Mosquitto (аддон в HA) — порт 1883  
**Прошивка:** ESPHome (YAML) или Tasmota — **без написания кода**

### Пример ESPHome для DHT22 (climate-sensor.yaml):
```yaml
esphome:
  name: climate-sensor
  platform: ESP8266
  board: d1_mini

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_pass

mqtt:
  broker: homeassistant.local
  username: !secret mqtt_user
  password: !secret mqtt_pass

sensor:
  - platform: dht
    model: DHT22
    pin: D4
    temperature:
      name: "Temp"
    humidity:
      name: "Humidity"
    update_interval: 30s
```

**Как прошить:** `esphome run climate-sensor.yaml` (через веб-UI esphome.io) — 5 минут.

## 🚀 ЧТО ДАЛЬШЕ? (ПОШАГОВЫЙ ПЛАН)

1. **Закажи детали** (AliExpress / ChipDip / Ozon) — 3-7 дней доставки
2. **Прошей ESPHome** через веб-интерфейс (esphome.io) — 5 мин на устройство
3. **Добавь в HA:** Настройки → Устройства → ESPHome → "+" → введи IP
4. **Создай автоматизации:** "Если влажность > 70% → вентилятор ON"
5. **Настрой уведомления в Telegram** (HA → Настройки → Уведомления → Telegram Bot)
