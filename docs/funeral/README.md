# Eternal Rest — Funeral Services Demo Website

A studio-quality demo website for a fictional funeral services business, built with vanilla HTML, CSS, and JavaScript.

## Sections
- **Hero** — Full-width gradient with animated entrance, dual CTAs, trust badges
- **Service Packages** — 3-tier pricing (Essential / Traditional / Premium) with featured highlight
- **About** — Company story with stats (30+ years, 5000+ families, 24/7 availability)
- **Why Us** — 4 trust pillars with custom SVG icons (Transparent Pricing, 24/7 Availability, Licensed, Grief Support)
- **Testimonials** — 3 client quotes with star ratings and attribution
- **Contact** — Info panel + validated contact form with success state
- **Footer** — 4-column layout with nav, contact, and CTA

## Design
- **Palette:** Dark Blue (#2c3e50) + Off-White (#ecf0f1) + Muted (#7f8c8d) + Soft Green (#8fbc8f)
- **Typography:** Cormorant Garamond (headings) + Lato (body) via Google Fonts
- **Tone:** Dignified, calm, compassionate — appropriate for funeral services

## Features
- Sticky header with scroll effect
- Mobile hamburger menu with body scroll lock
- Smooth scroll with header offset
- Intersection Observer scroll-reveal animations with stagger
- Active nav link highlighting
- Contact form validation with success state
- Fully responsive (320px → 1920px)

## Tech Stack
- HTML5 semantic elements
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (no frameworks, no jQuery)
- Google Fonts CDN
