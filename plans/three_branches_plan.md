## ВЕТКА 1: ЗАРАБОТОК НА ЧУЖОМ КОНТЕНТЕ

### Цель: первый доход за 2 недели

### Модель: Агрегатор + AI-трансформация + монетизация

| Шаг | Действие | Срок | Статус |
|-----|----------|------|--------|
| 1 | Выбрать нишу (отели Крыма / AI-инструменты / рецепты) | Сегодня | ⏳ |
| 2 | Собрать источники (RSS, API, открытые данные) | 1-2 дня | ⏳ |
| 3 | Написать генератор контента (LLM API) | 2-3 дня | ⏳ |
| 4 | Создать сайт (WordPress или свой генератор) | 3-5 дней | ⏳ |
| 5 | Настроить автопубликацию (cron) | 5-7 дней | ⏳ |
| 6 | Подключить монетизацию (РСЯ/партнёрки) | 7-10 дней | ⏳ |
| 7 | SEO-оптимизация + индексация | 10-14 дней | ⏳ |

### Монетизация:
- Яндекс.РСЯ (50-200₽/1000 показов)
- Партнёрские ссылки (5-15% от продаж)
- Лидогенерация (500-5000₽/заявка)
- Продажа ссылок (осторожно)

### Цель: автономный сайт, который сам наполняется

### Архитектура:

```
Источники контента
├── RSS-ленты
├── API (новости, курсы, погода)
├── Скрейпинг открытых страниц
└── Генерация через LLM
         │

    Обработка
    ├── Чистка и структуризация
    ├── SEO-оптимизация
    ├── Генерация заголовков/мета
    ├── Внутренняя перелинковка
    └── Добавление уникальности (AI-переписывание)
         │
         ▼
    Публикация
    ├── WordPress REST API
    ├── Статический генератор (Hugo/Jekyll)
    └── Свой движок на Python
         │
         ▼
    Монетизация
    ├── Реклама (РСЯ/AdSense)
    ├── Партнёрки
    └── Лидогенерация
```

### Что нужно:
1. Домен + хостинг (500₽/год + 200₽/мес)
2. WordPress или свой движок
3. LLM API (opengateway)
4. Парсеры источников
5. SEO-шаблоны
6. Cron-задачи

### Риски:
- Яндекс банит мусор → делать КАЧЕСТВЕННЫЙ контент

## ВЕТКА 3: ДВИЖОК СУЩНОСТЕЙ

### Цель: выявлять скрытые сущности и облекать в форму

### Архитектура:

```
Входные данные
├── Текст запроса
├── История сессии
├── Контекст (файлы, код, конфиги)
└── Внешние данные (web, API)
         │
         ▼
    Извлечение маркеров
    ├── Явные сущности (имена, места, даты, числа)
    ├── Полуявные (настроение, намерение, стиль)
    └── Скрытые (паттерны, зависимости, предпосылки)
         │
         ▼
    Кластеризация
    ├── Частые → оформляем в сущность
    ├── Редкие → белое пятно (наблюдаем)
    └── Новые → предлагаем форму
         │
         ▼
    Облечение в форму
    ├── Параметр (число, флаг, диапазон)
    ├── Категория (enum, шкала)
    ├── Связь (граф, цепочка)
    ├── Паттерн (regex, template, правило)
    └── Метрика (агрегат, тренд, аномалия)
         │
         ▼
    Хранение
    ├── SQLite (entity_engine.db)
    ├── Knowledge Cube (интеграция)
    └── Memory Tree (связи)
```

### Типы сущностей:

| Тип | Пример | Форма |
|-----|--------|-------|
| Состояние | "пользователь торопится" | Флаг + триггер |
| Намерение | "хочет автоматизировать" | Категория |
| Паттерн | "каждый вечер спрашивает про бота" | Правило |
| Зависимость | "после ошибки всегда переспрашивает" | Граф |
| Скрытый навык | "умеет кодить, но не говорит" | Метрика |
| Эмоция | "фрустрация после 3-й ошибки" | Шкала |
| Контекст | "это продолжение вчерашнего" | Связь |

## ИНТЕГРАЦИЯ ТРЁХ ВЕТОК

```
Ветка 3 (Сущности) → Ветка 1 (Контент)
  Сущности из контента → структурированные данные → монетизация

Ветка 3 (Сущности) → Ветка 2 (Дорвеи)
  Сущности из поисковых запросов → генерация релевантного контента

Ветка 1 (Контент) → Ветка 3 (Сущности)
  Контент → извлечение сущностей → обогащение базы

Ветка 2 (Дорвеи) → Ветка 1 (Контент)
  Автогенерированный контент → монетизация
```

Все дороги ведут в Куб.
