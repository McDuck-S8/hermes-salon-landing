### Готовые решения для комбо-продаж:

1. **Отель + Трансфер**
   - Гость бронирует номер → автоматически предлагает трансфер из аэропорта
   - Комбо-цена: 35 000₽

2. **Ресторан + Доставка**
   - Гость заказывает еду → курьер доставляет
   - Комбо-цена: 20 000₽

3. **Риэлтор + Отель**
   - Турист → показ квартир → проживание в отеле
   - Комбо-цена: 30 000₽

4. **Всё вместе = Экосистема**
   - Один бот для всех сервисов
   - Комбо-цена: 80 000₽
