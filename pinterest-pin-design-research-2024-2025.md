# SYNTHESIS: Top Patterns Across All 10+ Sources (2024/2025)

## 🎨 **Pin Templates That Convert (Priority Order)**
1. **Text Overlay (TOBI)** - 60/40 image/text, benefit headline + CTA button
2. **Carousel/Story Pins** - 3-5 slides, tutorial or transformation narrative
3. **Idea Pins (Vertical Video)** - 15-60 sec, educational/inspirational, native format
4. **Before/After Split** - High contrast, emotional payoff, "Swipe to see"
5. **Listicle/Infographic** - "5 Ways to..." numbered, save-worthy reference

## 🔤 **Typography Styles 2024/2025**
| Style | Font Pairing | Best For |
|-------|-------------|----------|
| **Modern Clean** | Montserrat Bold + Open Sans | Tech, Business, SaaS |
| **Elegant Lifestyle** | Playfair Display + Lato | Home, Fashion, Beauty |
| **Bold Impact** | Oswald ExtraBold + Roboto | Fitness, Finance, DIY |
| **Friendly Approachable** | Nunito Bold + Nunito Regular | Food, Parenting, Crafts |
| **Minimal Luxury** | Cormorant Garamond + DM Sans | High-ticket, Wellness |

**Rules:** Max 2 fonts/pin, Headline 48-60px, Body 20-24px, CTA 18-20px bold, Line height 1.2-1.4

## 🎯 **CTA Formats That Convert (Ranked)**
1. **"Get the Free Guide"** - Lead gen, low friction
2. **"Save for Later"** - Engagement, algorithm signal
3. **"Shop the Look"** - E-commerce, direct intent
4. **"Read Full Tutorial"** - Blog traffic, high value
5. **"Try This Tonight"** - Recipe/DIY, urgency + ease
6. **"Tap for Details"** - Affiliate, soft sell
7. **"Follow for Part 2"** - Video series, retention

**Button Specs:** 28px border radius, 4:1 contrast ratio, 24px min touch target, 16px padding horizontal

## 🎨 **Color Trends 2024/2025 (Pinterest Predicts)**
- **Earth Tones Renaissance:** Terracotta, Sage, Warm Beige, Deep Olive
- **Digital Lavender** + **Muted Coral** (Gen Z appeal)
- **Midnight Navy** + **Champagne Gold** (Luxury)
- **Monochromatic gradients** (single hue, 3-4 stops)
- **Avoid:** Neon, High-saturation primary colors (declining engagement)

## 📐 **Pin Dimensions & Specs 2025**
| Format | Dimensions | Ratio | Max File |
|--------|-----------|-------|----------|
| Standard Pin | 1000 x 1500px | 2:3 | 20MB |
| Square Pin | 1000 x 1000px | 1:1 | 20MB |
| Long Pin | 1000 x 2100px | 2:4.2 | 20MB |
| Carousel | 1000 x 1500px each | 2:3 | 20MB/slide |
| Idea Pin (Video) | 1080 x 1920px | 9:16 | 100MB |

## 🔑 **SEO on Pin (Non-Negotiable)**
1. **Pin Title:** Primary keyword + benefit (max 100 chars)
2. **Pin Description:** 2-3 sentences, 2-3 keywords naturally, CTA, 3-5 hashtags
3. **Alt Text:** Descriptive + keyword (for accessibility + SEO)
4. **Board SEO:** Keyword-rich board titles + descriptions
5. **Profile SEO:** Keywords in display name + bio + website claim
