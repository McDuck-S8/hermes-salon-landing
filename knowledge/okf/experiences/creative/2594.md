ARCHITECTURE: Windows cp1251 encoding constraint for all Python scripts. All print() and log() calls must use ASCII-only characters. Emoji like target, cross mark, warning sign, hourglass, rocket are FORBIDDEN in print statements. Use text tags like [OK], [FAIL], [WARN] instead. Arrow character U+2192 must be replaced with ->. This applies to ALL scripts in the hermes codebase.
