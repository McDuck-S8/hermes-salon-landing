FIX: UnicodeEncodeError in goal_executor.py, event_bus.py, session_boot.py, health_check.py, crystal/core.py, and 25+ other scripts. Root cause: Windows cp1251 stdout encoding cannot render emoji characters used in print() and log() calls. Symptoms: Autonomous action at boot fails with charmap codec error, goal execution crashes before starting. Fix: Replaced all emoji in print/log calls with ASCII text labels: [OK], [FAIL], [WARN], [REJECT], [START], [QUEUE], [TIMEOUT], [ERROR], -> (replaces arrow). safe_print() helper added to goal_evaluator.py for dynamic content like goal titles. Lesson: On Windows, NEVER use emoji in print() - stdout defaults to cp1251. Use ASCII-only log tags.
