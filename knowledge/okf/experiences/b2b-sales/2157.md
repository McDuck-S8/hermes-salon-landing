## 1. CRM: HubSpot vs Pipedrive vs Close vs Attio

### Когда какую брать (жёстко)

| CRM | Для кого | Главная фишка | Боль |
|-----|----------|---------------|------|
| **HubSpot** | B2B, длинные сделки, маркетинг + продажи | Бесплатный вход, экосистема | Дорогой на 3+ пользователях, медленный |
| **Pipedrive** | Малый бизнес, продуктовая воронка | Визуальный pipeline, скорость | Слабая автоматизация без лишних плагинов |
| **Close** | Холодные обзвоны / email-камипании | Встроенный диалайнер и авто-трекинг | Слабый отчётный модуль |
| **Attio** | Tech-стартапы, продуктовые команды | Объектно-реляционная модель (как Notion) | Нет телефонии, не для «тяжёлых» отделов |

### Конфиг по умолчанию (2024)

**Для классического B2B Outbound:**  
HubSpot (Sales Hub Professional) + интеграция с LinkedIn Sales Nav.

**Настройка полей (обязательные):**
- `Lead Score` (формула на основе открытий/кликов)
- `Last Activity Date`
- `Next Step Type` (Call / Email / Demo / Proposal)
- `Intent Signal` (ручной тег или из Clay)

**Пример автоматизации в HubSpot (workflow):**
```
Триггер: Сделка перешла в "Demo Scheduled"
Действие:
  - Создать задачу менеджеру за 2 часа до встречи
  - Отправить напоминание контакту (шаблон с Zoom-ссылкой)
  - Создать deal task на следующий день: "Send proposal"
```

**Для холодных продаж (Close):**
- Включаем **Power Dialer** (режим автодозвона)
- Ставим `call disposition` (Answering Machine / Connected / Not Interested)
- Автоматическая запись звонков → отправка в Gong.

## 2. Sequencing: Outreach vs Salesloft vs Apollo vs Instantly

### Сравнение для практика

| Инструмент | Лучшее для | Ограничение |
|------------|------------|-------------|
| **Outreach** | Enterprise, сложные многоэтапные последовательности | Цена, сложный UI |
| **Salesloft** | Кастомные отчёты и cadence-аналитика | Медленный импорт |
| **Apollo** | Всё в одном (база + последовательность) | Нет глубокой персонализации на уровне шагов |
| **Instantly** | Массовый холодный email (до 10к/день) | Не для звонков и LinkedIn |

### Рекомендуемый выбор

- **Outbound с Research** → Apollo (база) + Outreach (последовательности)
- **Только email-прогрев** → Instantly + отдельный домен

### Типовой workflow в Outreach (или Salesloft)

1. Создать **Cadence**:
   - Шаг 1: Email (день 1)
   - Шаг 2: LinkedIn View (день 2) – вручную
   - Шаг 3: Email (день 4) – с упоминанием компании
   - Шаг 4: Call (день 6) – задача в CRM
   - Шаг 5: Email breakup (день 10)

2. Настройка **условий выхода**:
   - Если replied → стоп
   - Если demo booked → стоп
   - Если bounced → стоп

### Шаблон email (работает в 2024)

**Тема:** `[Company] + [Trigger event]`

**Тело:**
```
Привет, {first_name},

Заметил, что {company} недавно {trigger: открыли вакансию / привлекли раунд / обновили сайт}.

Мы помогаем {value_proposition} без {pain_point}.

Короткое 10-минутное созвон — покажу пример, как это работает у {similar_company}.

Готовы обсудить?
```

## 3. Intelligence: Apollo vs ZoomInfo vs Clay

### Когда что

| Инструмент | Суть | Формат данных |
|------------|------|---------------|
| **ZoomInfo** | Готовая БД + контакты с подтверждённым email | B2B, enterprise |
| **Apollo** | БД + встроенный поиск + экспорт | SMB + Mid-Market |
| **Clay** | Enrichment + кастомный водопад из 50+ источников | Для сложной персонализации |

### Практическая связка №1 (бесплатно-дорого)

**Clay → Apollo → HubSpot**

- В Clay загружаешь список компаний (CSV).
- Настраиваешь **водопад**:
  1. Поиск LinkedIn профиля
  2. Поиск email через Apollo + Hunter + NeverBounce
  3. Обогащение: технологический стек (BuiltWith), ключевые лица (LinkedIn)
- Экспорт в HubSpot через **автоматический webhook**.

### Пример конфига Clay (шаг за шагом)

1. Колонка `company_domain`
2. Enrich: `Find decision-makers` → выбираешь титулы (VP Sales, Head of Growth, CEO)
3. Enrich: `Find work email` → проверка через 3 источника
4. Формула: `If email_valid = TRUE AND title CONTAINS "VP" → set Priority = High`
5. Export в CRM с полями: `first_name, last_name, title, email, company, industry, tech_stack`

## 4. Call Recording: Gong vs Fireflies vs tl;dv

### Реальное применение

| Инструмент | Для кого | Главный юз-кейс |
|------------|----------|-----------------|
| **Gong** | Отделы продаж 20+ | Аналитика разговоров, прогнозы, тренды |
| **Fireflies** | Команды до 10 чел | Авто-заметки, суммаризация, поиск |
| **tl;dv** | Продуктовые / клиентские коллы | Интеграция с Notion, выделение инсайтов |

### Выбор

- Если бюджет позволяет → **Gong** (окупается на сделках от $10k+)
- Для стартапа → **Fireflies** + Zapier → запись в Google Drive

### Настройка Gong (рекомендация)

1. Подключить интеграцию с Zoom/Meet/Teams
2. Включить **auto-join** для всех внутренних встреч
3. Настроить **Trackers**:
   - `Противник` (упоминание конкурентов)
   - `Бюджет` (цифры)
   - `Decision Timeline` (фразы "через месяц", "в следующем квартале")
4. Создать **глобальный дашборд**:
   - Win/Loss по ключевым фразам
   - % времени говорит продавец vs клиент (цель <40%)

## 5. Готовая схема Workflow (целиком)

### День 1. Загрузка лидов
- Apollo → экспорт 500 контактов по ICP
- Clay → обогащение → проверка email
- CSV → HubSpot (через импорт или API)

### День 2. Запуск последовательности
- Outreach: каденция из 5 шагов (Email → LinkedIn → Email → Call → Email)
- Условие: только для `Lead Score > 50`

### День 3-10. Мониторинг
- Открытия и клики → в HubSpot (автоматическое обновление поля `Engagement`)
- Если клик по ссылке → задача SDR на звонок в течение 2 часов

### После звонка
- Gong расшифровывает разговор
- Автоматически создаётся `Call Summary` → в заметку сделки
- Если в разговоре есть "budget approved" → задача на отправку коммерческого предложения
