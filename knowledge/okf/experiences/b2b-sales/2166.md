Вот практический стек продаж 2024 — выбор, связка и автоматизация без переплаты.

---

**1. CRM: Кто и когда**
- **Pipedrive ($24/мес):** для малых команд (<10 чел), продажи по воронке. Сильная сторона — визуальный Kanban и автоматические действия при смене этапа. Минус — слабая отчетность.
- **HubSpot (бесплатно до 5 чел, $50 Pro):** идеален для inbound + контент-маркетинга. Встроенный email-трекер и чат. Сложность — дорогие аддоны (автоматизация — отдельно).
- **Salesforce ($75/мес):** для enterprise (>50 чел). Глубокая кастомизация, но требует администратора. Используйте, если нужно интеграция с ERP/BI.

**Выбор:** стартап → HubSpot, B2B-сделки до $10K → Pipedrive, корпораты → Salesforce.

---

**2. Outreach-платформы**
- **Outreach:** мощный движок последовательностей (A/B-тесты вложений, время отправки). Идеален для сложных многоступенчатых кампаний (7+ касаний). Цена — $100/мес.
- **Salesloft:** проще в настройке, сильный акцент на звонки (локальный caller ID) и диалоговые окна. Используйте при гибридной модели (email + cold calls).
- **Lemlist ($59/мес):** для персонализации на старте — вставка аватаров, видео, персонализированных изображений в письма. Отлично для SMB-сегмента.

**Связка:** Lemlist на холодные лиды → Salesloft для теплых → Outreach для действующих клиентов (при большом объеме).

---

**3. Call Recording & AI-аналитика**
- **Gong:** лидер по транскрипции и выявлению паттернов (паузы, тон, скорость речи). Автоматически определяет «говорящих» и % времени продавца. Цена ~$200/мес.
- **Chorus (ZoomInfo):** сильный в анализе эмоций (voice tone) и интеграции с Salesforce — сделки подсвечиваются красным, если падает энтузиазм клиента.
- **Fireflies ($19/мес):** бюджетный вариант, автоматически заходит в Zoom/Teams, расшифровывает и создает саммари. Недостаток — нет глубокого скоринга.

**Выбор:** Gong если бюджет позволяет и команда >10, Fireflies — для малого бизнеса.

---

**4. Enrichment (обогащение данных)**
- **Apollo ($49/мес):** база 250M контактов + встроенная последовательность. Используйте для быстрого поиска email/phone по домену.
- **ZoomInfo ($15K/год):** золотой стандарт для enterprise — мобильные номера, прямой dial, обновление должностей в реальном времени. Окупается при ASP > $50K.
- **Clay ($100/мес):** новая звезда — собирает данные из 50+ источников (LinkedIn, Crunchbase, Twitter) в одну таблицу и обогащает GPT-выводами (например, «вероятность бюджета»). Идеален для персонализации.

**Правило:** ZoomInfo для базы, Clay для разовой глубокой разведки по топ-100 аккаунтам.

---

**5. Интеграционная архитектура (без кода)**
**Схема:**
```
Lead (LinkedIn/Web) → Apollo/ZoomInfo (обогащение) → 
Lemlist/Outreach (первый контакт) → 
HubSpot/Pipedrive (CRM, хранение сделок) → 
Gong/Fireflies (запись звонка) → 
BI-дашборд (Power BI/Tableau)
```
**Центральный оркестратор:** Make (бывший Integromat) или Zapier — связывайте через вебхуки:
- При создании сделки в CRM → автоматически запускается последовательность в Outreach.
- При завершении звонка (Gong) → теги в CRM обновляются.
- При изменении статуса (Closed Won) → уведомление в Slack + создание задачи в Asana.

**Настройка:** все API-ключи храните в `.env`, используйте `N8N` для self-hosted (экономия на подписках).

---

**6. Workflow продаж (ежедневный)**
```
08:00 — Загрузка лидов из Apollo (по списку компаний) → обогащение через Clay (GDPR, бюджет)
09:00 — Запуск 2 последовательностей (Lemlist — email + LinkedIn, Salesloft — обзвон)
11:00 — Gong анализирует вчерашние звонки → подсвечивает сделки с риском (низкий тон клиента)
13:00 — Обновление сделок в Salesforce (автоматический импорт из HubSpot через Zapier)
16:00 — Отчет: конверсия этапов, % открытий vs ответов, соотношение звонков к встречам
```

---

**7. Метрики и пороги**
- **Email:**
  - Открытия > 60% (иначе меняйте тему)
  - Ответы > 8% (если ниже — настройка таргетинга)
- **Звонки:**
  - Connect rate > 15% (доля соединений)
  - Разговор > 3 мин (после 2 мин ставьте «квалифицирован»)
- **CRM:**
  - Время сделки (Cycle Time) — сокращайте до 30 дней
  - Win Rate по сегментам (Enterprise vs SMB)

**Инструмент контроля:** `Databox` — визуализация всех KPI на одном экране.
