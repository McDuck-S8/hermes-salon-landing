## Telegram Mini Apps + CPA — бесплатный вход, платформа Telegram

**Источник:** анализ Telegram Mini Apps, 2026-07-13
**Применимо к нам: ДА — проработать**

### Что такое Telegram Mini Apps

Мини-приложения (Mini Apps) — приложения внутри Telegram, работающие через WebApp. Пользователь открывает бота, запускает мини-приложение, выполняет действие.

### Модели монетизации с CPA

1. **Игра + реклама** — пользователь играет, за просмотр рекламы получает бонус. За каждый просмотр — CPA-выплата
2. **Квест с офферами** — пользователь выполняет задания (регистрация, установка приложения) -> получает внутриигровую валюту
3. **Квиз/опрос** — пользователь отвечает на вопросы -> в конце ссылка на партнёра

### Как создать Mini App

- **Фреймворк**: t.me/webapps — официальная документация
- **Для старта**: HTML + JS, хостинг GitHub Pages (бесплатно)
- **Взаимодействие**: Telegram.WebApp API — всё в браузере

### Цифры

- Стоимость создания: $0 (GitHub Pages + HTML/JS бот)
- Время разработки MVP: 2-3 дня
- Конверсия: 10-30% (геймификация повышает CR)
- CPA за действие: $0.50-2.00

**Применимо к нам: ДА — среднесрочно.** Нужно создать бота + Mini App. Сложность выше, чем просто пост, но потенциал выше. Можно сделать один раз и получать пассивный доход.
