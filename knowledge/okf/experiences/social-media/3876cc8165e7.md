## YouTube Shorts / TikTok -> CPA — органический видео-трафик

**Источник:** анализ видео-трафика для CPA, 2026-07-13
**Применимо к нам: ДА — самый перспективный Level 2 канал**

### Схема

1. Создаёшь короткое видео (15-60 сек): лайфхак, совет, подборка, демонстрация
2. В описании/bio — партнёрская ссылка (или ссылка на контент-локер)
3. Видео набирает просмотры -> трафик идёт по ссылке
4. Заработок: CPA за регистрацию/покупку / Content Locking / Маркетплейсы

### Что работает

| Формат | Пример | Конверсия |
|--------|--------|-----------|
| Лайфхак | "Как бесплатно получить Canva Pro" | 5-15% |
| Заработок | "Как я зарабатываю $500 на рефералках" | 3-8% |
| Обзор AI-инструмента | "Gamma делает презентацию за 30 сек" | 2-5% |
| Подборка | "10 приложений которые должны быть у каждого" | 4-10% |
| Сравнение | "VS Code vs Cursor — что лучше?" | 2-6% |

### Вертикали без цензуры

- **TikTok** — жёсткая модерация, нельзя CPA-ссылки в видео. Только bio + призыв
- **YouTube Shorts** — мягче, можно ссылки в описании
- **Instagram Reels** — нельзя ссылки (кроме Stories)

### Инструменты

- **Генерация видео**: CapCut (бесплатно), InShot, Canva видео
- **Голос**: ElevenLabs (5$ credit free)
- **Субтитры**: CapCut (авто)
- **Музыка**: TikTok Sound Library

### Цифры

- 1 видео может набрать 1K-100K просмотров
- CTR из описания: 1-5%
- Доход с 10K просмотров: $5-50 (зависит от оффера)
- Никакого бюджета не нужно — чисто органический трафик

### Вывод
**Применимо к нам: ДА — ПЕРВЫЙ ПРИОРИТЕТ СРЕДИ LEVEL 2.** То, что мы прорабатывали в Content-Locking-CPA. Нужно: 1 аккаунт YouTube для теста, 1 тестовое видео, реф-ссылка на SaaS/маркетплейс/контент-локер.
