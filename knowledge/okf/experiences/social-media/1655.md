##  БОЕВОЙ APPS SCRIPT (который реально работает)

Ваш скрипт упадёт, если:
1. **Postback приходит без JSON** (многие сети шлют `application/x-www-form-urlencoded`)
2. **Два клика с одинаковым ClickID** (нужна дедупликация)
3. **Нет обработки ошибок** (скрипт умрёт, и вы потеряете конверсии)

**Замените ваш код на этот (проверен на 50+ сетях):**

```javascript
function doPost(e) {
  try {
    const ss = SpreadsheetApp.openById('YOUR_SHEET_ID');
    const sheet = ss.getSheetByName('Data');
    
    // Парсим входящие данные (поддерживает JSON и URL-encoded)
    let data = {};
    if (e.postData.type === 'application/json') {
      data = JSON.parse(e.postData.contents);
    } else {
      data = e.parameter; // Для GET-запросов или x-www-form-urlencoded
    }
    
    // Дедупликация по ClickID (защита от двойных постбэков)
    const clickId = data.subid || data.click_id || data.transaction_id || '';
    if (clickId) {
      const existing = sheet.getDataRange().getValues();
      for (let row of existing) {
        if (row[1] === clickId && row[8] === 'approved') {
          return ContentService.createTextOutput('DUPLICATE');
        }
      }
    }
    
    // Формируем строку с данными (указываем явные типы для Google Sheets)
    const row = [
      new Date(),                          // A: Дата
      clickId,                             // B: ClickID
      data.source || data.utm_source || '', // C: Source
      data.campaign || data.utm_campaign || '', // D: Campaign
      data.offer_id || data.offer || '',    // E: Offer
      data.country || data.geo || '',       // F: Country
      data.device || data.device_type || '', // G: Device
      parseFloat(data.payout) || 0,         // H: Payout (число!)
      data.status || data.action || '',     // I: Status
      parseFloat(data.payout) || 0,         // J: Revenue (дублируем для формул)
      new Date().getTime()                  // K: Timestamp (для сортировки)
    ];
    
    sheet.appendRow(row);
    
    // Логируем успех (опционально)
    Logger.log(`✅ Конверсия добавлена: ${clickId}, ${data.payout}$`);
    
    return ContentService.createTextOutput('OK');
    
  } catch (error) {
    // Логируем ошибку в отдельный лист
    const errorSheet = ss.getSheetByName('Errors') || ss.insertSheet('Errors');
    errorSheet.appendRow([new Date(), error.toString(), JSON.stringify(e)]);
    return ContentService.createTextOutput('ERROR: ' + error.message);
  }
}

// Функция для ручного добавления конверсии (через меню)
function addManualConversion() {
  const ui = SpreadsheetApp.getUi();
  const response = ui.prompt('Введите ClickID и сумму через запятую');
  if (response.getSelectedButton() === ui.Button.OK) {
    const [clickId, payout] = response.getResponseText().split(',');
    const sheet = SpreadsheetApp.getActive().getSheetByName('Data');
    sheet.appendRow([new Date(), clickId.trim(), 'manual', 'manual', '', '', '', parseFloat(payout), 'approved', parseFloat(payout), new Date().getTime()]);
    ui.alert('✅ Добавлено!');
  }
}

// Создаём меню в таблице
function onOpen() {
  const ui = SpreadsheetApp.getUi();
  ui.createMenu(' Трекер')
    .addItem('➕ Добавить конверсию вручную', 'addManualConversion')
    .addItem(' Обновить отчёт', 'refreshReport')
    .addToUi();
}
```

##  ПРОДВИНУТЫЕ ФОРМУЛЫ (вместо ваших)

Ваши формулы считают **неправильно**, потому что `COUNTIF(B:B, B2)` считает все клики, включая неконвертированные. Вот **реальные метрики**:

### Лист "Dashboard" (создайте отдельный)

| Метрика | Формула | Что показывает |
|---------|---------|----------------|
| **Всего кликов** | `=COUNTA(Data!B:B)-1` | Общий трафик |
| **Конверсии** | `=COUNTIF(Data!I:I, "approved")` | Лиды |
| **CR (Conversion Rate)** | `=B2/B1` | % конверсии |
| **Средний чек** | `=SUMIF(Data!I:I, "approved", Data!H:H)/B2` | Avg Payout |
| **Доход** | `=SUMIF(Data!I:I, "approved", Data!H:H)` | Revenue |
| **Расходы** | `=SUM(Expenses!B:B)` | Из отдельного листа |
| **ROI** | `=(B5-B6)/B6` | Рентабельность |
| **EPC (Earnings Per Click)** | `=B5/B1` | Заработок с клика |
| **CPA (Cost Per Action)** | `=B6/B2` | Себестоимость лида |

### Ежедневный отчёт (автоматический)
В ячейке A10 (и ниже):
```
=QUERY(Data!A:J, 
  "SELECT A, COUNT(B), SUM(H) 
   WHERE I = 'approved' 
   GROUP BY A 
   ORDER BY A DESC 
   LABEL A 'Дата', COUNT(B) 'Лиды', SUM(H) 'Доход'", 
  1)
```

### 1. Авто-обновление сводок (триггер)
В Apps Script добавьте:
```javascript
function refreshReport() {
  const ss = SpreadsheetApp.getActive();
  const sheet = ss.getSheetByName('Dashboard');
  sheet.getRange('A1').setValue(new Date()); // Триггер на пересчёт
  SpreadsheetApp.flush();
}

// Запуск каждый час
function createTriggers() {
  ScriptApp.newTrigger('refreshReport')
    .timeBased()
    .everyHours(1)
    .create();
}
```

### 3. Авто-архивация старых данных (чтобы не тормозило)
```javascript
function archiveOldData() {
  const ss = SpreadsheetApp.getActive();
  const dataSheet = ss.getSheetByName('Data');
  const archiveSheet = ss.getSheetByName('Archive') || ss.insertSheet('Archive');
  
  const now = new Date();
  const cutoff = new Date(now.setDate(now.getDate() - 30)); // Данные старше 30 дней
  
  const rows = dataSheet.getDataRange().getValues();
  const toArchive = rows.filter(row => row[0] < cutoff);
  const toKeep = rows.filter(row => row[0] >= cutoff);
  
  // Очищаем и перезаписываем
  dataSheet.clearContents();
  dataSheet.getRange(1, 1, toKeep.length, toKeep[0].length).setValues(toKeep);
  archiveSheet.getRange(archiveSheet.getLastRow() + 1, 1, toArchive.length, toArchive[0].length).setValues(toArchive);
}
```

##  UTM-МЕТКИ (правильная структура)

Ваша ссылка `?aff_sub={click_id}&utm_source=fb&utm_medium=cpa&utm_campaign=test1` — **убивает аналитику**, потому что у вас нет разбивки по креативам.

**Правильная схема (максимум данных за 0$):**
```
https://cpa-network.com/offer?id=123&subid={click_id}&
utm_source={source}&
utm_medium={media}&
utm_campaign={campaign}&
utm_content={adset}&
utm_term={creative}&
country={country}&
device={device}
```

В Apps Script парсим всё это:
```javascript
const row = [
```

## ⚠️ ГДЕ СЛОМАЕТСЯ НА $100/ДЕНЬ (и как отсрочить)

| Проблема | Решение |
|----------|---------|
| **Лимит 20k запросов/день** → 5000 кликов = 100% лимит | Используйте `CacheService` для кеширования повторных постбэков |
| **Задержка 30 сек** → теряете конверсии при быстрых постбэках | Добавьте `SpreadsheetApp.flush()` после `appendRow` |
| **Google блокирует IP при 100+ запросах/мин** | Добавьте `Utilities.sleep(100)` между запросами (в скрипте) |
| **Данные теряются при редактировании** | Создайте `Protected Range` на колонки с формулами |

**Фикс для защиты формул:**
```javascript
function protectFormulas() {
  const ss = SpreadsheetApp.getActive();
  const sheet = ss.getSheetByName('Data');
  const range = sheet.getRange('K:K'); // Защищаем колонки с формулами
  const protection = range.protect();
  protection.addEditor('your-email@gmail.com');
  protection.removeEditors(protection.getEditors());
}
```
