Ниже — **краткий фактологический** разбор домена **entertainment (развлечения)** для арбитража трафика. 

---

## 1. Ниши (подтемы)

| № | Ниша | Что внутри |
|---|------|------------|
| 1 | **Гейминг (видеоигры)** | Мобильные игры (кликеры, стратегии, казуалки, gacha), PC/консольные AAA-проекты (Genshin, WoT, PUBG, Dota 2, CS2), инди-игры, киберспорт, внутриигровые покупки, гайды, прохождения, моды, читы |
| 2 | **Стриминг** | Прямые эфиры на Twitch, VK Play, YouTube Gaming, GoodGame — донаты, подписки, спонсорские интеграции, нарезки клипов |
| 3 | **Видеоконтент (лёгкий)** | TikTok-тренды, мемы, челленджи, реакции, ASMR, квизы, видео «смотри до конца», короткий юмор, скетчи |
| 4 | **Фандомы** | Косплей, фан-арт, обсуждения сериалов/фильмов/аниме, фан-сайты, вики, теории, секреты, коллекционирование |
| 5 | **Киберспорт** | Турниры по Dota 2, CS2, Valorant, League of Legends — прогнозы, ставки (в серой зоне), аналитика, трансляции, фэнтези-спорт |
| 6 | **Аудиоразвлечения** | Подкасты (игровые, юмористические, поп-культура), аудиокниги, музыкальные плейлисты, голосовые чаты |
| 7 | **Интерактивные развлечения** | Онлайн-квизы, викторины, розыгрыши, голосования, боты-игры в Telegram, интерактивные сериалы |

## 2. Источники трафика (где сидит аудитория)

| Источник | Формат / механика | Особенность |
|----------|-------------------|-------------|
| **Twitch / VK Play / GoodGame** | Прямые стримы с донатами, реклама в перерывах, интеграции, совместные просмотры | Самая тёплая аудитория, готовая платить донатами и подписками |
| **YouTube** | Летсплеи, обзоры, прохождения, топы, нарезки смешных моментов, шортсы с игровыми фишками, гайды по читам/модам | Огромный органический трафик, долгий просмотр |
| **Telegram** | Игровые каналы с новостями, боты-игры, розыгрыши скинов, файлы с модами, обсуждения, ссылки на стримы | Высокая лояльность, лёгкий сбор базы |
| **Discord** | Серверы по играм, общение, турниры, скрытая реклама офферов, эксклюзивный контент | Высокий CR на внутриигровые покупки |
| **TikTok / VK Клипы / Shorts** | Короткие игровые моменты, челленджи, мемы, косплей, скетчи | Виральность, дешёвый охват, быстрый рост |
| **Форумы (игровые порталы, Reddit, 4pda)** | Обсуждения, гайды, ответы, сигнатуры со ссылками | Недорогой, доверительный трафик |
| **Контекст / таргет** | Яндекс.Директ, VK Реклама по запросам: «скачать игру», «купить скины», «смотреть стрим» | Прогретые лиды с высокой интенцией |
| **Игровые платформы (Steam, VK Play, Epic Games)** | Обзоры, комментарии, группы, форумы | ЦА уже сидит внутри с деньгами |

## 3. Монетизация

| Тип | Что продаём | Формат выплат |
|-----|-------------|---------------|
| **Гейминг-офферы (CPA)** | Установка мобильных игр (кликеры, стратегии, казуалки, gacha) + достижение уровня | $0.5–5 за установку, $3–30 за целевое действие (level 10, донат) |
| **Внутриигровые покупки** | Скины, кейсы, косметика, голда/валюта, сезонные пропуски, DLC, донат в мобильных играх | 10–30% от пополнения (чеки 100–10 000 руб) |
| **Подписки** | PlayStation Plus, Game Pass, VK Play, облачные сервисы (GFN), премиум-аккаунты в играх | 50–300 руб за активацию подписки |
| **Донаты** | Прямые донаты стримерам через DonationAlerts, Streamlabs, VK Donut | % с донатов (партнёрка сервисов) |
| **Мерч** | Футболки, худи, кружки, фигурки, постеры, комиксы, коллекционные предметы | 10–30% от чека (через партнёрки маркетплейсов) |
| **Курсы / гайды** | «Как стать стримером», «Как прокачаться в Dota», «Секреты прохождений», «Настройка OBS» | 500–5000 руб за курс |
| **Контент-локеры** | Скачать мод/чит/гайд можно после подписки на канал или репоста | Сбор базы для прогрева |
| **Рефералки** | Кешбэк с покупок игр в Steam, VK Play, Epic Games; бонусы за регистрацию на игровых платформах | % от покупок / бонусы за регистрацию |

### Итоговый вывод (для стратегии)

- **Тёплые связки**: TikTok/Shorts → Telegram-бот → контент-локер (гайд/мод) → CPA на мобильную игру.
- **Самые конвертируемые офферы**: бесплатные мобильные игры с донатом (CPI + CR) — дают быстрые установки и быстрый возврат.
- **Главное УТП**: эмоция, азарт, «я тоже так могу», «стань топ-1», «получи эксклюзив». Продаём не продукт, а **чувство победы, прогресса или эксклюзивности**.
- **Контент, который всегда работает**: «10 способов пройти босса», «Обзор открытия 100 кейсов», «Как я стал стримером», «Топ-5 модов для Minecraft», «Моменты, которые порвали стрим».
