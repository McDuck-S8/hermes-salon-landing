Ниже — **глубокий разбор** креативов для CPA-арбитража в 2025–2026. Всё максимально прикладное, с конкретными примерами, таймингами и готовыми решениями.

---

## 1. Формула AIDA / PAS / QUEST в видео/картинке

### AIDA (Attention → Interest → Desire → Action)

| Этап | Что делаем | Тайминг (для 30-сек видео) |
|------|------------|---------------------------|
| **Attention** | Хук: вопрос, громкое заявление, неожиданный факт | 0–3 сек |
| **Interest** | Раскрываем проблему/выгоду: «Представь, если бы ты мог...» | 3–10 сек |
| **Desire** | Показываем решение (товар, услугу), эмоционально усиливаем | 10–22 сек |
| **Action** | CTA: «Переходи по ссылке», «Забирай сейчас» | 22–30 сек |

### PAS (Problem → Agitation → Solution)

| Этап | Что делаем | Тайминг |
|------|------------|---------|
| **Problem** | «Ты тратишь 3 часа на ... и всё равно не видишь результата» | 0–5 сек |
| **Agitation** | Усиливаем боль: «А твои конкуренты уже ...» | 5–15 сек |
| **Solution** | Показываем продукт как спасение: «Вот решение — всего за 5 минут» | 15–30 сек |

### QUEST (Question → Understand → Educate → Stimulate → Transition)

| Этап | Что делаем |
|------|------------|
| **Question** | Задаём вопрос, который волнует ЦА |
| **Understand** | Показываем, что понимаем их ситуацию |
| **Educate** | Даём полезную информацию/инсайт |
| **Stimulate** | Усиливаем желание (скидка, бонус) |
| **Transition** | CTA с переходом |

---

### Примеры заголовков / хуков для AIDA

| Оффер | Хук (0–3 сек) |
|-------|---------------|
| Нутра / похудение | «Как я сбросила 15 кг за месяц без диет?» |
| Гейминг | «Ты всё ещё качаешь героя неделями?» |
| Финансы | «Один инструмент, который сэкономит тебе 5000 ₽ в месяц» |

---

### Визуальные элементы

| Элемент | Как использовать |
|---------|------------------|
| Текст на экране | Крупный, контрастный, по центру |
| Подсветка продукта | Обводка, стрелка, зум на товаре |
| Эмодзи/анимация | ❗ — добавляйте в моменты CTA |
| Лицо/эмоция | В моменты «ага-реакций» (удивление, радость) |

---

### Когда работает лучше

- Сложные продукты (B2B, финансы, обучение) — AIDA.
- Боль / срочность (нутрянка, товарка) — PAS.
- Инфобизнес, курсы — QUEST.

## 2. Негативный маркетинг / «боль»

### Формула

| Шаг | Пример |
|-----|--------|
| 1. Назовите проблему | «Хватит тратить деньги на контекст, который не работает» |
| 2. Усильте последствия | «Ты сливаешь бюджет, а клиенты уходят к конкурентам» |
| 3. Дайте решение | «Есть способ — лови гайд» |
| 4. CTA | «Переходи, пока не поздно» |

---

### Примеры заголовков (для картинки/видео)

| Тема | Заголовок |
|------|-----------|
| Бизнес/маркетинг | «Почему твой сайт не продаёт? (5 фатальных ошибок)» |
| Красота/здоровье | «Ты всё ещё используешь эту маску? Она разрушает кожу» |
| Гейминг | «Твой чит замедляет ПК? Вот что реально работает» |
| Саморазвитие | «Ты теряешь годы жизни из-за этой привычки» |

---

### Визуальные элементы

| Элемент | Как использовать |
|---------|------------------|
| Красный/чёрный фон | Создаёт ощущение тревоги |
| Крупный текст «СТОП» / «НЕТ» | Привлекает внимание |
| Лицо с эмоцией страха/удивления | Усиливает эмпатию |
| Скриншот проблемы | Например, график с падением |

---

### Когда работает лучше

- Финансы, инвестиции, бизнес-офферы.
- Товарка с «ошибками» конкурентов.
- Любая вертикаль, где можно бить в страх потери денег/времени.

## 3. Социальное доказательство (скрины, отзывы, кейсы)

### Формула

| Шаг | Пример |
|-----|--------|
| 1. Покажите результат | «Как я заработал 100 000 ₽ за первую неделю» |
| 2. Добавьте детали | Скрин выплаты, график роста |
| 3. Добавьте лицо/историю | «Обычный парень из провинции» |
| 4. CTA | «Хочешь также? Переходи» |

---

### Примеры заголовков

| Тема | Заголовок |
|------|-----------|
| Заработок | «Она заработала 1000$ за 2 дня, просто сидя дома» |
| Похудение | «Как я убрал живот за 14 дней — честный отзыв» |
| Обучение | «Сменил профессию за 3 месяца — моя история» |
| БАДы/витамины | «Врачи не верили, но это сработало» |

---

### Визуальные элементы

| Элемент | Как использовать |
|---------|------------------|
| Скриншот выплаты/графика | Крупно, с суммой, датой |
| Фото «до/после» | Для нутры, фитнеса, лайфстайла |
| Оценка «5 звёзд» | Визуальный блок |
| Комментарий реального человека | С фото профиля и датой |
| Сравнительная таблица | «Было / Стало» |

---

### Когда работает лучше

- Финансовые офферы, партнёрки.
- Нутра, похудение, БАДы.
- Курсы, обучение, саморазвитие.
- Любые продукты, где нужен высокий уровень доверия.

## 4. Интрига / Клиффхэнгер

### Формула

| Шаг | Пример |
|-----|--------|
| 1. Создайте тайну | «Я не мог в это поверить, но это работает на 100%» |
| 2. Не раскрывайте сразу | «То, что ты сейчас увидишь — изменит твой подход» |
| 3. Намёк на решение | «Простой трюк, о котором молчат эксперты» |
| 4. CTA | «Подпишись / перейди, чтобы узнать» |

---

### Примеры заголовков

| Тема | Заголовок |
|------|-----------|
| Заработок | «Один лайфхак, который за 5 минут принёс мне 10 000 ₽» |
| Гейминг | «Секрет, который скрывают от топ-игроков» |
| Фитнес | «Всего одно упражнение, о котором молчат тренеры» |
| Лайфстайл | «Эта привычка разрушает твою жизнь (и ты её даже не замечаешь)» |

---

### Визуальные элементы

| Элемент | Как использовать |
|---------|------------------|
| Затемнение/замочек | Визуализация «секрета» |
| Звук «барабаны» | В момент раскрытия |
| Вопросы на экране | «А ты пробовал?», «Что бы ты выбрал?» |
| Размытие/цензура | Закрытое лицо, скрытый текст |

---

### Когда работает лучше

- Тизеры/прелендинги (кликбейт).
- Для сбора лидов с малой вовлечённостью.
- Sweeps, гейминг, лёгкие офферы.
- Контент, где важна эмоция «любопытство».

## 5. Нативная интеграция / UGC-стиль

### Формула

| Шаг | Пример |
|-----|--------|
| 1. Естественный вход | «Я случайно наткнулся на ... и не мог поверить» |
| 2. Честный обзор | «Это не реклама, просто делюсь» |
| 3. Покажите пользу | «Теперь я экономлю 2 часа в день» |
| 4. CTA мягкое | «Кому надо — ссылка в описании» |

---

### Примеры заголовков

| Тема | Заголовок |
|------|-----------|
| Любая | «Нашла крутую вещь!» |
| Нутра | «Заказала случайно, но теперь пью каждый день» |
| Гейминг | «Скачал приложение и ...» |
| Бизнес | «Перешёл по ссылке — не пожалел» |

---

### Визуальные элементы

| Элемент | Как использовать |
|---------|------------------|
| Фронтальная камера | «Говорю с тобой лично» |
| Естественное освещение | Минимум продакшна |
| Руки/предметы | Показываем продукт в реальной жизни |
| Сторис-формат | Вертикально, наложенный текст |

---

### Когда работает лучше

- Instagram / TikTok / Telegram (где важна персонализация).
- Продукты с быстрым принятием решения.
- Для аудитории, которая устала от «продающих» креативов.

##  МОЙ ВЫБОР — 3 формулы для тестирования на старте

### 1. **Интрига + Срочность** (для быстрых офферов)
- Пример: «Секрет, который скрывают... — всего 3 дня осталось»
- Почему: высокий CTR, мало контента.

### 2. **Боль + Решение (PAS)** (для товарки/нутри)
- Пример: «Ты сливаешь деньги на [X], а работает только [Y]»
- Почему: бьёт в боль, хорошая конверсия в лид.

### 3. **UGC + Соц. доказательство** (для доверительных офферов)
- Пример: «Я в шоке от результата... (скрин)»
- Почему: максимальное доверие, минимальный бан.

## Главный совет 2025–2026

> **Смешивайте подходы.**  
> Одно видео = Интрига (начало) + Боль (середина) + Доказательство (скрин/отзыв) + Мягкий CTA.  
> Так вы попадаете во все эмоциональные триггеры и не даёте зрителю заскучать.
