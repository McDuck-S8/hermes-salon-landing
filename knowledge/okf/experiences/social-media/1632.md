Ниже — **глубокий разбор** источников трафика для CPA-арбитража в 2025–2026. Всё максимально прикладное, с цифрами, рисками и готовыми решениями.

## 1. TikTok Ads

| Параметр | Значение |
|----------|----------|
| **Мин. депозит** | $50–200 (через агентство от $100) |
| **Стоимость клика (CPC)** | $0.10–0.50 (RU), $0.30–1.00 (USA) |
| **Стоимость лида** | $0.50–5.00 (SOI), $5–20 (CPL), $10–50 (CPS) |
| **Типичный ROI** | 10–40% (у новичков), 50–150% (у профи) |
| **Сложность входа** | ★★★☆☆ (средняя: нужны креативы и понимание трендов) |
| **Риск блокировок** | ★★★★☆ (высокий, особенно для нутры/дейтинга) |

---

### Таргетинг

| Параметр | Возможности |
|----------|-------------|
| **Демография** | Возраст, пол, язык, местонахождение |
| **Интересы** | Категории (игры, фитнес, путешествия) |
| **Поведение** | Вовлечённость, типы устройств, операторы |
| **Lookalike (LLA)** | Аудитории по пикселю, активности в приложении |
| **Хэштеги** | Таргетинг по использованным хэштегам в видео |
| **Комментарии** | Таргетинг на тех, кто комментировал похожие видео |

---

### Креативы (что работает)

- **UGC-стиль** (снимайте на телефон, без продакшена).
- **Трендовые звуки** — 80% успеха.
- **Первый кадр** — хук за 0.5 секунды.
- **Интерактив** (опросы, вопросы в конце).
- **Адаптация под вертикаль** (9:16, не обрезайте).
- **Для нутры** — «до/после», отзывы, трансформации.
- **Для игр** — геймплей + эмоции.
- **Для sweeps** — «выиграй приз», срочность.

---

### Бюджеты и стратегии

| Стратегия | Бюджет на тест | Длительность |
|-----------|---------------|--------------|
| **Тест креативов** | $20–50 на группу | 1–2 дня |
| **Тест аудиторий** | $30–100 на аудиторию | 2–3 дня |
| **Масштабирование** | $100–500/день | 5–7 дней |

---

### Модерация и клоакинг

| Метод | Описание |
|-------|----------|
| **Белый прелендинг** | Ссылка ведёт на нейтральную статью/блог (без оффера) |
| **Клоакинг** | Через сервисы (Keitaro, Binom) — боту TikTok показываем белую страницу, пользователю — оффер |
| **Агентства** | Дают аккаунты с историей, помогают с модерацией |
| **Маскировка** | Используйте ссылки-редректы (Bitly, Rebrandly) |

---

### Чек-лист запуска TikTok Ads

| № | Действие |
|---|----------|
| 1 | Зарегистрируйтесь в TikTok Business |
| 2 | Подготовьте 3–5 креативов (UGC + трендовый звук) |
| 3 | Настройте прелендинг (белый, без ссылок на оффер) |
| 4 | Создайте кампанию с бюджетом $50 |
| 5 | Запустите тест на широкую аудиторию (18–35, пол, GEO) |
| 6 | Остановите через 24 часа, проанализируйте CTR/CPC |
| 7 | Масштабируйте лучший креатив с LLA-аудиторией |

---

### Частые ошибки новичков

| Ошибка | Решение |
|--------|---------|
| Прямая ссылка на оффер | Используйте прелендинг или клоакинг |
| Скучный первый кадр | Делайте динамичное начало |
| Игнорирование трендов | Следите за звуками и форматами |
| Слабый CTA | Добавьте «Скачай сейчас», «Успей» |

## 2. Facebook/Instagram Ads

| Параметр | Значение |
|----------|----------|
| **Мин. депозит** | $100–500 (агентский аккаунт), $0–50 (личный) |
| **Стоимость клика (CPC)** | $0.20–1.00 (RU), $0.50–3.00 (USA) |
| **Стоимость лида** | $1–10 (SOI), $5–30 (CPL), $20–100 (CPS) |
| **Типичный ROI** | 20–60% (новички), 80–200% (профи с клоакингом) |
| **Сложность входа** | ★★★★☆ (высокая: баны, BM, пиксели) |
| **Риск блокировок** | ★★★★★ (очень высокий для нутры/дейтинга) |

---

### Business Manager (BM) и аккаунты

| Тип | Описание |
|-----|----------|
| **Личный BM** | Можно создать 1–2, но быстро банят |
| **Арендованный BM** | От 1000–5000 руб/мес, с историей |
| **Фарм-аккаунты** | Покупаются на биржах, нужны для заливки |
| **Агентские аккаунты** | Дают высокие лимиты, проходят модерацию |

---

### Клоакинг на Facebook

| Метод | Сложность | Цена |
|-------|-----------|------|
| **Keitaro/Binom** | Средняя | $50–100/мес |
| **TrafficArmor** | Низкая | $30–50/мес |
| **Ссылка-редирект** | Низкая | Бесплатно (Bitly) |
| **Прелендинг + маскировка** | Высокая | $100–200 на настройку |

---

### Пиксель и CAPI (Conversion API)

| Что нужно | Зачем |
|-----------|-------|
| **Facebook Pixel** | Сбор данных для оптимизации |
| **CAPI** | Передача конверсий напрямую с сервера (не из браузера) — меньше блокировок |
| **API-ключ** | Получить в настройках Business Manager |
| **Настройка в трекере** | В Binom/Voluum указать токен CAPI |

---

### Чек-лист запуска на Facebook/Instagram

| № | Действие |
|---|----------|
| 1 | Приобретите или создайте BM с историей |
| 2 | Настройте пиксель + CAPI в трекере |
| 3 | Подготовьте 5–10 креативов (фото + видео) |
| 4 | Создайте прелендинг и настройте клоакинг |
| 5 | Запустите тестовую кампанию на широкую аудиторию ($50) |
| 6 | Отслеживайте CPC/CTR через 24 часа |
| 7 | Масштабируйте через Lookalike-аудитории |

---

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Нет CAPI | Настройте обязательно — снижает бан |
| Один креатив | Тестируйте 5–10 вариантов |
| Бюджет $10 | Минимум $50 для теста |
| Прямая ссылка на оффер | Обязательно прелендинг |

## 3. Telegram Ads / Telegram-каналы

| Параметр | Значение |
|----------|----------|
| **Мин. депозит** | $0–50 (ручной закуп), $100–500 (через Telegram Ads) |
| **Стоимость клика (CPC)** | $0.02–0.10 (RU), $0.05–0.20 (EU) |
| **Стоимость лида** | $0.20–2.00 (SOI), $1–5 (CPL) |
| **Типичный ROI** | 50–150% (один из самых высоких) |
| **Сложность входа** | ★★☆☆☆ (низкая) |
| **Риск блокировок** | ★☆☆☆☆ (минимальный) |

---

### Форматы закупа

| Формат | Описание | Стоимость |
|--------|----------|-----------|
| **Пост в канале** | Текст + ссылка, закреп на 24 часа | $5–50 (за канал 10–100k подписчиков) |
| **Тизерка (реклама в ботах)** | Баннер/текст в рекламных ботах | $0.005–0.02 за показ |
| **Боты-каталоги** | Каталог каналов с платными местами | $10–100/мес |
| **Telegram Ads (официальная)** | Таргетинг по GEO, языку, темам | CPM $1–5 |

---

### Где искать каналы

| Источник | Что даёт |
|----------|----------|
| **Telegram-каталоги (Telemetr, Telegrams)** | Список каналов по тематике |
| **Поиск в Telegram** | «CPA», «заработок», «купить рекламу» |
| **Биржи рекламы** (telega.in, tgstat) | Цена за пост, статистика |
| **Конкурентный анализ** | Смотрите, где льют другие арбитражники |

---

### Таргетинг в Telegram Ads (официальный)

- GEO (страна, город).
- Возраст (18–65+).
- Пол.
- Интересы (категории: игры, бизнес, технологии).
- Подписки на каналы (таргетинг по подписчикам конкурентов).

---

### Чек-лист запуска в Telegram

| № | Действие |
|---|----------|
| 1 | Найдите 5–10 каналов по вашей тематике |
| 2 | Проверьте ER (Engagement Rate) — > 5–10% |
| 3 | Договоритесь о посте (текст + ссылка или преленд) |
| 4 | Запустите тестовый пост ($20–50) |
| 5 | Отследите переходы через UTM-метки |
| 6 | Повторите на лучших каналах, масштабируйте |

---

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Не проверяете ER | Используйте Telemetr/TGStat |
| Дорогой пост на непроверенном канале | Начните с $5–10 |
| Прямая ссылка | Всегда UTM-метки |
| Один пост | Закупайте серию постов на нескольких каналах |

## 4. Google Ads (UAC, Search, Display)

|----------|----------|
| **Мин. депозит** | $100–500 (агентский аккаунт) |
| **Стоимость клика (CPC)** | $0.30–2.00 (Search), $0.10–0.50 (Display/UAC) |

| **Типичный ROI** | 10–30% (без клоакинга), 50–100% (с клоакингом) |
| **Сложность входа** | ★★★★☆ (высокая: модерация, политики) |
| **Риск блокировок** | ★★★★★ (очень высокий для нутры/дейтинга) |

---

### Форматы Google Ads

| Формат | Для чего |
|--------|----------|
| **Search (поиск)** | Горячие запросы: «купить», «скачать», «заказать» |
| **Display (баннеры)** | Ретаргетинг, охват на сайтах-партнёрах |

---

### Политики и клоакинг

| Метод | Описание |
|-------|----------|
| **Клоакинг (Keitaro/Binom)** | Google-боту показываем белую страницу |
| **Редирект по User-Agent** | Скрипт определяет бота Google и отдаёт белую версию |
| **Агентские аккаунты** | Дают белый траст, меньше банят |
| **Grey-аккаунты** | Покупаются на биржах, с уже прошедшей модерацией |

---

### Чек-лист запуска Google Ads

| № | Действие |
|---|----------|
| 1 | Приобретите агентский или grey-аккаунт |
| 2 | Настройте прелендинг + клоакинг |

| 4 | Для Search — соберите семантику через Google Keyword Planner |
| 5 | Запустите кампанию с бюджетом $50–100 |
| 6 | Следите за CPC и CR, отключайте слабые ключи |
| 7 | Масштабируйте на высококонверсионные запросы |

---

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Нет клоакинга | Бан через 1–2 дня |
| Узкая семантика | Используйте 100+ ключей на тест |
| Слабые креативы для UAC | Делайте 5–10 вариантов |
| Отсутствие CAPI | Настройте передачу конверсий в Google |

## 5. Нативка / Push / Pop (Propeller, RichAds, AdMaven, Monetizer)

| Параметр | Значение |
|----------|----------|
| **Мин. депозит** | $50–100 |
| **Стоимость клика (CPC)** | $0.005–0.05 (Pop), $0.05–0.30 (Push), $0.10–0.50 (Native) |
| **Стоимость лида** | $0.30–3.00 (SOI), $2–10 (CPL) |
| **Типичный ROI** | 20–80% (зависит от оффера и настройки) |
| **Сложность входа** | ★☆☆☆☆ (низкая) |
| **Риск блокировок** | ★☆☆☆☆ (минимальный) |

---

### Сравнение форматов

| Формат | Плюсы | Минусы |
|--------|-------|--------|
| **Pop (попап)** | Дешево ($0.001–0.005/показ), много трафика | Низкое качество, боты, нужно много трафика для окупаемости |
| **Push (уведомления)** | Тёплый трафик, высокий CTR (10–30%) | Сложно масштабировать, ограниченный объём |
| **Native (нативка)** | Доверительный трафик, высокие CR | Дороже ($0.10–0.50/клик), ограниченные площадки |

---

### Важнейший параметр: вайт-листы (white lists)

| Что это | Как использовать |
|---------|------------------|
| Список сайтов/Zones с высокой CR | Собираете в процессе теста (2–3 дня), затем льёте только на них |
| Где брать | В Propeller/RichAds есть статистика по зонам, используйте её |
| Зачем | Повышаете ROI в 2–5 раз, отсекая мусорные сайты |

---

### Настройка кампании на Propeller Ads (пример)

| № | Действие |
|---|----------|
| 1 | Выберите формат (Pop/Push/Native) |
| 2 | Укажите GEO (RU, USA, EU) |
| 3 | Настройте бюджет ($50–100/день) |
| 4 | Запустите тест на всех зонах |
| 5 | Через 2–3 дня соберите вайт-лист (зоны с CR > 2–5%) |
| 6 | Создайте кампанию только на вайт-листе |
| 7 | Масштабируйте, повышайте ставки на топ-зоны |

---

### Чек-лист запуска на Propeller/RichAds

| № | Действие |
|---|----------|
| 1 | Зарегистрируйтесь в сети (Propeller, RichAds, AdMaven) |
| 2 | Пополните баланс ($50) |
| 3 | Создайте кампанию с одним оффером |
| 4 | Запустите на всех зонах (GEO, бюджет $50) |
| 5 | Соберите статистику за 24–48 часов |
| 6 | Сформируйте вайт-лист |
| 7 | Запустите вторую кампанию только на вайт-листе |

---

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Покупаете трафик без вайт-листа | Сначала соберите вайт-лист |
| Слишком маленький бюджет на тест | Минимум $50 |
| Не используете частотные кэпы | Добавьте ограничение показов на пользователя |
| Игнорируете мобильный трафик | Большинство попапов — мобильные |

##  МОЙ ВЫБОР: 2 источника для старта с $0–100

### Источник №1: Telegram-каналы (ручной закуп)

| Почему | Обоснование |
|--------|-------------|
| **Низкий порог** | Можно начать с $20–30 |
| **Минимальный риск** | Нет блокировок |
| **Высокий ROI** | До 150% при правильном подборе каналов |
| **Простота** | Не нужны аккаунты, клоакинг, пиксели |

---

### Источник №2: Pop/Push (Propeller Ads + вайт-листы)

| Почему | Обоснование |
|--------|-------------|
| **Быстрый тест** | $50 достаточно для сбора данных |
| **Гибкость** | Можно тестировать много офферов |
| **Без блокировок** | Белый трафик |
| **Автоматизация** | Настройки сохраняются на недели |

---

### План запуска (с бюджетом $100)

| День | Бюджет | Действие |
|------|--------|----------|
| **День 1** | $20 | Зарегистрируйтесь в 2 CPA-сетях (CPAGrip, AdCombo) |
| **День 2** | $30 | Выберите оффер (Sweeps или Nutra) и создайте прелендинг |
| **День 3** | $30 | Запустите тест в Propeller Ads (поп-трафик, $30 на все зоны) |
| **День 4** | $20 | Соберите вайт-лист, запустите кампанию только на топ-зоны |
| **День 5** | $0 | Анализируйте ROI, масштабируйте прибыльные офферы |

---

### Распределение бюджета ($100)

| Статья | Сумма |
|--------|-------|
| Тест в Propeller (попы) | $30 |
| Тестовый пост в Telegram-канале | $20 |
| Трекер (Keitaro/Binom, первый месяц) | $20 |
| Прелендинг + хостинг | $10 |
| Резерв на масштабирование | $20 |

---

### Что делать, если $0 (полный старт с нуля):

| № | Действие |
|---|----------|
| 1 | Зарегистрируйтесь в CPAGrip (бесплатно) |
| 2 | Возьмите оффер с бесплатным прелендингом от сети |
| 3 | Найдите 3–5 Telegram-каналов с бесплатными постами (или по бартеру) |
| 4 | Заливайте трафик руками (посты в каналах, комментарии, форумы) |
| 5 | Соберите $20–30 с первых лидов и реинвестируйте в Propeller |

---

### Итоговый вывод

- **Telegram + Propeller (поп-трафик)** — идеальные источники для старта.
- **TikTok/Facebook/Google** — только когда есть бюджет $500+, опыт и клоакинг.
- **Главное правило** — сначала тестируйте с минимальным бюджетом ($20–50), собирайте статистику, масштабируйте только на вайт-листах.
