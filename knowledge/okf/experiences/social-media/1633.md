Ниже — **глубокий разбор** систем трекинга и аналитики для CPA-арбитража в 2025–2026. Всё максимально прикладное, с цифрами, сравнениями и готовыми решениями.

---

## 1. Keitaro (self‑hosted)

| Параметр | Значение |
|----------|----------|
| **Стоимость** | $49/мес (до 1M посетителей), $99/мес (до 5M), $199/мес (до 15M) |
| **Время настройки** | 2–5 часов (с установкой на VPS и базовой настройкой) |
| **Хостинг** | VPS (от $10/мес), нужен свой домен |
| **Фичи** | A/B-тесты, бот-фильтр (более 30 методов), клоакинг (по User‑Agent, IP, гео), мульти-юзер (неограниченно), антибан-система |
| **Интеграции** | 200+ CPA‑сетей (встроенные шаблоны), S2S, Facebook CAPI, TikTok, Google |

---

### Ключевые возможности

| Фича | Что делает |
|------|------------|
| **Потоки (Streams)** | Создаёте несколько путей для одного оффера (например, по странам или устройствам) с разными креативами/лендингами |
| **Фильтры** | Можно отсекать ботов, нецелевой трафик (по IP, ISP, странам, браузерам, языкам) прямо в трекере — до отправки клика в сеть |
| **Постбэки (S2S)** | Встроенные шаблоны для большинства CPA‑сетей; можно быстро настроить приём конверсий и передачу в источники трафика |
| **Мульти‑юзер** | Можно создать неограниченное количество подпользователей с разными правами (например, для команды или белых/серых кампаний) |
| **Клоакинг** | Встроенный блок «Anti‑Fraud»: показываем белую страницу ботам, чёрную — реальным пользователям; настраивается без сторонних сервисов |
| **A/B‑тесты** | Из коробки — тестируем до 30 вариантов офферов/лендингов/креативов, статистика по CR и EPC |

---

### Установка на VPS

| № | Действие |
|---|----------|
| 1 | Купите VPS (DigitalOcean, Hetzner, Vultr) с 2 ГБ ОЗУ, 20 ГБ SSD |
| 2 | Установите Ubuntu 20.04 / 22.04 (LTS) |
| 3 | Подключитесь по SSH и выполните команды установки (Keitaro даёт готовый скрипт) |
| 4 | Назначьте свой домен на IP VPS (через DNS A-запись) |
| 5 | Пройдите установку через браузер (задайте логин/пароль, лицензионный ключ) |
| 6 | Запустите крон-задачи для обработки кликов/конверсий |

---

### Чек‑лист настройки кампании в Keitaro

| № | Действие |
|---|----------|
| 1 | Добавьте источник трафика (например, «Propeller») → введите токен постбэка |
| 2 | Добавьте оффер из CPA‑сети (URL + постбэк в сеть) |
| 3 | Настройте поток (Stream): укажите оффер, лендинг/прелендинг (опционально) |
| 4 | Создайте кампанию: выберите источник, поток, укажите гео и другие ограничения |
| 5 | Получите ссылку кампании (с макросами) и передайте в источник трафика |
| 6 | Проверьте постбэк: отправьте тестовую конверсию и убедитесь, что она отображается в трекере и сети |

---

### Плюсы и минусы

| Плюсы | Минусы |
|-------|--------|
| Один платёж — вечная лицензия для версии без обновлений (или аренда) | Требуется администрирование VPS |
| Полный контроль над данными и настройками | Сложнее в настройке, чем SaaS |
| Нет лимитов по объёму трафика | Обновления нужно делать вручную |
| Мощные фильтры и клоакинг из коробки | При проблемах с сервером — теряете данные, если нет бэкапа |

---

### Частые ошибки новичков в Keitaro

| Ошибка | Решение |
|--------|---------|
| Не установили крон‑задачи | Не обрабатываются постбэки |
| Не настроили фильтры — идёт ботовый трафик | Включите антибот-фильтр |
| Нет постбэка от сети | Проверьте URL, макросы, тестовый лид |
| Не настроили домен для трекера | Используйте поддомен (track.yourdomain.com) с SSL |

## 2. Binom (self‑hosted)

| Параметр | Значение |
|----------|----------|
| **Стоимость** | $49/мес (до 500 кликов/день), $99/мес (до 2000), $199/мес (до 10 000), $399/мес (безлимит) |
| **Время настройки** | 1–3 часа (базово быстрее Keitaro) |
| **Хостинг** | VPS (от $10/мес) + домен |
| **Фичи** | A/B, бот-фильтр (AI-детекция), клоакинг (по ботам, IP, гео), API, когортный анализ, дашборды |
| **Интеграции** | Встроенные шаблоны для 200+ CPA‑сетей, Facebook CAPI, TikTok, Google |

---

### Отличия Binom от Keitaro

| Аспект | Binom | Keitaro |
|--------|-------|---------|
| **Интерфейс** | Более простой, минималистичный | Мощный, но более громоздкий |
| **Бот‑фильтр** | AI‑детекция + обновляемые списки | Локальные списки + правила |
| **Клоакинг** | Есть, но не встроен как отдельный модуль | Есть полноценный антибан-модуль |
| **API** | Отличный REST API для автоматизации | API есть, но менее гибкий |
| **Отчёты** | Визуальные когортные отчёты, «эффективность» | Больше цифр, меньше графики |
| **Мульти‑юзер** | Ограниченное число (зависит от плана) | Безлимитно в любом плане |
| **Обновления** | Регулярные, лёгкие | Реже |

---

### Быстрый старт в Binom

| № | Действие |
|---|----------|
| 1 | Установка через скрипт на Ubuntu (5 минут) |
| 2 | Добавьте свой домен и получите SSL через Let's Encrypt (встроенный инструмент) |
| 3 | Зайдите в админку → добавьте источник трафика (выберите из списка или укажите свой постбэк) |
| 4 | Добавьте оффер (ссылка + постбэк в сеть) |
| 5 | Создайте кампанию одним кликом (мастер) |
| 6 | Отправьте тестовый клик и проверьте постбэк |

---

### Отчёты и API

| Что даёт | Описание |
|----------|----------|
| **Когортный анализ** | Показывает поведение пользователей по дням (быстро находим сильные офферы) |
| **Дашборды** | Строятся по дням/часам, по источникам, по офферам |
| **REST API** | Можно автоматически создавать кампании, выгружать статистику, управлять потоками |
| **Экспорт** | CSV, JSON, графики в PNG |

---

### Плюсы и минусы Binom

| Плюсы | Минусы |
|-------|--------|
| Быстрее установка и настройка | Дорогой на больших объёмах (от 2000 кликов/день) |
| Простой интерфейс | Ограниченное число подпользователей |
| Отличный API | Клоакинг слабее, чем в Keitaro |
| Когортные отчёты — лучший инструмент для оптимизации | Меньше встроенных фильтров |

---

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Не настроен SSL | Используйте Let's Encrypt (кнопка в настройках) |
| Не настроен постбэк в сети | Проверьте URL и макросы |
| Не обновлён Binom до последней версии | Делайте `php update.php` через CLI |

## 3. RedTrack / Voluum / Binom Cloud (SaaS)

| Параметр | RedTrack | Voluum | Binom Cloud |
|----------|----------|--------|-------------|
| **Стоимость** | $35/мес (до 30k событий), $75/мес (100k), $149/мес (500k) | $69/мес (до 100k), $149/мес (500k) | — (аналога нет) |
| **Лимиты** | События (клики + конверсии) | Посещения/клики | Посещения |
| **Хостинг** | Облачный, не нужно настраивать | Облачный | — |
| **Время настройки** | 15–30 минут | 20–40 минут | — |
| **Фичи** | A/B, бот‑фильтр, клоакинг (только на дорогих тарифах), мульти‑юзер, 50+ интеграций | A/B, бот‑фильтр, ML‑оптимизация, клоакинг (доп. плата) | — |

---

### Когда SaaS выгоднее (и когда — нет)

| Сценарий | Лучший выбор |
|----------|--------------|
| **Бюджет до $100/мес** | Keitaro/Binom (self‑hosted) |
| **Бюджет $200+/мес** | Voluum/RedTrack — не нужно обслуживать сервер |
| **Команда 2–10 человек** | Voluum/RedTrack — встроенные роли |
| **Трафик >100k событий/месяц** | Self‑hosted (неограниченно) или Voluum/RedTrack (дорого) |
| **Нет технического администратора** | SaaS (Voluum/RedTrack) — проще для старта |

---

### Плюсы и минусы SaaS

| Плюсы | Минусы |
|-------|--------|
| Не нужно администрировать сервер | Ежемесячная плата + лимиты |
| Быстрое обновление функций | Нет полного контроля над данными |
| Готовые интеграции с основными сетями | Клоакинг — платный дополнительный модуль |
| Надёжность (99.9% аптайм) | Нельзя поставить свои фильтры/скрипты |

## 4. Самописный / Google Sheets + Apps Script (для старта с $0–$50)

| Параметр | Значение |
|----------|----------|
| **Стоимость** | $0–10/мес (хостинг + домен) |
| **Время настройки** | 2–4 часа (без опыта — до 2 дней) |
| **Хостинг** | VPS или обычный хостинг (PHP + MySQL) или Google Apps Script |
| **Фичи** | Базовые: клики, конверсии, простой постбэк (только передача данных), мини‑отчёты в Google Sheets |

---

### Как работает Google Sheets + Apps Script

| № | Действие |
|---|----------|
| 1 | Создайте Google Sheet с колонками: click_id, offer_id, datetime, ip, payout, status |
| 2 | Напишите скрипт (Apps Script) для приёма кликов (GET‑запрос с параметрами) |
| 3 | Разверните скрипт как веб‑приложение (получите URL) |
| 4 | В CPA‑сети укажите этот URL как постбэк (передавая click_id и статус) |
| 5 | Используйте ссылки в формате: `https://script.google.com/...?offer_id=123&sub1={click_id}` |

---

### Когда это подходит

- Бюджет $0–50.
- Трафик до 100 кликов/день.
- Только для теста гипотез.
- Нет технических навыков для установки Keitaro/Binom.

---

### Ограничения

| Ограничение | Почему плохо |
|-------------|--------------|
| Нет защиты от ботов | Google не блокирует ботов |
| Нет A/B‑тестов | Всё вручную |
| Нет автоматической оптимизации | Только ручной анализ |
| Ограничение лимитов Google Sheets | 5 млн ячеек, 500 запросов/день на бесплатном тарифе |

---

### Плюсы и минусы самописного решения

| Плюсы | Минусы |
|-------|--------|
| Бесплатно (или почти) | Нет клоакинга, фильтров, бот‑защиты |
| Полный контроль над кодом | Нужно программировать и поддерживать |
| Легко интегрировать с любыми источниками | Не масштабируется |
| Подходит для одного-двух офферов | При росте трафика — отказы и зависания |
