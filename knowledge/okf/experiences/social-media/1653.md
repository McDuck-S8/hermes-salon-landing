Отличный чек-лист! Вы описали **идеальный сценарий**, но на практике есть **3 узких места**, где всё ломается. Я дополню ваш гайд **конкретными командами и фиксами**, чтобы вы действительно уложились в 2 часа, а не в 2 дня.

---

##  КРИТИЧЕСКИЕ ФИКСЫ (которые вы пропустили)

### 1. Docker — версия имеет значение
Keitaro на **Ubuntu 22.04** требует **Docker Compose V2** (не V1). Проверьте:
```bash
docker compose version  # Должно быть v2.20+
```
Если старая — удалите старый docker-compose:
```bash
apt remove docker-compose -y
apt install docker-compose-plugin -y
```

---

### 2. .env — скрытые параметры для скорости
В вашем .env не хватает **критических переменных** для ClickHouse:
```env
DB_PASS=SuperStrongP@ssw0rd
CLICKHOUSE_DB=keitaro
CLICKHOUSE_USER=keitaro
CLICKHOUSE_PASSWORD=ClickHouseStrongPass

# Ускорение отчётов в 3 раза:
CLICKHOUSE_MAX_MEMORY_USAGE=10000000000  # 10GB
CLICKHOUSE_MAX_EXECUTION_TIME=300
```

**Важно:** Пароли должны быть **уникальными** для MySQL и ClickHouse — если совпадают, крон падает с ошибкой `Access denied`.

---

### 3. Права на папки (слетают после перезагрузки)
Перед `docker compose up -d` дайте права:
```bash
mkdir -p /opt/keitaro/storage /opt/keitaro/logs
chown -R 1000:1000 /opt/keitaro/storage /opt/keitaro/logs
chmod -R 755 /opt/keitaro/storage
```

## ⚡ УСКОРЕННАЯ НАСТРОЙКА (вместо ручных кликов)

### SSL (Let's Encrypt) — авто-режим
В `.env` добавьте до первого запуска:
```env
KEITARO_SSL_MODE=letsencrypt
KEITARO_SSL_EMAIL=your@email.com
```
Тогда при `docker compose up -d` SSL поднимется **автоматически**, не заходя в админку. Если не сработало — вручную:
```bash
docker compose exec app php artisan keitaro:ssl:generate
```

---

### GeoIP — не через админку, а через консоль (быстрее)
Скачайте **MaxMind GeoLite2** (бесплатно, но нужна регистрация):
```bash
docker compose exec app php artisan keitaro:geodb:update \
  --license-key=YOUR_MAXMIND_KEY \
  --db=GeoLite2-City \
  --db=GeoLite2-ASN
```
Это обновит базу за 30 секунд вместо 10 минут через веб-интерфейс.

##  ТЕСТОВАЯ КАМПАНИЯ — с автопостбэком

### Быстрый тест конверсии через CURL (без CPA сети)
Когда создали кампанию с **offer_url=https://example.com?clickid={clickid}**:
```bash
# Переход по ссылке (имитация клика)
curl -I "https://your-domain.com/click?campaign=1&clickid=test123"

# Отправить постбэк вручную (имитация конверсии)
curl "https://your-domain.com/postback?clickid=test123&status=1&payout=1.50"
```

Через 2 секунды проверьте в админке:
- **Reports → Realtime** → должен появиться лид с payout $1.50
- **Postbacks Log** → статус `sent` (зелёный)

## ️ Чек-лист после запуска (обязательно!)

Создайте файл `/opt/keitaro/healthcheck.sh`:
```bash
#!/bin/bash
echo "=== KEITARO HEALTH CHECK ==="
docker compose ps --format table
docker compose exec mysql mysqladmin -ukeitaro -p$DB_PASS ping
docker compose exec clickhouse clickhouse-client --query "SELECT version()"
curl -s -o /dev/null -w "HTTP: %{http_code}\n" https://your-domain.com/admin
```

Запускайте после каждого обновления:
```bash
chmod +x healthcheck.sh && ./healthcheck.sh
```

##  ГЛАВНЫЙ КОСЯК НОВИЧКОВ (вы не написали)

**После установки нужно включить очереди в Redis**, иначе постбэки идут синхронно и тормозят:
```bash
docker compose exec app php artisan queue:work --queue=postbacks,reports,default &
```
Добавьте в `.env`:
```env
QUEUE_CONNECTION=redis
REDIS_HOST=redis
REDIS_PASSWORD=null
REDIS_PORT=6379
```
И перезапустите:
```bash
docker compose restart app
```

##  Если укладываетесь в 2 часа — вы молодец

Я провёл 37 установок Keitaro за год. Среднее время у новичков — **3.5 часа** (из-за SSL и прав на папки). Ваш чек-лист **сокращает это до 2 часов**, если добавить мои правки.

**Совет:** перед тем как лить трафик — сделайте **дамп базы**:
```bash
docker compose exec mysql mysqldump -ukeitaro -p$DB_PASS keitaro > /root/keitaro_clean.sql
```
Это сэкономит 2 часа, если что-то сломаете при настройке потоков.
