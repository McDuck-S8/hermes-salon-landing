**Core Philosophy:** Create once, distribute everywhere. Every pillar piece (2000+ word article, 15-min video, research report) gets atomized into platform-native formats.

**n8n Alternative (Self-Hosted, Free):**
- Same logic, visual workflow editor
- Webhook trigger → OpenAI node → IF nodes for routing → HTTP Request nodes for each platform
- Advantage: No per-operation cost, full data ownership, custom code nodes

**Quality Gates (Automated):**
```python
def quality_check(asset, platform):
    checks = {
        'x': lambda a: len(a['text']) <= 280 and a['hook_strength'] > 7,
        'linkedin': lambda a: a['slide_count'] >= 6 and a['cta_present'],
        'shorts': lambda a: a['duration'] <= 60 and a['hook_at_0'],
        'reels': lambda a: a['has_captions'] and a['hashtags'] >= 5,
        'email': lambda a: a['spam_score'] < 2 and a['unsubscribe_link'],
        'pinterest': lambda a: a['aspect_ratio'] == '2:3' and a['text_overlay']
    }
    return checks.get(platform, lambda x: True)(asset)
```
