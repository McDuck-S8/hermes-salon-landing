Organic Traffic Acquisition - SEO, YouTube, Pinterest, AI Content

1. Modern SEO 2024-2025: Build keyword clusters by search intent (commercial, informational, navigational) with one pillar page + 5-10 supporting articles with internal linking = topical authority. Technical: LCP < 2.5s, CLS < 0.1 (WebP, CDN caching). E-E-A-T: author bio with photo, social links, fresh update dates. Link building: crowd links in niche forums + editorial links via Digital PR (expert comments for media), NOT mass PBN.

2. YouTube SEO: Keywords via YouTube autocomplete + "watched together" widgets, NOT Google. Title: main query in first 3-4 words. CTR: thumbnail = large emotional face + 3-5 word contrast text, A/B test 2-3 via TubeBuddy. Retention: hook in first 3 sec (spoiler result), trigger at 20 sec ("stay for hack"). Shorts: vertical, 1.5 sec cut frequency. Channel authority: 2-3 posts/week, >50% avg view duration.

3. Pinterest Marketing: Vertical pins (2:3) with overlay text (2-3 words), descriptions with 3-5 keywords separated by ";". Board strategy: narrow topics ("Summer office dresses 2024" not "Fashion"), 30% repins from others for trust. Idea Pins (60 sec video) = 3x reach, ranked by internal algo. Pinterest SEO vs Google: freshness matters - first 2 hours = 50% reach.

4. AI Content at Scale: Use GPT-4/Claude for structure, FAQ, meta descriptions - write intro/conclusion manually, add unique cases/tables. Programmatic SEO (pSEO) for category pages ([city]+service) - generate 100+ pages with unique AI intros, fact-check, add real reviews/addresses. Avoid penalties: Originality.ai <20% AI probability, always human edit + add "human experience" (on-site photos, videos, expert comments).

5. Content Repurposing: 1 article → Twitter thread (10-15 posts, 1 thought each), 3-5 Shorts/Reels (15 sec each), LinkedIn/IG carousel (slide summary), email newsletter (exclusive table/checklist), podcast outline (3 blocks). Adapt format per platform: LinkedIn = pro insights, TikTok = emotional before/after.

6. Traffic Diversification: Don't rely on single platform. Target: 40% SEO, 30% YouTube, 20% Pinterest/social, 10% email/direct. Syndicate with delay: blog first (Google index), day 3 = Medium/VC rewrite, week 1 = Shorts/Pinterest with links to original (rewrite, not duplicate).

7. Organic ROI Measurement: Organic rarely first-touch sale. Track assisted conversions in GA4 (conversion path report). Content decays 6-12 months: update when positions drop below #10 or CTR falls in GSC - add fresh stats, examples, internal links, request re-index in GSC.

8. Tools: Ahrefs (best backlinks) / Semrush (positions, clustering) for keyword research. GSC for tech SEO + Core Web Vitals. YouTube Studio for retention. Pinterest Analytics for saves/clicks. SurferSEO for content optimization. AI: Claude > GPT-4 for natural text, always check via Grammarly/human editor.
