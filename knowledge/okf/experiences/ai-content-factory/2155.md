Отлично. Переходим к самой актуальной модели на сегодня — **Flux.1-dev**. Это не просто очередная SD-модель, это новый стандарт качества, который требует совсем другого подхода к оптимизации и обучению. Ниже — **инженерный гайд** по работе с Flux в продакшене: от квантизации до создания собственных LoRA.

---

# Блок 1. Архитектура Flux.1-dev (Краткий обзор)

Flux.1-dev принципиально отличается от Stable Diffusion:

| Характеристика | Stable Diffusion XL | Flux.1-dev |
| :--- | :--- | :--- |
| **Архитектура** | U-Net + CLIP | **Transformer (DiT)** + T5-XXL |
| **Размер модели** | 7B | **12B** (включая T5) |
| **Требования к VRAM** | 8-12 GB | **20-24 GB** (без оптимизации) |
| **Качество текста** | Среднее (понимает промпты до 77 токенов) | **Отличное** (понимает до 512 токенов) |
| **Время инференса** | 5-10 сек | 20-40 сек (без оптимизации) |

**Ключевое:** Flux требует принципиально другого подхода к квантизации и обучению из-за архитектуры Transformer.

# Блок 2. FP8/NF4 Квантизация (Оптимизация памяти)

Квантизация — единственный способ запустить Flux на потребительских видеокартах (RTX 3090/4090 с 24GB VRAM).

## 2.1. FP8 Квантизация (Рекомендуемый метод)

FP8 дает лучшее качество, чем NF4, но требует поддержки на уровне драйверов (CUDA 12.0+).

**Конфигурация для ComfyUI:**

```json
{
  "loader": {
    "class_type": "UnetLoaderFluxFP8",
    "inputs": {
      "unet_name": "flux1-dev-fp8.safetensors",
      "weight_dtype": "fp8_e4m3fn"
    }
  },
  "diffusion": {
    "class_type": "FluxGuidance",
    "inputs": {
      "guidance": 3.5,
      "cfg": 1.0
    }
  }
}
```

## 2.2. NF4 Квантизация (Для карт с 16GB VRAM)

NF4 (4-bit Normal Float) сильнее сжимает модель, но теряет немного в качестве.

**Скрипт конвертации модели в NF4 (Python):**

```python
import torch
from diffusers import FluxPipeline
from transformers import BitsAndBytesConfig

# Загрузка модели в 4-bit
quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.float16,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_use_double_quant=True,
)

pipeline = FluxPipeline.from_pretrained(
    "black-forest-labs/FLUX.1-dev",
    torch_dtype=torch.float16,
    quantization_config=quantization_config,
    device_map="auto",
)

# Сохранение квантизованной модели
pipeline.save_pretrained("flux-dev-nf4")
```

**Запуск квантизованной модели в ComfyUI:**

Установите кастомную ноду: **ComfyUI-Quantization** (гит: `city96/ComfyUI-Quantization`)

```json
{
  "class_type": "QuantizedModelLoader",
  "inputs": {
    "model_path": "flux-dev-nf4",
    "quant_type": "nf4",
    "dtype": "fp16"
  }
}
```

## 2.3. Сравнение качества и скорости

| Метод | VRAM | Качество (из 10) | Скорость (сек) |
| :--- | :--- | :--- | :--- |
| **Full FP16** | 24 GB | 9.5 | 35 |
| **FP8 (e4m3fn)** | 16 GB | 9.2 | 25 |
| **NF4** | 12 GB | 8.5 | 20 |

**Мой выбор:** FP8 — лучшее соотношение качество/скорость. NF4 используйте только если у вас карта с 12GB (RTX 3060/4070).

## 3.3. Комбинирование нескольких ControlNet (Multi-ControlNet)

```python
# Python скрипт для комбинирования
import torch
from diffusers import FluxControlNetPipeline, FluxControlNetModel
from PIL import Image

# Загрузка нескольких ControlNet
controlnet_depth = FluxControlNetModel.from_pretrained(
    "black-forest-labs/FLUX.1-dev-ControlNet-Depth",
    torch_dtype=torch.float16
)

controlnet_canny = FluxControlNetModel.from_pretrained(
    "black-forest-labs/FLUX.1-dev-ControlNet-Canny",
    torch_dtype=torch.float16
)

# Создание пайплайна с несколькими ControlNet
pipeline = FluxControlNetPipeline.from_pretrained(
    "black-forest-labs/FLUX.1-dev",
    controlnet=[controlnet_depth, controlnet_canny],
    torch_dtype=torch.float16,
    variant="fp16"
).to("cuda")

# Подготовка изображений
depth_image = Image.open("depth.png")
canny_image = Image.open("canny.png")

# Генерация
result = pipeline(
    prompt="architectural visualization, modern building, photorealistic",
    control_image=[depth_image, canny_image],
    controlnet_conditioning_scale=[0.7, 0.5],  # вес каждого ControlNet
    height=1024,
    width=1024,
    num_inference_steps=30,
    guidance_scale=3.5,
).images[0]
```

# Блок 4. LoRA Training с Kohya_ss

Обучение LoRA для Flux требует специфических настроек из-за архитектуры Transformer.

## 4.1. Подготовка датасета

**Структура папок:**
```
dataset/
├── train/
│   ├── 001.jpg
│   ├── 001.txt
│   ├── 002.jpg
│   ├── 002.txt
│   └── ...
└── reg/
    ├── reg_001.jpg
    ├── reg_001.txt
    └── ...
```

**Критерии для датасета Flux:**
- **Разрешение:** 1024x1024 (минимальное)
- **Количество:** минимум 50 изображений (лучше 200+)
- **Качество:** 4K, профессиональные фото
- **Формат:** PNG или JPG (без потерь)

## 4.2. Капшенинг (Captioning) для Flux

Flux использует **T5-XXL**, который понимает длинные, описательные промпты. Используйте **WD14 Tagger** для автоматического капшенга.

**Скрипт для батч-капшенга:**

```python
# captioning.py
import os
from PIL import Image
import torch
from transformers import AutoProcessor, AutoModelForCausalLM

# Загрузка модели капшенга (BLIP-2 или CogVLM)
model_id = "Salesforce/blip2-opt-2.7b"
processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype=torch.float16).to("cuda")

def generate_caption(image_path):
    image = Image.open(image_path).convert("RGB")
    inputs = processor(image, return_tensors="pt").to("cuda", torch.float16)
    outputs = model.generate(**inputs, max_length=100)
    caption = processor.decode(outputs[0], skip_special_tokens=True)
    return caption

# Обработка всех изображений
dataset_path = "dataset/train"
for filename in os.listdir(dataset_path):
    if filename.endswith(('.jpg', '.png')):
        image_path = os.path.join(dataset_path, filename)
        caption = generate_caption(image_path)
        
        # Сохранение в .txt файл
        txt_path = os.path.splitext(image_path)[0] + '.txt'
        with open(txt_path, 'w') as f:
            f.write(caption)
        
        print(f"✅ {filename}: {caption[:50]}...")
```

**Пример хорошего капшена для Flux:**
```
professional fashion photography, elegant woman in red dress, standing on marble staircase, dramatic lighting, cinematic composition, high quality, 8k resolution, detailed fabric texture, shallow depth of field, bokeh background, luxurious atmosphere
```

## 4.3. Конфигурация Kohya_ss для Flux

Создайте `flux_lora_config.toml`:

```toml
[base]
pretrained_model_name_or_path = "black-forest-labs/FLUX.1-dev"
v2 = false
v_parameterization = false

[dataset]
train_data_dir = "dataset/train"
reg_data_dir = "dataset/reg"
caption_extention = ".txt"
shuffle_caption = true
caption_dropout_rate = 0.1
caption_tag_dropout_rate = 0.1

[training]
output_dir = "output"
output_name = "flux_lora_style"
learning_rate = 1e-4
lr_scheduler = "cosine"
lr_warmup_steps = 100
train_batch_size = 1
max_train_steps = 2000
gradient_accumulation_steps = 4
gradient_checkpointing = true
mixed_precision = "bf16"  # Важно для Flux!
save_every_n_epochs = 1
save_model_as = "safetensors"

[model]
network_module = "networks.lora"
network_dim = 64  # Рекомендуется 64-128 для Flux
network_alpha = 32
unet_lr = 1e-4
text_encoder_lr = 1e-5  # T5 обучается с меньшим LR

[optimizer]
optimizer_type = "AdamW8bit"
```

**Запуск обучения:**

```bash
# Установка Kohya_ss
git clone https://github.com/bmaltais/kohya_ss
cd kohya_ss
pip install -r requirements.txt

# Запуск обучения
python train_network.py \
  --config_file=flux_lora_config.toml \
  --sample_every_n_epochs=5 \
  --sample_prompts="photo of a woman in red dress, <lora:flux_lora_style:1.0>"
```

## 4.4. Оптимизированные параметры для разных сценариев

| Сценарий | network_dim | learning_rate | steps | regularization |
| :--- | :--- | :--- | :--- | :--- |
| **Style Transfer** | 128 | 1e-4 | 3000 | 10% |
| **Character** | 64 | 5e-5 | 1500 | 5% |
| **Object** | 32 | 1e-4 | 1000 | 0% |
| **Concept** | 128 | 1e-4 | 5000 | 20% |

# Блок 5. Инференс-оптимизация

## 5.1. TensorRT оптимизация (для NVidia)

```python
# tensorrt_optimize.py
import torch
from diffusers import FluxPipeline
import tensorrt as trt

# Конвертация в TensorRT
pipeline = FluxPipeline.from_pretrained(
    "black-forest-labs/FLUX.1-dev",
    torch_dtype=torch.float16,
    variant="fp16"
)

# Оптимизация UNet
from diffusers.optimization import optimize_unet_for_tensorrt
optimize_unet_for_tensorrt(
    pipeline.unet,
    input_shape=(1, 4, 64, 64),
    dtype=torch.float16,
    workspace_size=2_000_000_000  # 2GB
)

# Сохранение оптимизированной модели
pipeline.save_pretrained("flux-trt-optimized")
```

## 5.2. Inference с xformers и Flash Attention

```python
# inference_optimized.py
import torch
from diffusers import FluxPipeline

# Включение оптимизаций
torch.backends.cuda.matmul.allow_tf32 = True
torch.backends.cudnn.benchmark = True

pipeline = FluxPipeline.from_pretrained(
    "black-forest-labs/FLUX.1-dev",
    torch_dtype=torch.float16,
    variant="fp16"
).to("cuda")

# Enable memory optimizations
pipeline.enable_xformers_memory_efficient_attention()
pipeline.enable_attention_slicing()
pipeline.enable_vae_slicing()
pipeline.enable_model_cpu_offload()  # для карт с 12GB

# Генерация с оптимизированными параметрами
result = pipeline(
    prompt="beautiful landscape with mountains and lake, photorealistic, 8k",
    height=1024,
    width=1024,
    num_inference_steps=28,  # меньше шагов благодаря качеству модели
    guidance_scale=3.5,  # низкий guidance для Flux
    max_sequence_length=512,  # используем весь контекст
).images[0]
```

# Блок 7. Шпаргалка по промптам для Flux

Flux понимает **естественный язык**, а не ключевые слова как SD:

**Плохой промпт (стиль SD):**
```
1girl, anime, big eyes, red dress, city, sunset
```

**Хороший промпт (стиль Flux):**
```
A stunning young woman with long flowing hair, wearing an elegant red dress, standing in a futuristic city at golden sunset, cinematic photography, dramatic lighting, highly detailed, photorealistic, 8k resolution, sharp focus, bokeh background
```

**Дополнительные параметры промпта:**
- Указывайте **стиль** (photorealistic, cinematic, illustration)
- Указывайте **освещение** (studio lighting, golden hour, dramatic)
- Указывайте **композицию** (close-up, full body, wide shot)
- Указывайте **эмоцию** (joyful, mysterious, elegant)

# Блок 8. Рабочий процесс (Production Workflow)

1. **Подготовка данных:** Сбор 100-200 изображений → Капшенинг через BLIP-2/CogVLM
2. **Обучение LoRA:** 2000 шагов на Kohya_ss с параметрами выше
3. **Тестирование:** Генерация 10-20 промптов с разной силой LoRA (0.5, 0.8, 1.0)
4. **Квантизация:** Конвертация модели в FP8 для быстрого инференса
5. **Интеграция:** Встраивание в ComfyUI API или FastAPI сервис
6. **Мониторинг:** Отслеживание времени генерации и качества

**Пример Dockerfile для продакшена:**

```dockerfile

WORKDIR /app

RUN apt-get update && apt-get install -y python3-pip git
```

**Золотое правило Flux:**
> *"Flux требует больше памяти, но дает лучшее качество при меньшем количестве шагов. Инвестируйте время в создание качественного датасета и правильный капшенинг — это окупится десятикратно."*

Начните с FP8-квантизации на RTX 4090, затем обучите LoRA на 100+ изображениях. После этого вы поймете, почему Flux называют "убийцей Midjourney". Удачи!
