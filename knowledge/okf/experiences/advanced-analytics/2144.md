R Bayesian A/B Test with brms - Stan Interface

```r
library(brms)
library(tidybayes)

df <- data.frame(
  group = rep(c("control", "treatment"), each = 5000),
  converted = c(rep(1, 120), rep(0, 4880), rep(1, 150), rep(0, 4850))
)

fit <- brm(
  converted ~ 0 + group,
  data = df,
  family = bernoulli(),
  prior = c(prior(normal(0, 1.5), class = "b")),
  sample_prior = "yes",
  iter = 3000, warmup = 1000, chains = 4, cores = 4, seed = 42
)

posterior <- as_draws_df(fit)
prob_superior <- mean(posterior$b_grouptreatment > posterior$b_groupcontrol)
cat("P(treatment > control):", prob_superior, "\n")

hyp <- hypothesis(fit, "exp(b_grouptreatment) / (1 + exp(b_grouptreatment)) - exp(b_groupcontrol) / (1 + exp(b_groupcontrol)) > 0.001")
print(hyp)

p_control <- plogis(posterior$b_groupcontrol)
p_treatment <- plogis(posterior$b_grouptreatment)
expected_loss <- mean(pmax(0, p_control - p_treatment))
cat("Expected loss:", expected_loss, "\n")
```

prior(normal(0, 1.5)) on log-odds ≈ 95% between 0.001-0.999. hypothesis() for business thresholds. posterior_predict() for new visitors.
