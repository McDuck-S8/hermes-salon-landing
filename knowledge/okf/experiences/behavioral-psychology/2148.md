Fogg Behavior Model (B=MAP) for Landing Page Optimization

**Formula: B = M × A × P** — Behavior happens when Motivation, Ability, Prompt align simultaneously.

**Motivation Triggers (M) — Core Motivators:**
```python
motivators = {
    'pleasure_pain': {'pleasure': 'Instant result preview', 'pain': 'Cost of inaction calculator'},
    'hope_fear': {'hope': 'Case study: +40% in 30 days', 'fear': 'Competitors already using this'},
    'social_acceptance_rejection': {'acceptance': 'Join 5000+ pros', 'rejection': 'Don't be left behind'}
}
# Pick ONE primary motivator per page. Mixing dilutes.
```

**Ability Reduction (A) — Simplicity Factors:**
| Factor | Friction | Fix | Lift |
|--------|----------|-----|------|
| Time | 5+ min form | 30-sec wizard | +35% |
| Money | $X upfront | Free trial / freemium | +50% |
| Physical | App download | Web app / PWA | +25% |
| Brain | Complex choices | Smart defaults | +40% |
| Social | Public commitment | Private start | +15% |
| Routine | New habit | Integrate existing | +30% |

**Code: Form Field Reduction**
```jsx
// Progressive profiling - only ask what's needed NOW
const formFields = (stage) => {
  const base = ['email'];
  if (stage >= 2) base.push('name', 'company');
  if (stage >= 3) base.push('role', 'team_size');
  return base;
};
// Stage 1: email only → Stage 2: +name/company (after value delivered)
```

**Prompt Engineering (P) — Timing & Placement:**
```javascript
// Prompt types by timing
const prompts = {
  'immediate': {trigger: 'page_load', delay: 0, type: 'banner'},      // Low intent
  'engaged': {trigger: 'scroll_50%', delay: 0, type: 'sidebar'},      // Medium intent
  'intent': {trigger: 'pricing_hover', delay: 500, type: 'modal'},    // High intent
  'exit': {trigger: 'mouse_leave', delay: 0, type: 'overlay'},        // Last chance
  'return': {trigger: 'localStorage_visit>1', delay: 0, type: 'chat'} // Warm lead
};

// A/B test: engaged prompt vs intent prompt → intent wins 3:1 for B2B
```

**Metrics per Phase:**
- M: Motivation score (survey 1-5), value prop clarity test (5-sec test)
- A: Form completion rate, time-to-complete, field drop-off funnel
- P: Prompt impression → action rate, prompt dismiss rate, optimal timing distribution
