Hook Model (Nir Eyal) for Retention - Implementation

**4-Phase Loop: Trigger → Action → Variable Reward → Investment**

**1. Trigger Types:**
```python
triggers = {
    'external': {
        'paid': 'Ads, sponsored content',
        'earned': 'PR, reviews, social mentions',
        'relationship': 'Referral invites, shares',
        'owned': 'Email, push, in-app messages'
    },
    'internal': {
        'emotion': 'Boredom → open app, Anxiety → check dashboard',
        'routine': 'Morning coffee → open analytics',
        'situation': 'Client meeting → pull up report'
    }
}
# Map your user's internal triggers via survey: "What were you feeling right before opening?"
```

**2. Action Simplicity (B=MAP applied):**
```javascript
// Fogg's 6 simplicity factors - score each 1-5, target total > 20
```

**3. Variable Reward Schedules (Skinner Box):**
| Reward Type | Examples | Dopamine Pattern | Retention |
|-------------|----------|------------------|-----------|
| Tribe (Social) | Likes, comments, leaderboards | Unpredictable social validation | High (DAU) |
| Hunt (Material) | Discounts, unlocks, loot boxes | Random material gain | Medium |
| Self (Achievement) | Streaks, badges, progress bars | Mastery/completion | High (LTV) |

```python
# Variable reward implementation
```

**4. Investment Loops (Increase Switching Cost):**
```javascript

```

**Metrics per Phase:**
- Trigger: Trigger → Action rate (target > 20% for owned, > 5% for paid)
- Action: Time-to-action, drop-off points, simplicity score
- Reward: Reward claim rate, reward type preference, dopamine proxy (return within 24h)
- Investment: Investment completion rate, subsequent session length, churn by investment type
