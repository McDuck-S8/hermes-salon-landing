Dark Patterns vs Ethical Persuasion - Compliance Checklist

**Dark Patterns to AVOID (Illegal in EU/UK, risky everywhere):**

| Dark Pattern | What It Does | Ethical Alternative | Conversion Impact |
|--------------|--------------|---------------------|-------------------|
| Roach Motel | Easy signup, impossible cancel | One-click cancel in settings | -5% short, +30% LTV |
| Confirmshaming | "No, I hate saving money" | "No thanks, maybe later" | -3% short, +15% trust |
| Disguised Ads | Ads as content/navigation | Clear "Sponsored" label | -2% CTR, +40% brand |
| Forced Continuity | Silent auto-renew | 7-day email reminder before charge | -8% churn |
| Sneak into Basket | Pre-checked add-ons | Opt-in with clear benefit | -12% AOV, +25% NPS |
| Privacy Zuckering | Complex privacy settings | Granular toggles, plain language | +20% opt-in |
| Misdirection | Visual hierarchy hides options | Equal visual weight for all choices | +15% informed choice |
| Hidden Costs | Fees at final step | All-in pricing upfront | -10% cart abandon |

**White-Hat Alternatives with SAME Lift:**

```python
# Instead of fake scarcity timer
def ethical_urgency(product):
    real_constraints = []
    if limited_inventory(product):
        real_constraints.append(f"Осталось {get_stock(product)} шт.")
    if cohort_closing_soon(product):
        real_constraints.append(f"Набор закрывается {get_deadline(product)}")
    if price_increasing(product):
        real_constraints.append(f"Цена вырастет {get_date(product)} на {get_increase(product)}%")
    return " | ".join(real_constraints) if real_constraints else None

# Instead of confirmshaming
def ethical_decline(option_name):
    return f"Нет, {option_name} не нужно сейчас"  # Neutral, respectful

# Instead of forced continuity
def subscription_reminder(user, days_before=7):
    if days_before == 7:
        return "Напоминание: через неделю спишется подписка. Отменить: [link]"
    if days_before == 1:
        return "Завтра списание. Хотите отменить или сменить тариф? [link]"
```

**Compliance Checklist (Pre-Launch):**
- [ ] All claims substantiated (screenshots, data, testimonials with names)
- [ ] No fake scarcity/timers/countdowns
- [ ] Cancel in ≤ 2 clicks from any page
- [ ] Pricing: all-in upfront, no hidden fees
- [ ] Privacy: granular controls, plain Russian language
- [ ] Auto-renew: email 7d + 1d before, one-click cancel in email
- [ ] Disclosures: #ad / "реферальная ссылка" on all affiliate content
- [ ] Accessibility: WCAG 2.1 AA (color contrast, keyboard nav, alt text)
- [ ] A/B test: ethical variant vs dark pattern → if ethical within 5%, SHIP ETHICAL
