Cialdini's 6 Principles in Digital Funnels - Implementation

**1. Reciprocity (Lead Magnet → Email Sequence)**
```html
<!-- Lead magnet delivery page -->
<div class="reciprocity-frame">
  <h2>Ваш гайд готов! Отправлен на email.</h2>
  <p>Пока ждёте — 3 быстрых победы, которые можно внедрить сегодня:</p>
  <ul>
    <li>✅ Уберите 2 лишних поля из формы — +15% конверсия</li>
    <li>✅ Добавьте счетчик «Осталось 3 места» — +8%</li>
    <li>✅ Поставьте логотипы клиентов над сгибом — +12%</li>
  </ul>
  <button onclick="track('micro_yes')">Хочу больше таких советов</button>
</div>
```
Email sequence: Day 0 = delivery + micro-yes, Day 1 = case study, Day 3 = tool/template, Day 5 = soft pitch, Day 7 = FAQ + hard pitch.

**2. Commitment/Consistency (Micro-Yes Ladder)**
```javascript
// Progressive commitment funnel
const steps = [
  {q: "Хотите увеличить конверсию?", action: "track_yes"},
  {q: "Готовы потратить 15 мин на аудит?", action: "book_call"},
  {q: "Какой KPI главный: лиды или чек?", action: "segment"},
  {q: "Подходит ли $X бюджет на тест?", action: "qualify"}
];
// Each 'yes' increases commitment probability by ~20%
```

**3. Social Proof (Placement Matrix)**
| Position | Format | Lift |
|----------|--------|------|
| Above fold | Live counter + 3 logos | +12% |
| Near CTA | Video testimonial (15s) | +18% |
| Pricing table | "Most popular" badge | +22% |
| Exit intent | "1247 chose Pro" | +9% |

**4. Authority (Signals That Work)**
- Certificates/badges: ISO, SOC2, Google Partner — place in footer + checkout
- Expert quotes: "Рекомендую [Product] — Иван Петров, CTO Яндекса" — photo + title mandatory
- Media logos: "Как видели в Forbes/VC/Хабр" — only if real

**5. Liking (Personalization at Scale)**
```python
# Dynamic landing page based on UTM
def personalize(request):
    source = request.GET.get('utm_source', 'direct')
    variants = {
        'linkedin': {'tone': 'professional', 'case': 'b2b_enterprise'},
        'facebook': {'tone': 'friendly', 'case': 'small_business'},
        'google': {'tone': 'direct', 'case': 'roi_focused'}
    }
    return render('landing.html', variants.get(source, variants['direct']))
```

**6. Scarcity (Ethical - Real Constraints Only)**
```python
# Real inventory scarcity
def get_scarcity_message(product):
    stock = get_real_stock(product)
    if stock <= 10:
        return f"Осталось {stock} шт. по этой цене"
    elif has_active_cohort(product):
        return "Набор в когорту закрывается через 2 дня"
    return None  # No fake scarcity
```
Metrics: track scarcity_message_shown → conversion lift. Kill if lift < 3% or complaints > 1%.
