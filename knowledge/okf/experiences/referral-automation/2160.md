Отлично. Переходим к **тревел- и хостинг-партнёркам** — это классика пассивного дохода, но с очень разной экономикой. Отели дают % годами, хостинг — высокий разовый чек.

Ниже — **практический гайд по партнёрским программам**: Travelpayouts (отели + авиа), Hostinger, Cloudways, Booking.com. С таблицами, сезонными стратегиями, контент-планами и кодом. Всё на русском.

---

## 1. Сводная таблица партнёрских программ

| Программа | Тип | Размер комиссии | Средний чек | Куки-период | Мин. выплата | Сложность |
|-----------|-----|----------------|-------------|-------------|--------------|-----------|
| **Travelpayouts (отели)** | % от брони | 3-12% | $80-150/ночь | 30 дней | $10 |  Низкая |
| **Travelpayouts (авиа)** | Фикс за билет | $2-10 | $50-300 | 30 дней | $10 |  Низкая |
| **Booking.com** | RevShare (чистый доход) | 25-40% | $120/ночь (средний) | 30 дней | $50 |  Средняя |
| **Hostinger** | Фикс за продажу | $100 | $50-150 (хостинг) | 30 дней | $50 |  Низкая |
| **Cloudways** | Фикс за продажу | $75-125 | $40-120/мес (VPS) | 60 дней | $50 |  Средняя |

**Важно:** 
- Booking.com платит **% от чистой прибыли** (без налогов и комиссий отелей)
- Travelpayouts — агрегатор (Agoda, Hotels.com, Expedia, 100+ авиакомпаний)
- У Cloudways — **recurring комиссия** (вы платите за жизненный цикл клиента)

## 2. Таблица LTV для партнёра (средние значения)

| Программа | Средний чек | Срок жизни клиента | Кол-во покупок | LTV партнёра (1 клиент) |
|-----------|-------------|-------------------|----------------|-------------------------|
| **Travelpayouts (отели)** | $120/ночь | 5 ночей = $600 | 1 раз/год (3 года) | **$60-180** (3-12%) |
| **Travelpayouts (авиа)** | $200/билет | 1 билет | 2 рейса/год × 3 года | **$12-60** ($2-10 × 6) |
| **Booking.com** | $120/ночь × 4 ночи = $480 | 1 раз/год (3 года) | 3 поездки | **$360-576** (25-40%) |
| **Hostinger** | $100 (средний) | 1 раз (хостинг на 2 года) | 1 покупка | **$100** (разово) |
| **Cloudways** | $60/мес (VPS) | 18 месяцев | 1 подписка | **$1,350-2,250** ($75-125 × 18 мес) |

**Вывод:**
- **Самый высокий LTV** → Cloudways (до $2,250 с клиента)
- **Самый быстрый кэш** → Hostinger ($100 за одну продажу)
- **Самый стабильный** → Booking.com (повторные бронирования)

## 5. Интеграционный код

### Универсальный трекер для Travelpayouts (JavaScript)

```javascript
// Travelpayouts / Booking.com трекер
(function() {
    // 1. Получаем партнёрский ID из ссылки
    const urlParams = new URLSearchParams(window.location.search);
    const subId = urlParams.get('subid') || urlParams.get('ref') || 'default';

    // 2. Сохраняем в localStorage на 30 дней
    const days = 30;
    const expires = new Date(Date.now() + days * 86400000).toUTCString();
    document.cookie = `travel_ref=${subId}; expires=${expires}; path=/; domain=.${window.location.hostname}; SameSite=Lax`;

    // 3. Если это продающая страница - отправляем событие
    if (window.location.pathname.includes('/booking/') || 
        window.location.pathname.includes('/hotels/')) {
        
        // Google Analytics событие
        if (typeof gtag !== 'undefined') {
            gtag('event', 'travel_referral_click', {
                'sub_id': subId,
                'destination': window.location.href
            });
        }

        console.log(`[TravelPayouts] Tracked: ${subId}`);
    }
})();
```

### Генерация партнёрской ссылки (PHP)

```php
<?php
class TravelAffiliateLink
{
    private $api_key = 'YOUR_TRAVELPAYOUTS_API_KEY';
    private $base_urls = [
        'hotels' => 'https://www.travelpayouts.com/affiliate_marketing/hotels/',
        'flights' => 'https://www.travelpayouts.com/affiliate_marketing/flights/'
    ];

    public function generateHotelLink($destination, $checkin, $checkout, $subId = 'default')
    {
        $params = [
            'destination' => urlencode($destination),
            'checkin' => $checkin,
            'checkout' => $checkout,
            'sub_id' => $subId,
            'marker' => $this->api_key
        ];

        return $this->base_urls['hotels'] . '?' . http_build_query($params);
    }

    public function generateFlightLink($from, $to, $date, $subId = 'default')
    {
        $params = [
            'origin' => urlencode($from),
            'destination' => urlencode($to),
            'date' => $date,
            'sub_id' => $subId,
            'marker' => $this->api_key
        ];

        return $this->base_urls['flights'] . '?' . http_build_query($params);
    }
}

// Использование
$aff = new TravelAffiliateLink();
echo $aff->generateHotelLink('Bangkok', '2026-08-15', '2026-08-20', 'blog_post_1');
// https://www.travelpayouts.com/affiliate_marketing/hotels/?destination=Bangkok&checkin=2026-08-15&checkout=2026-08-20&sub_id=blog_post_1&marker=YOUR_API_KEY
?>
```

## 12. Ошибки новичков

| Ошибка | Последствие | Как избежать |
|--------|-------------|--------------|
| Ставить ссылки внутри текста без визуала | Низкий CTR | Делайте кнопки + ссылки в конце абзацев |
| Не отслеживать UTM-метки | Не поймёте, что работает | Всегда добавляйте utm_source, utm_medium |
| Продвигать только дорогие отели | Нет продаж | Микс: бюджетные + премиум |
| Забывать про мобильную версию | Потеря трафика 60% | Тестируйте ссылки на телефоне |
| Игнорировать сезонность | Пишете про пляжи зимой | Календарь контента на год вперёд |

## 14. Бонус: скрипт для проверки битых ссылок (Python)

```python
import requests
from urllib.parse import urlparse

def check_affiliate_links(urls):
    """
    Проверяет список партнёрских ссылок на доступность
    """
    results = []
    for url in urls:
        try:
            response = requests.get(url, timeout=5, allow_redirects=True)
            status = response.status_code
            final_url = response.url
            results.append({
                'url': url,
                'status': status,
                'final_url': final_url,
                'ok': 200 <= status < 400
            })
        except Exception as e:
            results.append({
                'url': url,
                'status': 'ERROR',
                'error': str(e),
                'ok': False
            })
    
    return results

# Использование
links = [
    'https://www.travelpayouts.com/...',
    'https://www.booking.com/...'
]

for result in check_affiliate_links(links):
    if not result['ok']:
        print(f" Битая ссылка: {result['url']}")
    else:
        print(f"✅ {result['url']} → {result['final_url']}")
```
