## 4. Суб-партнёрские уровни (Multi-Tier)

### Binance (3 уровня):
```
Вы (Master) → Партнёр 1-го уровня → Партнёр 2-го уровня
```
- 1-й уровень: 20-40% от комиссии приглашённого
- 2-й уровень: 5-10% от комиссии партнёра 1-го уровня
- 3-й уровень: 2-5% от комиссии партнёра 2-го уровня

**Пример расчёта (Binance):**
- Приглашённый трейдер заплатил комиссии $100
- 1-й уровень: получает $40 (40%)
- Вы (Master): получаете 10% от дохода 1-го уровня = $4
- Итого ваш доход: $4 (пассивно)

### Bybit (2 уровня):
```
Вы → Партнёр 1-го уровня → Партнёр 2-го уровня
```
- 1-й уровень: до 50%
- 2-й уровень: 5-10%

### KuCoin (2 уровня):
- 1-й уровень: до 30%
- 2-й уровень: 5%

**Вывод:** Binance и Bybit — лучшие для построения сети суб-партнёров.

### Как отслеживать переходы (JavaScript + PHP):

**Frontend (отслеживание клика):**
```javascript
// Универсальный реферальный трекер
function trackReferralClick(exchange, refCode) {
    // 1. Сохраняем в localStorage
    localStorage.setItem(`${exchange}_ref`, refCode);
    localStorage.setItem(`${exchange}_ref_time`, Date.now());

    // 2. Отправка в вашу аналитику (Google Analytics / Mixpanel)
    gtag('event', 'referral_click', {
        'exchange': exchange,
        'ref_code': refCode,
        'source': document.referrer || 'direct'
    });

    // 3. Создаём ссылку с UTM
    const url = `https://www.${exchange}.com/register?ref=${refCode}&utm_source=partner&utm_medium=referral`;
    window.open(url, '_blank');
}

// Использование:
// trackReferralClick('binance', '123456789');
```

### Backend (валидация и сохранение в БД):

**PHP (Laravel) пример:**
```php
<?php
namespace App\Http\Controllers;

use App\Models\Referral;
use Illuminate\Http\Request;

class ReferralController extends Controller
{
    public function track(Request $request)
    {
        $validated = $request->validate([
            'exchange' => 'required|in:binance,bybit,okx,gate,kuCoin',
            'ref_code' => 'required|string',
            'user_ip' => 'nullable|ip'
        ]);

        // Проверка на дубликат (24 часа)
        $exists = Referral::where('ip', $request->ip())
                          ->where('exchange', $validated['exchange'])
                          ->where('created_at', '>', now()->subDay())
                          ->exists();

        if ($exists) {
            return response()->json(['status' => 'duplicate'], 429);
        }

        // Сохраняем
        $referral = Referral::create([
            'exchange' => $validated['exchange'],
            'ref_code' => $validated['ref_code'],
            'ip' => $request->ip(),
            'user_agent' => $request->userAgent(),
            'referrer' => $request->header('referer')
        ]);

        return response()->json([
            'status' => 'success',
            'id' => $referral->id
        ]);
    }
}
```

## 7. Автоматизация: отслеживание торговой активности (через API)

### Получение данных о комиссиях (Binance API):

**Python:**
```python
import requests
import hmac
import hashlib
import time

API_KEY = 'your_api_key'
API_SECRET = 'your_api_secret'

def get_referral_commission(recv_window=5000):
    timestamp = int(time.time() * 1000)
    params = {
        'timestamp': timestamp,
        'recvWindow': recv_window
    }
    
    query_string = '&'.join([f"{k}={v}" for k, v in params.items()])
    signature = hmac.new(API_SECRET.encode(), query_string.encode(), hashlib.sha256).hexdigest()
    
    headers = {
        'X-MBX-APIKEY': API_KEY
    }
    
    response = requests.get(
        'https://api.binance.com/sapi/v1/rebate/tax-query',
        params={**params, 'signature': signature},
        headers=headers
    )
    
    return response.json()

# Пример вызова
data = get_referral_commission()
for record in data.get('data', []):
    print(f"User: {record['userId']}, Commission: {record['commissionAmount']} USDT")
```

## 10. Продвинутая стратегия: "Суб-партнёрская сеть" (на примере Binance)

### Workflow:
1. Вы регистрируетесь как **Master Partner** на Binance
2. Получаете уникальный реферальный код
3. Привлекаете 10 активных трейдеров → получаете доступ к **Суб-партнёрской программе**
4. Создаёте Landing Page для вербовки суб-партнёров
5. Суб-партнёры получают свой код (привязанный к вашему)
6. Вы получаете % от их дохода (пассивно)

### Математика (Binance, 3 уровня):
```
Вы привлекли:
- 5 суб-партнёров
- Каждый привлёк по 10 трейдеров = 50 трейдеров

Доход:
- Трейдеры: 50 × $40/мес (средний) = $2,000
- Суб-партнёры: 5 × $400/мес (их доход) × 10% = $200
Итого: $2,200/мес (пассивно)
```

## 12. Ошибки новичков (чего НЕ делать)

| Ошибка | Последствие |
|--------|-------------|
| Не проходить KYC до начала | Не получите выплаты |
| Использовать ERC20 для мелких сумм | Съедите комиссией весь доход |
| Не проверять активность пользователей | Платите за мёртвые аккаунты |
| Спамить ссылкой везде | Бан на площадках |
| Не использовать суб-партнёров | Упускаете пассивный доход |

## 14. Бонус: код для проверки активности пользователей (Python)

```python
import pandas as pd
from datetime import datetime, timedelta

def check_user_activity(api_data, days=30):
    """
    Проверяет, торговал ли пользователь за последние N дней
    """
    cutoff = datetime.now() - timedelta(days=days)
    
    active_users = []
    for user in api_data:
        last_trade = datetime.fromtimestamp(user['last_trade_time'])
        if last_trade > cutoff:
            active_users.append(user)
    
    return active_users

# Использование
users = [
    {'id': 1, 'last_trade_time': 1700000000},
    {'id': 2, 'last_trade_time': 1600000000}
]

active = check_user_activity(users)
print(f"Активных пользователей: {len(active)}")
```
