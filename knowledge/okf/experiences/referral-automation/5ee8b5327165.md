## Автоматизированные воронки для рефералов — пассивный доход 24/7

**Источник:** анализ автоматизации реф-воронок, 2026-07-13
**Применимо к нам: ДА — ТРЕТИЙ ПРИОРИТЕТ**

### Типы воронок

#### 1. Telegram-бот воронка
Пользователь заходит в бота -> бот задаёт вопросы -> даёт бесплатный гайд -> внутри реф-ссылка

Пример: Бот "Как выбрать хостинг" -> вопросы про проект -> рекомендация Hostinger с реф-ссылкой + скидкой

#### 2. Email-последовательность (5 писем)
День 1: Проблема (почему нужен хороший хостинг)
День 2: Решение (сравнение хостингов)
День 3: Кейс (как я выбрал Hostinger)
День 4: Реф-ссылка + скидка
День 5: FAQ + гарантия

#### 3. YouTube-канал воронка
Видео -> в описании ссылка на гайд -> внутри реф-ссылка

#### 4. Pinterest воронка
Пин с инфографикой -> ссылка на статью на Teletype -> внутри реф-ссылки

### Инструменты

| Этап | Инструмент | Стоимость |
|------|-----------|-----------|
| Сбор email/подписчиков | Telegram-бот (pyTelegramBotAPI) | Бесплатно |
| Email-последовательность | Mailchimp (free до 500) | Бесплатно |
| Лендинг | Teletype / GitHub Pages | Бесплатно |
| Аналитика | Google Analytics / Яндекс.Метрика | Бесплатно |

### Цифры

- Конверсия холодный трафик -> email: 20-40%
- Конверсия email -> клик по реф-ссылке: 10-30%
- Доход с 1000 подписчиков: $30-200/мес
- Время на создание воронки: 3-5 дней

### Вывод
**Применимо к нам: ДА — ТРЕТИЙ ПРИОРИТЕТ.** Создать 1 простую воронку (Telegram-бот + Teletype) за 2-3 дня. Воронка будет работать пассивно.
