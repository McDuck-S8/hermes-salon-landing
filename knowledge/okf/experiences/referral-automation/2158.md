## 4. Код интеграции для отслеживания партнёрских переходов

### Универсальный скрипт (JavaScript) для установки UTM-меток и кук

```javascript
// Партнёрский трекер (Universal)
(function() {
    // 1. Получаем параметры из URL
    const urlParams = new URLSearchParams(window.location.search);
    const partnerId = urlParams.get('ref') || urlParams.get('partner') || urlParams.get('utm_source');
    
    if (!partnerId) return;

    // 2. Устанавливаем куку на 90 дней (для Notion/Miro)
    const days = 90;
    const date = new Date();
    date.setTime(date.getTime() + (days * 24 * 60 * 60 * 1000));
    document.cookie = `partner_id=${partnerId}; expires=${date.toUTCString()}; path=/; domain=.${window.location.hostname}; SameSite=Lax`;

    // 3. Отправка события в аналитику
    if (typeof gtag !== 'undefined') {
        gtag('event', 'partner_click', {
            'partner_id': partnerId,
            'source': document.referrer || 'direct'
        });
    }

    // 4. Запись в localStorage для кросс-доменных переходов
    localStorage.setItem('partner_id', partnerId);
    localStorage.setItem('partner_click_time', Date.now());

    console.log(`[Partner Track] ID: ${partnerId} saved`);
})();
```

### Пример ссылки для партнёра (на примере Notion):
```
https://www.notion.so/?ref=PARTNER123
```

## 5. Готовый конфиг для партнёрского дашборда (на основе Airtable)

### Структура базы Airtable для партнёров:

**Таблица 1: `Partners`**
| Field | Type | Описание |
|-------|------|----------|
| `Partner ID` | Single line text | Уникальный ID |
| `Name` | Single line text | Имя партнёра |
| `Email` | Email | Контакт |
| `Commission Rate` | Number | % или фикс |
| `Total Earned` | Currency | Сумма выплат |
| `Status` | Single select | Active / Pending / Inactive |

**Таблица 2: `Conversions`**
| Field | Type | Описание |
|-------|------|----------|
| `Partner ID` | Link to Partners | Связь |
| `Customer Email` | Email | Клиент |
| `Plan` | Single select | Monthly / Yearly |
| `Revenue` | Currency | Доход с клиента |
| `Commission` | Formula | `Revenue * Commission Rate` |
| `Paid` | Checkbox | Выплачено? |
| `Date` | Date | Дата регистрации |

**Формула для комиссии (Airtable):**
```javascript
// Для Airtable: 50% за первый год
IF(
  {Plan} = "Yearly", 
  {Revenue} * 0.5, 
  {Revenue} * 0.5 * 12 / 12
)
```

## 6. Схема автоматической выплаты (workflow)

### Интеграция: Airtable → Zapier → Stripe / PayPal

**Триггер:** Новая запись в `Conversions` с `Paid = false`

**Действия в Zapier:**
1. Найти партнёра по `Partner ID`
2. Проверить статус `Active`
3. Рассчитать комиссию (по формуле из таблицы)
4. Создать платёж в Stripe Connect / PayPal Payout
5. Обновить `Paid = true` и дату выплаты

**Пример конфига Zapier (JSON):**
```json
{
  "trigger": {
    "app": "airtable",
    "event": "new_record",
    "table": "Conversions",
    "condition": "Paid == false"
  },
  "actions": [
    {
      "app": "stripe",
      "action": "create_transfer",
      "data": {
        "amount": "{{Commission}}",
        "currency": "USD",
        "destination": "{{Partner.StripeAccountID}}",
        "description": "Commission for {{CustomerEmail}}"
      }
    },
    {
      "app": "airtable",
      "action": "update_record",
      "table": "Conversions",
      "record_id": "{{RecordID}}",
      "fields": {
        "Paid": true,
        "PaidDate": "{{now}}"
      }
    }
  ]
}
```

## 10. Продвинутый вариант: динамическая комиссия (как Linear)

Если вы как Linear даёте **Custom** условия — используйте формулу:

```
Базовая ставка: 20%
Бонус за объём:
  - 10+ клиентов/мес → +5%
  - 25+ клиентов/мес → +10%
  - 50+ клиентов/мес → +15%
```

**Пример кода для расчёта (Python):**
```python
def calculate_commission(total_clients, base_rate=20):
    if total_clients >= 50:
        bonus = 15
    elif total_clients >= 25:
        bonus = 10
    elif total_clients >= 10:
        bonus = 5
    else:
        bonus = 0
    return base_rate + bonus

# Пример
print(calculate_commission(30))  # 30%
```
