# СХЕМА: Claude Knowledge Work Plugins (Anthropic Plugin Architecture)

## Источник
Видео: https://www.youtube.com/watch?v=47dS7GT2dHs — "Anthropic's New Claude Plugins Do Your ENTIRE Job (Free)"
Репозиторий: https://github.com/anthropics/knowledge-work-plugins — 22.5k stars, 11 plugins, 260 commits

## Суть схемы
Anthropic выпустила файловую систему плагинов для Claude Cowork/Code, которая позволяет превратить AI в специалиста для любой роли (sales, legal, marketing, data, finance, product, support, etc.).

Ключевая инновация: НУЛЕВОЙ ПОРОГ — плагины собираются из markdown + JSON файлов, без кода, без сборки, без инфраструктуры.

## Структура плагина
```
plugin-name/
├── .claude-plugin/plugin.json   # Манифест — имя, версия, описание
├── .mcp.json                    # MCP коннекторы — внешние инструменты
├── commands/                    # Слеш-команды (явный вызов)
└── skills/                      # Навыки (автоматические по контексту)
    └── skill-name/SKILL.md
```

## Формат SKILL.md
YAML frontmatter (name, description, trigger phrases) + markdown тело:
- How It Works — ASCII схема (standalone vs supercharged)
- Getting Started — что нужно от пользователя
- Connectors — какие инструменты усиливают навык
- Output Format — точный шаблон результата
- Execution Flow — пошаговый алгоритм
- Variations — сценарии использования
- Related Skills — связанные навыки

## Принцип Dual-Mode
1. Standalone — работает с web search + вводом пользователя
2. Supercharged — если подключены MCP коннекторы (CRM, Email, Slack)

## Применение для Hermes
Наша система skills/ уже использует SKILL.md с YAML frontmatter — полное совпадение!
MCP конфигурация (.mcp.json) — Hermes уже поддерживает MCP серверы.
Можно ввести .hermes-plugin/manifest.json для организации плагинов.

## Ключевые выводы
1. Файловая архитектура без кода — минимальный порог для AI агентов
2. Dual-mode (standalone + connectors) — правильный паттерн
3. Skills срабатывают автоматически по контексту
4. MCP — единый протокол подключения инструментов
5. Ролевая специализация — каждый плагин = доменная область
