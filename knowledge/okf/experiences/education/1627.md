Ниже — **краткий фактологический** разбор домена **education (образование)** для арбитража трафика. Всё тезисно, по пунктам, с конкретными примерами.

## 1. Ниши (подтемы)

| № | Ниша | Что внутри |
|---|------|------------|
| 1 | **Онлайн-курсы (EdTech массовый сегмент)** | Профессиональные программы (маркетинг, дизайн, управление), хобби-курсы (фото, музыка, рисование), подготовка к экзаменам (ЕГЭ, IELTS, TOEFL) |
| 2 | **IT-образование** | Программирование (Python, JS, Java, C++), веб-разработка, Data Science, DevOps, кибербезопасность, QA, мобильная разработка |
| 3 | **Языковое обучение** | Английский (разговорный, бизнес, технический), европейские и азиатские языки, подготовка к международным экзаменам (IELTS, TOEFL, DELE), языковые приложения (Duolingo, Lingualeo) |
| 4 | **Сертификация и аккредитация** | Профессиональные сертификаты (1С, Cisco, Microsoft, AWS, PMP), курсы повышения квалификации, переподготовка, вебинары с выдачей сертификатов |
| 5 | **Корпоративное обучение (B2B)** | Внедрение LMS (iSpring, Moodle), обучение сотрудников (soft skills, управление, продажи), онбординг, развивающие программы для персонала |
| 6 | **Дошкольное и школьное образование** | Подготовка к школе, репетиторы, развивашки, интерактивные уроки, образовательные игры для детей |
| 7 | **Soft skills и личная эффективность** | Навыки переговоров, публичные выступления, тайм-менеджмент, эмоциональный интеллект, лидерство, работа в команде |
| 8 | **Бизнес-образование** | MBA, финансы для предпринимателей, юнит-экономика, управление проектами, Agile, Scrum, стратегическое планирование |
| 9 | **Творческие профессии** | Дизайн, UX/UI, моушн-дизайн, видеомонтаж, 3D-моделирование, фотография, анимация, гейм-дизайн |
| 10 | **Подготовка к ЕГЭ/ОГЭ и поступлению** | Онлайн-школы подготовки к экзаменам, курсы для абитуриентов, консультации по поступлению в вузы |

## 2. Источники трафика (где сидит ЦА)

| Источник | Формат / механика | Особенность |
|----------|-------------------|-------------|
| **YouTube Edu (образовательный сегмент)** | Бесплатные уроки, разборы тем, лекции, карьерные кейсы, обзоры курсов | Огромный органический трафик, доверие, долгий просмотр |
| **Telegram** | Каналы с бесплатными материалами, дайджестами, подборками курсов, мини-уроки, боты-тренажёры, каналы вакансий | Лёгкий прогрев, дешёвый трафик, высокое вовлечение |
| **Профильные форумы (IT-форумы, Habr, 4pda, Reddit)** | Обсуждения, вопросы по обучению, рекомендации курсов, сигнатуры | Узкопрофильная аудитория, высокое доверие |
| **HR-платформы (hh.ru, HeadHunter, Career.habr)** | Обсуждения карьеры, вакансии, статьи о навыках, рекомендации курсов для роста | Прогретые лиды, ищут работу/рост |
| **Instagram*** | Reels с лайфхаками, карточки-сравнения курсов, отзывы студентов, сторис с анонсами | Хорошо на молодую аудиторию (20–30 лет) |
| **Контекст / таргет** | Яндекс.Директ, VK Реклама по запросам «курсы», «обучение», «программирование», «английский» | Горячие лиды с высокой интенцией |
| **LMS-платформы (Stepik, Coursera)** | Внутренние рекомендации, форумы, отзывы, рефералки | Трафик уже внутри образовательной среды |
| **VK / VK Клипы / TikTok** | Короткие образовательные ролики, лайфхаки, факты | Виральность, дешёвый охват, молодёжь |
| **Подкасты (образовательные)** | Тематические выпуски, упоминания платформ | Фоновое потребление, хорошо для прогрева |

## 3. Монетизация

| Тип | Что продаём | Формат выплат |
|-----|-------------|---------------|
| **CPA-курсы (B2C)** | Курсы на Skillbox, Нетологии, Geekbrains, Яндекс Практикум, Skyeng, EnglishDom, Stepik | 500–5000 руб за лид / 20–40% с оплаты курса |
| **Рефералки платформ (EdTech)** | Подписки на Coursera, Udemy, Lingualeo, Duolingo Premium, Skyeng | 10–30% от оплаты подписки / 50–500 руб за лид |
| **B2B корпобучение** | Внедрение LMS (iSpring, Moodle), программы развития персонала, корпоративные курсы | 1000–10000 руб за заявку / % от контракта (100 000–2 000 000 руб) |
| **Аффилиаты учебников** | Учебники, методички, книги для подготовки к экзаменам, профессиональная литература | 10–30% от чека (через Ozon/WB/Литрес) |
| **Контент-локеры** | «Бесплатный чек-лист по подготовке к экзамену», «Методичка по Python» — доступ за подписку/репост | Сбор контактов для прогрева |
| **Премиум-подписки** | Подписки на образовательные платформы (Skillshare, Pluralsight, O'Reilly) | 50–500 руб за активацию подписки |
| **Сертификационные экзамены** | Рефералки на регистрацию на экзамены (IELTS, TOEFL, Cisco, AWS, 1С) | 500–2000 руб за регистрацию |

### Итоговый вывод (для стратегии)

- **Тёплые связки**: YouTube (бесплатный урок) → Telegram-канал (материалы) → контент-локер (гайд/чек-лист) → вебинар → CPA на курс.
- **Самые конвертируемые офферы**: IT-курсы с гарантией трудоустройства (высокий чек) и языковые приложения (массовая аудитория, дешёвая подписка).
- **Главное УТП**: продаём не курс, а **новую профессию, рост зарплаты, карьеру, будущее**.
- **Контент, который всегда работает**: «Как я сменил профессию за 6 месяцев», «Топ-10 курсов для старта в IT», «Как выучить английский самостоятельно», «Обзор платформы X», «Что будет через год после обучения».

---
