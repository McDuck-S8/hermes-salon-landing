Ниже — **ЧЕК-ЛИСТ: Деплой лендинга на Netlify + чистый HTML (GitHub репо)**.  
Всё по шагам, с конкретными действиями, файлами, UTM-метками и готовыми решениями.

---

##  Зачем Netlify + чистый HTML для CPA-арбитража
- **Полный контроль** над кодом, формами, скриптами.
- **Бесплатно** до 100GB трафика/мес (хватает на 100+ лендингов при среднем трафике).
- **Авто SSL + CDN** — скорость загрузки < 1с.
- **Деплой** через `git push` — буквально 30 секунд.
- **Deploy Previews** — каждой A/B-версии свой URL (тестируй гипотезы без возни).
- **Масштабируемость**: можно легко клонировать репозиторий под новые офферы.

---

## ✅ Пошаговая инструкция

---

### Шаг 1. Создать репозиторий на GitHub

1. Зайдите на **GitHub.com** → New repository.
2. Назовите, например: `cpa-landing`.
3. Создайте локально папку и инициализируйте:
   ```bash
   mkdir cpa-landing && cd cpa-landing
   git init
   ```
4. Создайте файлы (см. Шаг 2).

---

### Шаг 2. Файлы в репозитории

#### 2.1. `index.html` (основной файл)

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=yes">

  <!-- SEO / OG -->
  <title>Получи доступ к [оффер]</title>
  <meta name="description" content="[Краткое описание оффера]">
  <meta property="og:title" content="Забери [продукт] сейчас">
  <meta property="og:image" content="https://your-site.com/og-image.jpg">
  <meta property="og:url" content="https://your-site.com">
  <meta property="og:type" content="website">

  <link rel="stylesheet" href="styles.css">

<body>
  <main class="container">
    <h1>Ты теряешь деньги на рекламе?</h1>
    <p class="subtitle">Вот простое решение — [оффер] за 3 минуты</p>

       class="cta-button" target="_blank">
      Забрать сейчас →

  </main>

</html>
```

#### 2.4. `netlify.toml` (настройки деплоя)

```toml
[build]
  publish = "."

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "no-referrer-when-downgrade"
```

### Шаг 3. Залить на GitHub

```bash
git add .
git commit -m "initial commit"
git remote add origin https://github.com/ваш-логин/cpa-landing.git
git push -u origin main
```

---

### Шаг 4. Netlify: деплой из GitHub

1. Зайдите на **app.netlify.com**.
2. Нажмите **Add new site → Import an existing project**.
3. Выберите **GitHub** → дайте доступ к репозиторию.
4. Выберите репозиторий `cpa-landing`.
5. Настройки оставьте по умолчанию (Build command пусто, Publish directory `.`).
6. Нажмите **Deploy site** → через 1 минуту получите ссылку вида `https://ваш-сайт.netlify.app`.

---

### Шаг 5. Подключение своего домена

| Действие | Инструкция |
|----------|------------|
| В Netlify: **Site settings → Domain management → Add custom domain** | Введите ваш домен, например `land.yourbrand.com` |
| У регистратора: добавьте CNAME-запись | `land.yourbrand.com` → `ваш-сайт.netlify.app` (TTL 300) |
| SSL автоматом | Netlify выдаёт бесплатный Let’s Encrypt через 5–10 минут |

---

### Шаг 6. Формы (сбор лидов)

#### Вариант A: Netlify Forms (бесплатно 100 отправок/мес)

Добавьте в `index.html`:

```html
<form name="lead" method="POST" data-netlify="true" netlify-honeypot="bot-field">
  <input type="hidden" name="form-name" value="lead">
  <input type="email" name="email" placeholder="Ваш email" required>
  <button type="submit">Получить доступ</button>
</form>
```

Все заявки будут в **Netlify Admin → Forms**.

#### Вариант B: Свой бэкенд (Telegram бот / CRM)

```html
<form action="https://your-backend.com/lead" method="POST">
  <input type="email" name="email" required>
  <button type="submit">Отправить</button>
</form>
```

---

### Шаг 7. A/B-тесты через Deploy Previews

| Как работает | Пример |
|--------------|--------|
| Создайте новую ветку в GitHub: `git checkout -b test-button-color` | Меняете цвет кнопки в `styles.css` |
| Заливаете: `git push --set-upstream origin test-button-color` | Netlify автоматически создаст **Preview URL** вида `ваш-сайт.netlify.app/deploy-превью` |
| Тестируете на 20–30% трафика | Сравниваете конверсию с основной веткой |
| Если лучше — сливаете PR в `main` | Deploy автоматом обновится |

## ⚠️ ПЛЮСЫ и МИНУСЫ

| Плюсы | Минусы |
|-------|--------|
| Полный контроль над кодом | Нужен базовый HTML/CSS (или знание кода) |
| Бесплатно до 100GB/мес | Нет визуального редактора |
| Авто SSL + CDN | Формы Netlify — только 100 бесплатных отправок/мес |
| Deploy Previews — тестируй гипотезы легко | Для сложной логики (динамика) нужно JS/бэкенд |
| Масштабируемость — можно клонировать репо | Не подходит для тех, кто не хочет работать с кодом |
| Безопасность — сам контролируешь заголовки | — |

---

##  Когда Netlify + HTML — лучший выбор

- У вас есть базовые навыки вёрстки (или готовые шаблоны).
- Нужна максимальная скорость загрузки (< 1с).
- Вы тестируете десятки офферов — легко клонировать репозиторий и менять текст/ссылку.
- Вы хотите полный контроль над пикселями, формами и аналитикой.
- Вам нужно A/B-тестирование через Deploy Previews.

---

Если нужно — могу дать:
- **Готовый репозиторий-шаблон** (кнопка «Use this template»).
- **Настройку CI/CD** для автоматического деплоя при пуше.
- **Пример A/B-теста с двумя вариантами CTA через Deploy Previews.**
