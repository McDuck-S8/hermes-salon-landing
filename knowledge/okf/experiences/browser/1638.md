Ниже — **ЧЕК-ЛИСТ: Деплой лендинга на Carrd (биолинк) для CPA-оффера за 30 минут**. Всё по шагам, с конкретными действиями, UTM-метками и рисками.

---

##  Зачем Carrd для CPA-арбитража
- **Бесплатно** (1 сайт, до 10 элементов на страницу).
- **Молниеносно** (лендинг за 15–30 минут).
- **SSL-сертификат** автоматом (даже на поддомене).
- Идеально для **биолинка** в Instagram/TikTok/Telegram, как **промежуточный слой** перед оффером (чтобы не палить ссылку).
- Можно подключить **свой домен** (Pro $9/год) — повышает доверие и даёт возможность ретаргетинга через пиксель (если добавить код).

---

## ✅ Пошаговая инструкция (30 минут)

### Шаг 1. Регистрация на carrd.co
| Действие | Комментарий |
|----------|-------------|
| Перейти на **carrd.co** | Нажать **Sign Up** |
| Ввести email и пароль | Используйте **реальный** email (для верификации) |
| Подтвердить email | Проверьте папку «Спам» |
| Выбрать **Free plan** | 1 сайт, до 10 элементов, все базовые блоки доступны |

---

### Шаг 2. Выбор шаблона
| Тип | Когда использовать |
|-----|---------------------|
| **Profile** | Для биолинка (аватар + ссылки) — самый частый выбор |
| **Landing** | Если нужен более продающий лендинг с текстом и картинкой |
| **One Page** | Для полноценной страницы с секциями |

→ Выберите **Profile** (быстрее всего адаптируется под биолинк).

---

### Шаг 3. Настройка домена (SSL авто)
| Вариант | Действие |
|---------|----------|
| **Поддомен carrd.co** (бесплатно) | В поле Site Name введите `ваш-бренд.carrd.co` → SSL включится автоматом |
| **Свой домен** ($9/год) | В настройках **Settings → Domain** укажите свой домен, добавьте CNAME-запись у регистратора (инструкция внутри) |

→ На старте используйте **поддомен carrd.co** (бесплатно, SSL есть).

---

### Шаг 4. Добавление элементов (блоков)
#### ✅ Блок 1. Заголовок (H1) — проблема
- Текст: *«Устали от…?»* / *«Тратишь часы на …?»*
- Шрифт: крупный, жирный.
- Назначение: **сразу зацепить внимание**.

#### ✅ Блок 2. Подзаголовок — решение
- Текст: *«Есть простой способ — [краткий оффер]»* / *«Забирай [продукт] за 1 минуту»*
- Подкреплён иконкой/эмодзи ( / ✅ / ⚡).

#### ✅ Блок 3. CTA-кнопка (самое важное!)
- Текст: **«Забрать сейчас →»** / **«Перейти»** / **«Получить доступ»**
- Ссылка: ваш CPA-оффер (прямая ссылка или прелендинг).
- **ОБЯЗАТЕЛЬНО** добавить UTM-метки (см. Шаг 5).
- Оформление: контрастный цвет, кнопка на видном месте.

#### ✅ Блок 4. Социальное доказательство
- Скриншот выплаты / отзыва / результата (смасштабировать под блок).
- Или текст: *«Уже 500+ человек получили …»* / *«Алексей: «Заработал 5000 ₽ за 2 дня»»*.
- Это резко повышает доверие.

#### ✅ Блок 5. Дополнительная кнопка / форма (опционально)
- Можно добавить кнопку «Подписаться на Telegram» или «Скачать бесплатный гайд».
- Если собираете контакты — используйте внешнюю форму (Google Forms, Typeform) или ссылку на бота.

---

### Шаг 5. UTM-метки (критично!)

**Образец ссылки:**
```
https://your-offer.com/?utm_source=carrd&utm_medium=bio&utm_campaign={campaign}&utm_content={creative}
```

| Параметр | Значение | Зачем |
|----------|----------|-------|
| `utm_source` | carrd | Чтобы видеть в Metrica/GA, что трафик именно с биолинка |
| `utm_medium` | bio | Тип размещения (био) |
| `utm_campaign` | {campaign} | Название вашей рекламной кампании (например, `nutra_feb`) |
| `utm_content` | {creative} | Идентификатор креатива / поста (например, `post_1` или `video_1`) |

→ **В Carrd** в поле ссылки кнопки просто вставьте ссылку с метками.

---

### Шаг 6. Публикация и тестирование

| Действие | Проверка |
|----------|----------|
| Нажать **Publish** | Сайт становится доступным по ссылке |
| Открыть на **мобильном** | 80% трафика с биолинков — с телефонов |
| Открыть на **десктопе** | Проверить отображение кнопки и текста |
| Кликнуть по CTA | Убедиться, что ссылка ведёт на оффер |
| Проверить UTM в статистике (Метрика / Analytics) | Через 10–15 минут должны появиться первые визиты |
| Проверить постбэк | Если настроен — должен прийти тестовый лид (или реальный, если кликнул и сконвертился) |

---

### Шаг 7. Подключение своего домена (опционально)

| Действие | Зачем |
|----------|-------|
| В Carrd → Settings → Domain → указать свой домен | Поднимает доверие (пользователь видит `mybrand.com`, а не `carrd.co`). |
| Добавить CNAME-запись у регистратора | Инструкция есть внутри Carrd. |
| Купить домен $5–15/год | Окупается с 2–3 лидов. |

→ **Важно**: после смены домена проверьте все UTM-ссылки и обновите их, если старый домен был захардкожен где-то.

## ⚠️ РИСКИ и ограничения Carrd

| Риск | Решение |
|------|---------|
| **Блокировка по TOS** | Carrd запрещает: казино, скам, нутру с сомнительными БАДами, adult, финансовые пирамиды. Если заметят — сайт удаляют без предупреждения. |
| **GEO-ограничения** | В некоторых странах картинки/шрифты могут грузиться медленно из-за CDN. Используйте минималистичный дизайн. |
| **Нет встроенных форм с отправкой на email/CRM** | Используйте внешние формы (Tally, Typeform, Google Forms) или ссылку на Telegram-бота. |
| **Бесплатный план — только 1 сайт** | Для тестов хватит, а для скейла — $9/год на Pro (до 10 сайтов, свои домены, формы, CSS-кастомизация). |
