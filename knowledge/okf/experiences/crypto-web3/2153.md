# Блок 1. Выбор языка для Searcher Infrastructure (Rust vs Go vs Python)

Это не вопрос вкуса, а вопрос **задержки (latency)** и **стоимости ошибки**. В MEV каждая миллисекунда стоит денег.

| Критерий | Rust | Go | Python |
| :--- | :--- | :--- | :--- |
| **Скорость выполнения** |  (1-2 мс) |  (5-10 мс) | ❌ (50-100 мс) |
| **Параллелизм (мемпул)** |  (асинхронный tokio) |  (горутины) | ❌ (GIL тормозит) |
| **Управление памятью** | Ручное (нулевой оверхед) | Автоматическое (GC) | Автоматическое (медленное) |
| **Порог входа** | Высокий (Rust сложный) | Средний | Низкий |
| **Использование в продакшене** | Paradigm, Flashbots, топ-фонды | Стейкинг-пулы, средние боты | Только прототипы |

**Мой выбор для 2024:**
- Для **арбитража на Ethereum L1** — **Rust** (каждая миллисекунда = деньги, GC Go может создать непредсказуемые задержки).
- Для **L2 (Arbitrum/Optimism)** — **Go** (там задержки сети больше, чем задержки языка, и Go удобнее в поддержке).
- **Python** — используйте только для **прототипирования и бэктестинга**, НЕ для продакшена.

**Инфраструктура:** Поднимайте свой сервер в том же регионе AWS, где находится ваша RPC-нода (Infura/Alchemy). Расстояние между сервером и нодой должно быть < 10 мс — это критично.

# Блок 2. Мониторинг мемпула (Mempool Monitoring)

Чтобы видеть транзакции ДО их включения в блок, нужно поднять **полную архивную ноду** с включенным `txpool`.

## 2.1. Настройка Geth для мемпула (config.toml):
```toml
[Eth]
  TxPool = true
  TxPool.PriceLimit = 1  # gwei (слушаем все транзакции, даже с низкой ценой)
  TxPool.MaxSlots = 10000  # увеличиваем буфер

[Node]
  DataDir = "/path/to/chaindata"
  HTTPHost = "0.0.0.0"
  HTTPPort = 8545
  HTTPModules = ["net", "eth", "txpool"]
  WSPort = 8546
  WSModules = ["net", "eth", "txpool"]
```

**Запуск Geth с нужными флагами:**
```bash
geth --http --ws --txpool.globalslots 10000 --txpool.globalqueue 5000 --txpool.lifetime "2h"
```

## 2.2. Как парсить мемпул на Rust (эффективно):
```rust
use ethers::prelude::*;
use ethers::providers::{Provider, Ws};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let ws = Ws::connect("wss://mainnet.infura.io/ws/v3/YOUR_KEY").await?;
    let provider = Provider::new(ws);
    
    // Подписка на новые транзакции
    let mut stream = provider.subscribe_pending_txs().await?;
    
    while let Some(tx_hash) = stream.next().await {
        // Получаем полную транзакцию
        if let Some(tx) = provider.get_transaction(tx_hash).await? {
            // Фильтруем: только транзакции, идущие на DEX
            if let Some(to) = tx.to {
                if is_dex_contract(to) {
                    println!("Найден потенциальный арбитраж: {:?}", tx);
                    // Отправляем в обработчик
                    process_potential_arbitrage(tx).await?;
                }
            }
        }
    }
    Ok(())
}

fn is_dex_contract(address: Address) -> bool {
    // Список контрактов Uniswap, Sushiswap, Curve и т.д.
    let dex_contracts = vec![
        "0x7a250d5630B4cF539739dF2C5dAcb4c659F2488D", // Uniswap V2
        "0xE592427A0AEce92De3Edee1F18E0157C05861564", // Uniswap V3
        "0xd9e1cE17f2641f24aE83637ab66a2cca9C378B9F", // Sushi
        // ... добавьте другие
    ];
    dex_contracts.contains(&address)
}
```

**Осторожность:** На Ethereum ~ 3000 транзакций в секунду в мемпуле. Не обрабатывайте все подряд. Фильтруйте по `to` (контракты DEX) и минимальному `value` (чтобы не тратить ресурсы на мелкие транзакции).

# Блок 3. Flashbots Bundle Submission (Отправка бандлов)

Flashbots позволяет отправлять транзакции **напрямую майнерам**, минуя публичный мемпул. Это защищает вас от фронт-рана и дает гарантию, что ваш бандл будет выполнен в одном блоке.

## 3.1. Структура бандла (на Rust + ethers-rs):
```rust
use ethers::{
    prelude::*,
    providers::{Http, Provider},
    flashbots::{FlashbotsMiddleware, FlashbotsRequestBuilder},
};
use std::sync::Arc;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Подключение к Flashbots
    let provider = Provider::<Http>::try_from("https://rpc.flashbots.net")?;
    let client = FlashbotsMiddleware::new(
        provider,
        "https://rpc.flashbots.net".to_string(),
        LocalWallet::from_bytes(&YOUR_PRIVATE_KEY)?.with_chain_id(1u64),
    );
    
    // Формируем транзакции бандла
    let tx1 = TransactionRequest::new()
        .to("0xUniswapRouter")
        .value(U256::from(10_000_000_000_000_000u128)) // 0.01 ETH
        .gas(200_000)
        .max_priority_fee_per_gas(U256::from(2_000_000_000u64)) // 2 gwei
        .max_fee_per_gas(U256::from(50_000_000_000u64)); // 50 gwei
        
    let tx2 = TransactionRequest::new()
        .to("0xSushiswapRouter")
        .data(hex::decode("YOUR_SWAP_DATA")?)
        .gas(200_000)
        .max_priority_fee_per_gas(U256::from(2_000_000_000u64))
        .max_fee_per_gas(U256::from(50_000_000_000u64));
    
    // Собираем бандл
    let bundle = FlashbotsRequestBuilder::new()
        .add_transaction(tx1)
        .add_transaction(tx2)
        .set_block_number(provider.get_block_number().await? + 1) // следующий блок
        .build()?;
    
    // Отправляем
    let response = client.send_bundle(bundle).await?;
    println!("Bundle отправлен, статус: {:?}", response);
    
    Ok(())
}
```

## 3.2. Важные параметры газа:
- **`target_block_number`**: Всегда указывайте `current_block + 1`. Если бандл не впишется в этот блок, он не будет выполнен, и вы не заплатите газ.
- **`max_priority_fee_per_gas`**: Устанавливайте на **20% выше**, чем текущий базовый физ (чтобы майнер выбрал ваш бандл из очереди).
- **Минимальный газ для Flashbots**: Используйте 1.5x от стандартного, чтобы быть уверенным во включении.

# Блок 4. Прибыльные стратегии в 2024 (Без математики, только механика)

## 4.1. Атомарный арбитраж (Atomic Arbitrage)
**Как работает:** Разница цен между двумя пулами в одном блоке. Ваш бандл: покупать на дешевом DEX, продавать на дорогом.

**Условие успеха:** 
- Разница цен > (Комиссия за газ × 2 транзакции + комиссия протокола).
- Разница цен должна быть > 0.3% для покрытия затрат.

**Автоматизация:** Используйте API 1inch или 0x для поиска кросс-биржевых спредов.

**Скрипт поиска спреда (псевдокод):**
```python
def find_arbitrage_opportunity():
    # Получаем цены с разных DEX
    price_uni = get_price_uniswap('ETH', 'USDC')
    price_sushi = get_price_sushiswap('ETH', 'USDC')
    spread = (price_uni - price_sushi) / price_uni * 100
    
    if spread > 0.5:  # минимальный профит 0.5%
        # Строим бандл
        build_arbitrage_bundle(
            buy_path=[('ETH', 'USDC', 'uniswap')],
            sell_path=[('ETH', 'USDC', 'sushiswap')],
            amount=calculate_optimal_amount()
        )
```

## 4.2. Ликвидации (Liquidations)
**Как работает:** Вы ликвидируете пользователя, чья позиция стала ниже порога (например, залог < 110%). Вы получаете бонус (обычно 5–10% от суммы долга).

**Сложность:** Нужно отслеживать все позиции Aave/Compound в реальном времени.

**Готовая схема для Aave:**
1. Слушайте событие `Borrow` и сохраняйте `user` + `collateralAmount`.
2. В каждом блоке проверяйте `getUserAccountData(user)`.
3. Если `healthFactor < 1.05` (близко к ликвидации), собирайте бандл:
   - `liquidationCall(user, debtAsset, debtToCover)`
   - Обменяйте полученный collateral на ETH
   - Отправьте прибыль на хаб.

**Важно:** В Aave V3 ликвидации менее прибыльны (бонус 5%), чем в Compound (8%). Учитывайте это.

## 4.3. Sandwich Defense (Защита от сэндвич-атак)
**Суть:** Вы не атакуете, а **защищаете** свои свапы от фронт-рана. Это более устойчивая стратегия.

**Метод:** Отправляйте транзакции через **Flashbots Protect** (публичный RPC), который автоматически упаковывает ваш свап в приватный бандл. Это дешевле, чем писать собственного бота.

**Код отправки через Flashbots Protect (замена обычного RPC):**
```python
w3 = Web3(Web3.HTTPProvider('https://rpc.flashbots.net'))
# Все остальное как обычно, но транзакция никогда не попадет в публичный мемпул
tx = {
    'to': '0xDEX_CONTRACT',
    'value': web3.to_wei(0.1, 'ether'),
    'gas': 200000,
    'gasPrice': web3.to_wei('50', 'gwei'),
    'nonce': w3.eth.get_transaction_count(account_address),
}
signed = w3.eth.account.sign_transaction(tx, private_key)
w3.eth.send_raw_transaction(signed.rawTransaction)  # Отправляется через приватный канал
```

# Блок 6. Метрики риска для MEV-бота

Отслеживайте эти показатели **по каждому бандлу**, чтобы не уйти в минус:

| Метрика | Формула | Допустимый порог |
| :--- | :--- | :--- |
| **Success Rate** | (Успешных бандлов / Отправленных) * 100 | > 90% |
| **Gas Cost / Profit Ratio** | (Затраченный газ в USD) / (Прибыль в USD) | < 20% |
| **Revert Rate** | Сколько бандлов отклонились из-за изменения цен | < 5% |
| **Execution Time** | От отправки до включения в блок | < 5 секунд |
| **Profit per Day** | Итоговая прибыль после всех комиссий | > Затрат на ноду (≈ $50/мес) |

**Совет:** Ведите лог каждого бандла в БД (PostgreSQL или MongoDB) с этими полями:
```
bundle_id, block_number, profit_usd, gas_spent, strategy_type, timestamp, revert_reason
```

# Блок 7. Пошаговый запуск за 1 день (План для новичка)

1. **Утро (2 часа):** Поднимите Geth в тестовой сети Sepolia (это бесплатно).
2. **Обед (3 часа):** Напишите скрипт на Python, который подписывается на `pending_transactions` и логирует все свапы на Uniswap.
3. **Вечер (2 часа):** Создайте тестовый арбитражный бандл на Flashbots и отправьте его в тестовую сеть.
4. **Ночь (1 час):** Настройте мониторинг Telegram-бота, чтобы он присылал уведомления при каждом успешном выполнении.

**Важное предупреждение:** Начинайте с **суммы < 0.1 ETH** в основной сети. Сначала протестируйте все на `Sepolia`, чтобы убедиться, что ваш бандл не уходит в `revert` из-за неправильного порядка транзакций или недостаточного газа.

# Блок 8. Код для мониторинга успешности (Telegram-бот)

```python
import requests
import time
from eth_account import Account
from web3 import Web3

TELEGRAM_BOT_TOKEN = "YOUR_TOKEN"
CHAT_ID = "YOUR_CHAT_ID"
FLASHBOTS_URL = "https://rpc.flashbots.net"

def send_log(message):
    url = f"https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/sendMessage"
    requests.post(url, json={'chat_id': CHAT_ID, 'text': message})

def monitor_bundles():
    w3 = Web3(Web3.HTTPProvider(FLASHBOTS_URL))
    while True:
        # Проверяем последние блоки
        block = w3.eth.get_block('latest')
        # Здесь логика проверки выполненных бандлов
        time.sleep(15)

if __name__ == "__main__":
    send_log(" MEV-бот запущен")
    monitor_bundles()
```
